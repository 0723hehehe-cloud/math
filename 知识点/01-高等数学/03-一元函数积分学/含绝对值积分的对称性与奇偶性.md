# 含绝对值积分的对称性与奇偶性

> [!info] 概念定义
> 在定积分与变限积分中，经常遇到形如 $g(x) = \int_{a}^{b} |x - t| f(t) \, dt$ 的含绝对值被积函数的积分。这种函数的奇偶性分析是考研的高频难点，最优雅的解法是直接使用定义法并配合积分变量代换（照镜子代换法）。

> [!todo] 核心公式与性质
> ### 1. 经典模型与奇偶性定理
> 设 $f(x)$ 在对称区间 $[-a, a]$ 上连续，定义函数：
> $$g(x) = \\int_{-a}^{a} |x - t| f(t) \\, dt$$
> - 若 $f(x)$ 为**偶函数**，则 $g(x)$ 也必为**偶函数**。
> - 若 $f(x)$ 为**奇函数**，则 $g(x)$ 也必为**奇函数**。
> 
> ### 2. 核心证明（定义法变量代换）
> 我们来计算 $g(-x)$：
> $$g(-x) = \\int_{-a}^{a} |-x - t| f(t) \\, dt = \\int_{-a}^{a} |x + t| f(t) \\, dt$$
> 令积分变量代换 $u = -t \\implies dt = -du$：
> $$g(-x) = \\int_{a}^{-a} |x - u| f(-u) \\, (-du) = \\int_{-a}^{a} |x - u| f(-u) \\, du$$
> - 若 $f(x)$ 为**偶函数**（即 $f(-u) = f(u)$）：
>   $$g(-x) = \\int_{-a}^{a} |x - u| f(u) \\, du = g(x) \\implies g(x) \\text{ 是偶函数}$$
> - 若 $f(x)$ 为**奇函数**（即 $f(-u) = -f(u)$）：
>   $$g(-x) = -\\int_{-a}^{a} |x - u| f(u) \\, du = -g(x) \\implies g(x) \\text{ 是奇函数}$$

> [!tip] 考研核心结论 (必背)
> 1. **秒杀法则：切忌盲目拆分绝对值！**
>    很多同学一看到被积函数里有 $|x-t|$，就习惯性地在 $t=x$ 处进行分段拆分。虽然拆分后求导可以通过导数 $g'(x)$ 的奇偶性反推 $g(x)$，但计算量极大且容易在正负号上翻车。对于**奇偶性判断，首选定义代换法**。
> 2. **求导奇偶性反推**：
>    若对 $g(x)$ 拆分后求导，其导数为：
>    $$g'(x) = \\int_{-a}^{x} f(t) \\, dt - \\int_{x}^{a} f(t) \\, dt$$
>    若 $f(x)$ 是偶函数，可以验证 $g'(-x) = -g'(x)$（奇函数），从而可反推原函数 $g(x)$ 为偶函数。
