# 正割与余割函数的积分

> [!info] 概念定义
> 正割函数 $\sec x$ 和余割函数 $\csc x$ 的积分是考研数学中必须熟记的八大基本积分公式之一。其推导方法巧妙，是考查积分基本功（凑微分与三角变形）的经典题材。

> [!todo] 核心公式与性质
> ### 1. 正割函数积分的两种推导方法
> 
> #### 方法一：凑微分法（最经典、最快捷）
> 分子分母同乘以 $\sec x + \tan x$： $\displaystyle \int \sec x \, dx = \int \frac{\sec x(\sec x + \tan x)}{\sec x + \tan x} \, dx$
> 展开分子：\sec^2 x + \sec x \tan x。因为 $(\sec x + \tan x)' = \sec x \tan x + \sec^2 x$，直接凑微分得： $\displaystyle \int \sec x \, dx = \int \frac{d(\sec x + \tan x)}{\sec x + \tan x} = \ln|\sec x + \tan x| + C$
> 
> #### 方法二：三角变换与倍角法
> 将正割化为余弦倒数，再平移转化为正弦： $\displaystyle \int \sec x \, dx = \int \frac{dx}{\cos x} = \int \frac{d\left(x + \frac{\pi}{2}\right)}{\sin\left(x + \frac{\pi}{2}\right)}$
> 应用二倍角公式 $\sin 2\theta = 2\sin\theta\cos\theta$ 将分母展开： $\displaystyle \int \sec x \, dx = \int \frac{d\left(x + \frac{\pi}{2}\right)}{2\sin\left(\frac{x}{2} + \frac{\pi}{4}\right)\cos\left(\frac{x}{2} + \frac{\pi}{4}\right)}$
> 分子分母同除以 $\cos^2\left(\frac{x}{2} + \frac{\pi}{4}\right)$ 凑微分： $\displaystyle \int \sec x \, dx = \int \frac{\sec^2\left(\frac{x}{2} + \frac{\pi}{4}\right) \, d\left(\frac{x}{2} + \frac{\pi}{4}\right)}{\tan\left(\frac{x}{2} + \frac{\pi}{4}\right)} = \ln\left|\tan\left(\frac{x}{2} + \frac{\pi}{4}\right)\right| + C$
> 
> ---
> 
> ### 2. 余割函数积分的对应推导方法
> 
> #### 方法一：凑微分法
> 分子分母同乘以 $\csc x - \cot x$： $\displaystyle \int \csc x \, dx = \int \frac{\csc x(\csc x - \cot x)}{\csc x - \cot x} \, dx$
> 因为 $(\csc x - \cot x)' = -\csc x \cot x - (-\csc^2 x) = \csc^2 x - \csc x \cot x$，凑微分得： $\displaystyle \int \csc x \, dx = \int \frac{d(\csc x - \cot x)}{\csc x - \cot x} = \ln|\csc x - \cot x| + C$
> 
> #### 方法二：三角变换与倍角法
> 直接将正弦化为二倍角： $\displaystyle \int \csc x \, dx = \int \frac{dx}{\sin x} = \int \frac{dx}{2\sin\frac{x}{2}\cos\frac{x}{2}} = \int \frac{\sec^2\frac{x}{2} \, d\left(\frac{x}{2}\right)}{\tan\frac{x}{2}} = \ln\left|\tan\frac{x}{2}\right| + C$

> [!tip] 考研核心结论 (必背)
> 1. **公式等价性（常考证明/化简）**：
>    注意正割积分的两个结果是完全恒等互通的： $\displaystyle \ln|\sec x + \tan x| \equiv \ln\left|\tan\left(\frac{x}{2} + \frac{\pi}{4}\right)\right|$
>    *(证明：利用三角恒等式：$\tan\left(\frac{x}{2}+\frac{\pi}{4}\right) = \frac{\tan\frac{x}{2} + 1}{1 - \tan\frac{x}{2}} = \frac{\cos\frac{x}{2} + \sin\frac{x}{2}}{\cos\frac{x}{2} - \sin\frac{x}{2}} = \frac{(\cos\frac{x}{2} + \sin\frac{x}{2})^2}{\cos^2\frac{x}{2} - \sin^2\frac{x}{2}} = \frac{1 + \sin x}{\cos x} = \sec x + \tan x$)*
> 2. **余割积分公式恒等性**： $\displaystyle \ln|\csc x - \cot x| \equiv \ln\left|\tan\frac{x}{2}\right|$
>    *(证明：利用：$\csc x - \cot x = \frac{1 - \cos x}{\sin x} = \frac{2\sin^2\frac{x}{2}}{2\sin\frac{x}{2}\cos\frac{x}{2}} = \tan\frac{x}{2}$)*
