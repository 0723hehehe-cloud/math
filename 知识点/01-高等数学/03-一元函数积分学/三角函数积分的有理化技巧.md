# 三角函数积分的有理化技巧

> [!info] 概念定义
> 在计算三角函数分式的不定积分或定积分时，如果分母形如 $1 \pm \sin x$ 或 $1 \pm \cos x$，可以通过**分母有理化**（即分子分母同乘以其“共轭项” $1 \mp \sin x$ 或 $1 \mp \cos x$）的方法，将分母化为单项式 $\cos^2 x$ 或 $\sin^2 x$，从而快速拆分求解。这是一种极其高效的积分“秒杀”技巧。

> [!todo] 核心公式与性质
> 1. **反正弦共轭有理化**：
> $\displaystyle \frac{1}{1+\sin x} = \frac{1-\sin x}{(1+\sin x)(1-\sin x)} = \frac{1-\sin x}{\cos^2 x} = \sec^2 x - \sec x \tan x$
> 由于 $(\tan x - \sec x)' = \sec^2 x - \sec x \tan x$，可得：
> $\displaystyle \int \frac{1}{1+\sin x} \, dx = \tan x - \sec x + C$
> 
> 2. **反余弦共轭有理化**：
> $\displaystyle \frac{1}{1+\cos x} = \frac{1-\cos x}{(1+\cos x)(1-\cos x)} = \frac{1-\cos x}{\sin^2 x} = \csc^2 x - \csc x \cot x$
> 由于 $(\csc x - \cot x)' = \csc^2 x - \csc x \cot x$，可得：
> $\displaystyle \int \frac{1}{1+\cos x} \, dx = \csc x - \cot x + C$

> [!tip] 考研核心结论 (必背)
> 1. **秒杀万能公式**：对于分母含 $1 \pm \sin x$ 或 $1 \pm \cos x$ 的分式积分，**优先采用分母有理化**。这可以完美规避令 $t = \tan \frac{x}{2}$ 的万能公式所带来的繁琐积分代换，节省 80% 的答题时间。
> 2. **符号细节防错**：注意两项积分相减时的符号变化。在代入定积分上下限时，注意特殊三角函数值：
>    - $\sec \frac{\pi}{4} = \sqrt{2}$，$\sec 0 = 1$。
>    - $\csc \frac{\pi}{4} = \sqrt{2}$，$\csc \frac{\pi}{2} = 1$。
