# 微分方程全书复盘 总结复盘

### 涉及知识点

- **核心知识点1**：一阶方程先分类：可分离、齐次、一阶线性、Bernoulli 或可降阶。

- **核心知识点2**：一阶线性方程统一写成 $y^{\prime}+P(x)y=Q(x)$，使用积分因子。

- **核心知识点3**：高阶线性常系数方程由特征根决定齐次解，非齐次特解按右端类型设型。

- **核心知识点4**：Euler 方程可令 $x=e^t$ 化为常系数方程。

- **核心知识点5**：应用题从变化率建方程，初值用于确定任意常数；最后检查定义域与长期行为。

### 核心公式与使用边界

- **公式1**：$y^{\prime}+P(x)y=Q(x)\Rightarrow y=e^{-\int Pdx}\left(\int Qe^{\int Pdx}dx+C\right)$。

- **公式2**：$y^{\prime}+P(x)y=Q(x)y^n$ 令 $z=y^{1-n}$。

- **公式3**：$ay^{\prime\prime}+by^{\prime}+cy=0$ 对应特征方程 $ar^2+br+c=0$。

### 📌 强化核心：输入题目关键词 $\to$ 输出秒杀方法

| 题目表面信号 / 关键词 | 对应解题突破口 / 判定方法 |
| :--- | :--- |
| 变量可分到等号两侧 | 分离变量后两边积分，并检查丢失的常值解。 |
| $y^{\prime}=F(y/x)$ | 令 $u=y/x$，则 $y^{\prime}=u+xu^{\prime}$。 |

| 常系数高阶非齐次 | 先解特征方程，再按右端设特解并处理共振。 |

### 核心题型与解法

#### 题型模型一：一阶方程分类模型

- **核心方法**：【核心解题模型与思维框架】

  1. **第1步**：先观察方程结构而不是立即积分：能写成 $g(y)dy=f(x)dx$ 是可分离型；只含 $y/x$ 是齐次型；形如 $y^{\prime}+P(x)y=Q(x)$ 是一阶线性型。

  2. **第2步**：可分离时把含 $y$ 与含 $x$ 的部分移到两侧，但除以 $g(y)$ 前先检查 $g(y)=0$ 是否给出常值解，避免在除法中丢解。

  3. **第3步**：一阶线性方程先化成首项系数为 $1$ 的标准形式，积分因子为 $\mu=e^{\int Pdx}$；乘遍全式后左边应准确成为 $(\mu y)^{\prime}$。

  4. **第4步**：积分得到通解后代回原方程验证，并根据初值确定常数。还要写清解所在区间，特别是含对数、分母或绝对值时。

- **典型例示**：【一题反应一类】

  **题目**：求一阶线性方程 $y^{\prime}+y=e^x$ 的通解。

  **完整解答**：

  1. 标准形式中 $P(x)=1$，积分因子为 $e^{\int1dx}=e^x$。

  2. 方程两边乘 $e^x$，左侧成为 $(e^xy)^{\prime}$。

  3. 积分得 $e^xy=\frac12e^{2x}+C$。

  4. 所以 $y=\frac12e^x+Ce^{-x}$，代回原方程可验证。

- **书目出处**：《基础30讲》第15讲（约第377-408页）；《1000题数二》第15章相关题型。

#### 题型模型二：常系数高阶模型

- **核心方法**：【核心解题模型与思维框架】

  1. **第1步**：把齐次常系数方程 $ay^{\prime\prime}+by^{\prime}+cy=0$ 转成特征方程 $ar^2+br+c=0$，先求根及其重数。

  2. **第2步**：两个不同实根对应 $C_1e^{r_1x}+C_2e^{r_2x}$；重根 $r$ 对应 $(C_1+C_2x)e^{rx}$；共轭复根 $\alpha\pm i\beta$ 对应 $e^{\alpha x}(C_1\cos\beta x+C_2\sin\beta x)$。

  3. **第3步**：非齐次方程先写齐次通解，再按右端函数类型设特解。若试探形式与齐次解重合，要乘以足够次数的 $x$ 消除共振。

  4. **第4步**：将特解代回比较系数，最后叠加 $y=y_h+y_p$。有初值时对通解及其导数代入，联立求所有常数。

- **典型例示**：【一题反应一类】

  **题目**：求 $y^{\prime\prime}-3y^{\prime}+2y=0$ 的通解。

  **完整解答**：

  1. 特征方程为 $r^2-3r+2=0$。

  2. 因式分解得 $(r-1)(r-2)=0$。

  3. 两个不同实根为 $1,2$。

  4. 通解为 $y=C_1e^x+C_2e^{2x}$。

- **书目出处**：《基础30讲》第15讲（约第377-408页）；《1000题数二》第15章相关题型。

#### 题型模型三：微分方程应用模型

- **核心方法**：【核心解题模型与思维框架】

  1. **第1步**：先定义未知函数及自变量，逐句把“变化率与现有量成正比”“流入减流出”等文字翻译成导数关系，并保留比例常数。

  2. **第2步**：列方程时统一单位和正方向。冷却、衰减等过程中的导数应与偏离平衡值的量反号，不能只凭公式记忆符号。

  3. **第3步**：解出通解后依次使用全部初始或观测条件确定常数和参数。若有两个未知常数，就必须有两条独立条件。

  4. **第4步**：最后检查初值、长期极限和单调方向是否符合实际。例如冷却模型应满足 $T(t)$ 逐渐趋近环境温度，而不是无限下降。

- **典型例示**：【一题反应一类】

  **题目**：某物体满足冷却定律 $T^{\prime}=-k(T-20)$，且 $T(0)=80$、$T(10)=50$，求温度函数。

  **完整解答**：

  1. 令 $u=T-20$，则 $u^{\prime}=-ku$，分离变量得 $u=Ce^{-kt}$。

  2. 由 $T(0)=80$ 得 $u(0)=60$，所以 $C=60$。

  3. 由 $T(10)=50$ 得 $30=60e^{-10k}$，因此 $e^{-10k}=1/2$，$k=\frac{\ln2}{10}$。

  4. 温度函数为 $T(t)=20+60e^{-(\ln2)t/10}=20+60\cdot2^{-t/10}$。

- **书目出处**：《基础30讲》第15讲（约第377-408页）；《1000题数二》第15章相关题型。

### 易错点与纠正

- **易错点1**：分离变量时除以含未知函数的因子，丢掉常值解。

- **易错点2**：线性方程未先化成标准形式。

- **易错点3**：特征根重根或复根对应通解写错。

- **易错点4**：非齐次特解与齐次解共振却未乘 $x$。
