# 微分方程全书复盘 总结复盘

### 涉及知识点

- **核心知识点1**：一阶方程先分类：可分离、齐次、一阶线性、Bernoulli 或可降阶。

- **核心知识点2**：一阶线性方程统一写成 $y^{\prime}+P(x)y=Q(x)$，使用积分因子。

- **核心知识点3**：高阶线性常系数方程由特征根决定齐次解，非齐次特解按右端类型设型。

- **核心知识点4**：Euler 方程可令 $x=e^t$ 化为常系数方程。

- **核心知识点5**：应用题从变化率建方程，初值用于确定任意常数；最后检查定义域与长期行为。

### 核心公式与使用边界

- **公式1**：$y^{\prime}+P(x)y=Q(x)\Rightarrow y=e^{-\int Pdx}\left(\int Qe^{\int Pdx}dx+C\right)$。

- **公式2**：$y^{\prime}+P(x)y=Q(x)y^n$ 令 $z=y^{1-n}$。

- **公式3**：$ay^{\prime\prime}+by^{\prime}+cy=0$ 对应特征方程 $ar^2+br+c=0$。

### 📌 强化核心：输入题目关键词 $\to$ 输出秒杀方法

| 题目表面信号 / 关键词 | 对应解题突破口 / 判定方法 |
| :--- | :--- |
| 变量可分到等号两侧 | 分离变量后两边积分，并检查丢失的常值解。 |
| $y^{\prime}=F(y/x)$ | 令 $u=y/x$，则 $y^{\prime}=u+xu^{\prime}$。 |
| 一阶线性结构 | 标准化后直接用积分因子。 |
| 常系数高阶非齐次 | 先解特征方程，再按右端设特解并处理共振。 |

### 核心题型与解法

#### 题型模型一：一阶方程分类模型

- **核心方法**：【核心解题模型与思维框架】

  1. **步骤1**：看能否分离；

  2. **步骤2**：看 $y/x$；

  3. **步骤3**：看线性；

  4. **步骤4**：看 Bernoulli；

  5. **步骤5**：特殊换元；

  **关键提醒**：先分类比盲目变形更重要。

- **典型例示**：【一题反应一类】

  **题目**：求一阶线性方程 $y^{\prime}+y=e^x$ 的通解。

  **完整解答**：

  1. 标准形式中 $P(x)=1$，积分因子为 $e^{\int1dx}=e^x$。

  2. 方程两边乘 $e^x$，左侧成为 $(e^xy)^{\prime}$。

  3. 积分得 $e^xy=\frac12e^{2x}+C$。

  4. 所以 $y=\frac12e^x+Ce^{-x}$，代回原方程可验证。

- **书目出处**：《基础30讲》第15讲（约第377-408页）；《1000题数二》第15章相关题型。

#### 题型模型二：常系数高阶模型

- **核心方法**：【核心解题模型与思维框架】

  1. **步骤1**：特征方程；

  2. **步骤2**：齐次通解；

  3. **步骤3**：特解设型；

  4. **步骤4**：叠加；

  5. **步骤5**：初值；

  **关键提醒**：特解与齐次解重合时乘 $x^s$。

- **典型例示**：【一题反应一类】

  **题目**：求 $y^{\prime\prime}-3y^{\prime}+2y=0$ 的通解。

  **完整解答**：

  1. 特征方程为 $r^2-3r+2=0$。

  2. 因式分解得 $(r-1)(r-2)=0$。

  3. 两个不同实根为 $1,2$。

  4. 通解为 $y=C_1e^x+C_2e^{2x}$。

- **书目出处**：《基础30讲》第15讲（约第377-408页）；《1000题数二》第15章相关题型。

#### 题型模型三：微分方程应用模型

- **核心方法**：【核心解题模型与思维框架】

  1. **步骤1**：设未知函数；

  2. **步骤2**：写变化率关系；

  3. **步骤3**：解方程；

  4. **步骤4**：用初值；

  5. **步骤5**：解释结果；

  **关键提醒**：面积、体积、增长率的正负要符合实际。

- **典型例示**：【一题反应一类】

  **题目**：某物体满足冷却定律 $T^{\prime}=-k(T-20)$，且 $T(0)=80$、$T(10)=50$，求温度函数。

  **完整解答**：

  1. 令 $u=T-20$，则 $u^{\prime}=-ku$，分离变量得 $u=Ce^{-kt}$。

  2. 由 $T(0)=80$ 得 $u(0)=60$，所以 $C=60$。

  3. 由 $T(10)=50$ 得 $30=60e^{-10k}$，因此 $e^{-10k}=1/2$，$k=\frac{\ln2}{10}$。

  4. 温度函数为 $T(t)=20+60e^{-(\ln2)t/10}=20+60\cdot2^{-t/10}$。

- **书目出处**：《基础30讲》第15讲（约第377-408页）；《1000题数二》第15章相关题型。

### 易错点与纠正

- **易错点1**：分离变量时除以含未知函数的因子，丢掉常值解。

- **易错点2**：线性方程未先化成标准形式。

- **易错点3**：特征根重根或复根对应通解写错。

- **易错点4**：非齐次特解与齐次解共振却未乘 $x$。
