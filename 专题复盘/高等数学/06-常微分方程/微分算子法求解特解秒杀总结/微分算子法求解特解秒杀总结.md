### 题型一：指数型 $f(x) = e^{ax}$ （非共振与共振）

#### 公式总结
- **非共振（$F(a) \neq 0$）**：
  $$\frac{1}{F(D)} e^{ax} = \frac{1}{F(a)} e^{ax}$$
- **共振（$F(a) = 0$）**：
  $$\frac{1}{F(D)} e^{ax} = x \frac{1}{F'(D)} e^{ax}$$

#### 经典例题 1（非共振）
> **题目**：求微分方程 $y'' - 3y' + 2y = e^{4x}$ 的一个特解 $y^*$。
> 
> **解法（算子法秒杀）**：
> 1. 写出微分算子 $F(D) = D^2 - 3D + 2$。
> 2. 特解 $y^* = \frac{1}{D^2 - 3D + 2} e^{4x}$。
> 3. 代入 $D = 4 mplies F(4) = 4^2 - 3(4) + 2 = 6 \neq 0$。
> 4. 故 $y^* = \frac{1}{6} e^{4x}$。

#### 经典例题 2（单重共振）
> **题目**：求微分方程 $y'' - 3y' + 2y = e^{2x}$ 的一个特解 $y^*$。
> 
> **解法（算子法秒杀）**：
> 1. 算子 $F(D) = D^2 - 3D + 2$。代入 $D = 2 mplies F(2) = 2^2 - 3(2) + 2 = 0$（共振！）。
> 2. 对分母算子求导 $F'(D) = 2D - 3$，分子乘以 $x$：
>    $$y^* = x \frac{1}{F'(D)} e^{2x} = x \frac{1}{2D - 3} e^{2x}$$
> 3. 再代入 $D = 2 mplies 2(2) - 3 = 1$。
> 4. 故 $y^* = x e^{2x}$。

### 题型二：正弦/余弦型 $f(x) = \sin(ax)$ 或 $\cos(ax)$

#### 公式总结
- **替换规则**：直接将方程中的 $D^2$ 替换为 $-a^2$。
- **若分母留有一阶项 $D$**：分子分母同乘共轭项 $(AD + B)$ 再次凑出 $D^2$ 后替换。
- **共振秒杀公式**（$D^2 + a^2 = 0$ 时）：
  $$\frac{1}{D^2 + a^2} \sin(ax) = -\frac{x}{2a} \cos(ax), \quad \frac{1}{D^2 + a^2} \cos(ax) = \frac{x}{2a} \sin(ax)$$

#### 经典例题 3（直接替换型）
> **题目**：求微分方程 $y'' + 4y = \cos(3x)$ 的一个特解 $y^*$。
> 
> **解法（算子法秒杀）**：
> 1. 算子 $F(D^2) = D^2 + 4$。
> 2. 令 $D^2 \to -3^2 = -9$：
>    $$y^* = \frac{1}{-9 + 4} \cos(3x) = -\frac{1}{5} \cos(3x)$$

#### 经典例题 4（一阶留存共轭消去型）
> **题目**：求微分方程 $y'' + y' + y = \sin(2x)$ 的一个特解 $y^*$。
> 
> **解法（算子法秒杀）**：
> 1. 算子 $F(D) = D^2 + D + 1$。
> 2. 代入 $D^2 \to -2^2 = -4$：
>    $$y^* = \frac{1}{-4 + D + 1} \sin(2x) = \frac{1}{D - 3} \sin(2x)$$
> 3. 分子分母同乘 $(D + 3)$：
>    $$y^* = \frac{D + 3}{D^2 - 9} \sin(2x)$$
> 4. 再次代入 $D^2 \to -4$：
>    $$y^* = \frac{D + 3}{-4 - 9} \sin(2x) = -\frac{1}{13} (D + 3) \sin(2x)$$
> 5. 作用微分算子 $D \sin(2x) = 2 \cos(2x)$：
>    $$y^* = -\frac{1}{13} (2 \cos(2x) + 3 \sin(2x))$$

#### 经典例题 5（三角共振型）
> **题目**：求微分方程 $y'' + 9y = \sin(3x)$ 的一个特解 $y^*$。
> 
> **解法（算子法秒杀）**：
> 1. 算子 $F(D^2) = D^2 + 9$。代入 $D^2 \to -3^2 = -9 mplies -9 + 9 = 0$（共振！）。
> 2. 直接套用共振秒杀公式 $\frac{1}{D^2 + a^2} \sin(ax) = -\frac{x}{2a} \cos(ax)$：
>    $$y^* = -\frac{x}{2(3)} \cos(3x) = -\frac{x}{6} \cos(3x)$$

### 题型三：多项式型 $f(x) = P_n(x)$

#### 公式总结
- 将 $\frac{1}{F(D)}$ 展开为关于 $D$ 的麦克劳林级数，保留到 $D^n$ 项：
  $$\frac{1}{1 - D} = 1 + D + D^2 + \dots, \quad \frac{1}{1 + D} = 1 - D + D^2 - \dots$$

#### 经典例题 6
> **题目**：求微分方程 $y'' + 2y' + y = x^2 + 2x$ 的一个特解 $y^*$。
> 
> **解法（算子法秒杀）**：
> 1. 算子 $F(D) = D^2 + 2D + 1 = (1 + D)^2$。
> 2. 写为倒数升幂展开形式：
>    $$y^* = (1 + D)^{-2} (x^2 + 2x)$$
> 3. 利用泰勒展开 $(1 + D)^{-2} = 1 - 2D + 3D^2 - \dots$ （因为被作用式为二次多项式，展开至 $D^2$ 即可）：
>    $$y^* = (1 - 2D + 3D^2) (x^2 + 2x)$$
> 4. 逐项作用微分算子：
>    - $1 \cdot (x^2 + 2x) = x^2 + 2x$
>    - $-2 D (x^2 + 2x) = -2 (2x + 2) = -4x - 4$
>    - $3 D^2 (x^2 + 2x) = 3 (2) = 6$
> 5. 累加求和：
>    $$y^* = (x^2 + 2x) + (-4x - 4) + 6 = x^2 - 2x + 2$$

### 题型四：指数乘多项式型 $f(x) = e^{ax} P_n(x)$ （移位法则）

#### 公式总结
- 套用**指数移位法则**将 $e^{ax}$ 提至算子左侧，算子中的 $D$ 替换为 $D + a$：
  $$\frac{1}{F(D)} \left[ e^{ax} P_n(x) \right] = e^{ax} \frac{1}{F(D + a)} P_n(x)$$

#### 经典例题 7
> **题目**：求微分方程 $y'' - 2y' + y = x e^x$ 的一个特解 $y^*$。
> 
> **解法（算子法秒杀）**：
> 1. 算子 $F(D) = D^2 - 2D + 1 = (D - 1)^2$。
> 2. 应用移位法则，将 $e^x$ 移至左侧，同时 $D \to D + 1$：
>    $$y^* = \frac{1}{(D - 1)^2} [e^x \cdot x] = e^x \frac{1}{(D + 1 - 1)^2} x = e^x \frac{1}{D^2} x$$
> 3. 逆算子 $\frac{1}{D^2}$ 表示连续两次积分：
>    $$\frac{1}{D} x = nt x \, dx = \frac{x^2}{2} mplies \frac{1}{D^2} x = nt \frac{x^2}{2} \, dx = \frac{x^3}{6}$$
> 4. 故特解为：
>    $$y^* = \frac{x^3}{6} e^x$$

### 题型五：指数乘三角型 $f(x) = e^{ax} \cos(bx)$ 或 $e^{ax} \sin(bx)$

#### 公式总结
- 结合**指数移位法则**与**三角替换/共振法则**：
  $$\frac{1}{F(D)} \left[ e^{ax} \cos(bx) \right] = e^{ax} \frac{1}{F(D + a)} \cos(bx)$$

#### 经典例题 8
> **题目**：求微分方程 $y'' - 2y' + 5y = e^x \cos(2x)$ 的一个特解 $y^*$。
> 
> **解法（算子法秒杀）**：
> 1. 算子 $F(D) = D^2 - 2D + 5$。
> 2. 利用移位法则，移出 $e^x$，将 $D \to D + 1$：
>    $$y^* = e^x \frac{1}{(D + 1)^2 - 2(D + 1) + 5} \cos(2x) = e^x \frac{1}{D^2 + 4} \cos(2x)$$
> 3. 对 $\frac{1}{D^2 + 4} \cos(2x)$ 应用三角共振公式 $\frac{1}{D^2 + a^2} \cos(ax) = \frac{x}{2a} \sin(ax)$：
>    $$\frac{1}{D^2 + 4} \cos(2x) = \frac{x}{2(2)} \sin(2x) = \frac{x}{4} \sin(2x)$$
> 4. 乘回 $e^x$ 得：
>    $$y^* = \frac{x}{4} e^x \sin(2x)$$

> [!warning] 易错点 & 避坑指南

1. **$D^2 \to -a^2$ 符号陷阱**：
   - 必须先平方再加负号！例如对于 $\sin(3x)$，$a = 3$，应替换为 $D^2 \to -3^2 = -9$；**千万不能写成 $(-3)^2 = 9$**！
2. **指数移位法则中的代换顺序**：
   - 移位法则 $\frac{1}{F(D)} [e^{ax} v(x)] = e^{ax} \frac{1}{F(D+a)} v(x)$ 中，一旦 $e^{ax}$ 移到了算子左边，**后续所有算子运算都只作用于 $v(x)$，不再对 $e^{ax}$ 求导**！
3. **分母求导（洛必达）适用条件**：
   - 只有在代入后分母确为 $0$（即共振发生）时，才能使用 $x \frac{1}{F'(D)}$；若分母不为 $0$，直接代入数值即可，滥用求导会导致错误。
4. **多项式展开截断层数**：
   - 对于 $n$ 次多项式 $P_n(x)$，展开式只需保留到 $D^n$ 项，因为高于 $n$ 阶的导数 $D^{n+1} P_n(x) \equiv 0$。
