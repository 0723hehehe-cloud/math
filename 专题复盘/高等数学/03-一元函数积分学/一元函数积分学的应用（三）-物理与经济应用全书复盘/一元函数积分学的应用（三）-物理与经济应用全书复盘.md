# 一元函数积分学的应用（三）-物理与经济应用全书复盘 总结复盘

### 涉及知识点

- **核心知识点1**：积分应用统一思想是“总量 = 微元累加”，关键在于正确选择微元。

- **核心知识点2**：变力做功按位移积分，液体压力按深度分层并乘面积微元。

- **核心知识点3**：质量、质心与转动惯量由密度乘相应几何权重积分。

- **核心知识点4**：由边际函数恢复总量时使用定积分，并结合初始值。

- **核心知识点5**：建模完成后要用量纲与正负性检查答案。

### 核心公式与使用边界

- **公式1**：$W=\int_a^b F(x)dx$。

- **公式2**：$m=\int\rho(x)dx$，$\bar x=\frac1m\int x\rho(x)dx$。

- **公式3**：$C(q)=C(0)+\int_0^q C^{\prime}(t)dt$。

### 📌 强化核心：输入题目关键词 $\to$ 输出秒杀方法

| 题目表面信号 / 关键词 | 对应解题突破口 / 判定方法 |
| :--- | :--- |
| 力随位置变化 | 取位移微元，写 $dW=F(x)dx$。 |
| 液体对闸门压力 | 按深度取水平薄条，压强乘面积。 |
| 已知线密度求质心 | 先求总质量，再求一阶矩。 |
| 给边际成本/收益 | 积分恢复总量并代初始固定成本。 |

### 核心题型与解法

#### 题型模型一：微元建模模型

- **核心方法**：【核心解题模型与思维框架】

  1. **第1步**：先把连续对象切成位于 $x$ 附近、厚度为 $dx$ 的微元，明确微元的几何尺寸、密度或受力大小。

  2. **第2步**：写出微元量，例如质量 $dm=\rho(x)dx$、功 $dW=F(x)dx$、液压力 $dP=压强\times面积$。每个因子的物理意义都要对应题设。

  3. **第3步**：根据对象实际范围确定积分上下限，对微元量积分得到总量。若表达式在不同区间变化，应分段积分。

  4. **第4步**：最后检查量纲：质量、功、力矩各有不同单位。量纲不对通常说明漏乘长度、面积或距离。

- **典型例示**：【一题反应一类】

  **题目**：弹簧力为 $F(x)=kx$，从自然长度拉到 $x=a$，求做功。

  **完整解答**：

  1. 位移为积分变量，微元功 $dW=F(x)dx=kx\,dx$。

  2. 在 $0$ 到 $a$ 上累加：$W=\int_0^a kx\,dx$。

  3. 积分得到 $W=\frac12ka^2$。

  4. 单位检查：力常数乘长度平方得到能量单位。

- **书目出处**：《基础30讲》第12讲（约第294-303页）；《1000题数二》第12章相关题型。

#### 题型模型二：质心模型

- **核心方法**：【核心解题模型与思维框架】

  1. **第1步**：先计算总质量 $m=\int\rho(x)dx$。二维薄片则使用二重积分 $m=\iint_D\rho(x,y)dA$。

  2. **第2步**：计算关于参考轴的一阶矩：一维细棒为 $M=\int x\rho(x)dx$，平面薄片要分别计算 $M_x$ 与 $M_y$。

  3. **第3步**：质心坐标等于一阶矩除以总质量，例如 $\bar x=M/m$。密度为正时，质心必须落在物体坐标范围内。

  4. **第4步**：区域或密度具有对称性时先确定质心所在对称轴，可减少积分；但另一坐标仍需由积分或第二条对称性确定。

- **典型例示**：【一题反应一类】

  **题目**：细棒位于 $[0,1]$，线密度 $\rho(x)=1+x$，求质量和质心。

  **完整解答**：

  1. 质量 $m=\int_0^1(1+x)dx=3/2$。

  2. 关于原点的一阶矩 $M=\int_0^1x(1+x)dx=1/2+1/3=5/6$。

  3. 质心 $\bar x=M/m$。

  4. 所以 $\bar x=5/9$。

- **书目出处**：《基础30讲》第12讲（约第294-303页）；《1000题数二》第12章相关题型。

#### 题型模型三：边际恢复模型

- **核心方法**：【核心解题模型与思维框架】

  1. **第1步**：明确边际量是总量的导数，例如边际成本 $C^{\prime}(q)$。由边际量恢复总量本质上是求原函数。

  2. **第2步**：利用已知基准值写成定积分形式 $C(q)=C(q_0)+\int_{q_0}^qC^{\prime}(t)dt$，这样积分常数由固定成本自动确定。

  3. **第3步**：计算积分并整理函数，再求平均量时除以产量，例如平均成本为 $C(q)/q$，不要与边际成本混淆。

  4. **第4步**：用初始条件回代检查，并解释导数或积分的经济含义与单位，避免只得到形式上的函数表达式。

- **典型例示**：【一题反应一类】

  **题目**：已知边际成本 $C^{\prime}(q)=2q+3$，固定成本 $C(0)=10$，求总成本。

  **完整解答**：

  1. 由边际量恢复总量：$C(q)=C(0)+\int_0^qC^{\prime}(t)dt$。

  2. 代入得到 $C(q)=10+\int_0^q(2t+3)dt$。

  3. 积分为 $q^2+3q$。

  4. 所以 $C(q)=q^2+3q+10$。

- **书目出处**：《基础30讲》第12讲（约第294-303页）；《1000题数二》第12章相关题型。

### 易错点与纠正

- **易错点1**：微元方向选错导致宽度表达复杂或错误。

- **易错点2**：压力题漏乘薄条宽度。

- **易错点3**：求质心只算矩而未除总质量。

- **易错点4**：边际函数积分后漏加固定量。
