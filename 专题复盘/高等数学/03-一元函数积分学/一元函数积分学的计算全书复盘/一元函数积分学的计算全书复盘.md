# 一元函数积分学的计算全书复盘 总结复盘

### 涉及知识点

- **核心知识点1**：积分计算先识别结构：凑微分、换元、分部、部分分式、三角代换。

- **核心知识点2**：有理函数先做多项式除法，再因式分解与部分分式。

- **核心知识点3**：含根式时根据 $a^2-x^2$、$a^2+x^2$、$x^2-a^2$ 选择三角或双曲代换。

- **核心知识点4**：定积分优先检查奇偶性、周期性、区间平移和 $x\mapsto a+b-x$ 对称。

- **核心知识点5**：反常积分计算必须与判敛同步，不收敛时没有有限积分值。

### 核心公式与使用边界

- **公式1**：$\int u\,dv=uv-\int v\,du$。

- **公式2**：$\int_a^b f(x)dx=\int_a^b f(a+b-x)dx$。

- **公式3**：$\int_0^{2a}f(x)dx=\int_0^a[f(x)+f(2a-x)]dx$。

### 📌 强化核心：输入题目关键词 $\to$ 输出秒杀方法

| 题目表面信号 / 关键词 | 对应解题突破口 / 判定方法 |
| :--- | :--- |
| 被积函数含内函数及其导数 | 直接凑微分或令内函数为新变量。 |
| 多项式乘指数/三角 | 优先分部积分，必要时循环求解。 |
| 定积分区间对称 | 先做奇偶与中心反射，避免直接求原函数。 |
| 分母可因式分解的有理式 | 部分分式拆解后逐项积分。 |

### 核心题型与解法

#### 题型模型一：换元模型

- **核心方法**：【核心解题模型与思维框架】

  1. **第1步**：寻找被积式中的“函数及其导数”组合，令复杂内层为 $u$，同时把 $du$ 完整替换出来。换元后积分中不应残留原变量。

  2. **第2步**：三角幂积分根据奇偶性拆项：某个幂为奇数时保留一个因子并换另一个三角函数；两个幂都为偶数时使用降幂公式。

  3. **第3步**：定积分换元必须同步更换上下限，或在积分完成后换回原变量再代原上下限，两种做法不能混用。

  4. **第4步**：完成后对原函数求导检查不定积分；定积分则检查符号与范围，例如非负函数积分结果不能为负。

- **典型例示**：【一题反应一类】

  **题目**：计算 $\int_0^{\pi/2}\sin^3x\,dx$。

  **完整解答**：

  1. 拆成 $\sin x(1-\cos^2x)$。

  2. 令 $u=\cos x$，$du=-\sin x\,dx$。

  3. 积分化为 $\int_0^1(1-u^2)du$。

  4. 结果为 $1-1/3=2/3$。

- **书目出处**：《基础30讲》第9讲（约第230-262页）；《1000题数二》第9章相关题型。

#### 题型模型二：分部积分模型

- **核心方法**：【核心解题模型与思维框架】

  1. **第1步**：把被积式拆成 $u\,dv$，按“反对幂指三”选择 $u$：反三角、对数、幂函数通常优先作为 $u$，容易积分的部分作为 $dv$。

  2. **第2步**：计算 $du$ 和 $v$ 后使用 $\int u\,dv=uv-\int v\,du$。选择应使新积分比原积分更简单，否则要重新分配。

  3. **第3步**：指数乘三角函数连续分部两次后会出现原积分，此时把原积分移到等式一侧统一求解，不能无限循环。

  4. **第4步**：定积分分部时边界项必须写成 $[uv]_a^b$ 并先计算；反常积分还要保留极限，确认边界项有限。

- **典型例示**：【一题反应一类】

  **题目**：计算 $\int xe^x\,dx$。

  **完整解答**：

  1. 多项式乘指数，选择分部积分。

  2. 取 $u=x$、$dv=e^x dx$，则 $du=dx$、$v=e^x$。

  3. 代入得 $xe^x-\int e^x dx=xe^x-e^x+C$。

  4. 求导复核：$(xe^x-e^x)^{\prime}=xe^x$。

- **书目出处**：《基础30讲》第9讲（约第230-262页）；《1000题数二》第9章相关题型。

#### 题型模型三：对称定积分模型

- **核心方法**：【核心解题模型与思维框架】

  1. **第1步**：当区间为 $[a,b]$ 时作对称换元 $x=a+b-t$，把原积分写成第二个等值积分。重点观察 $f(x)$ 与 $f(a+b-x)$ 相加后是否简化。

  2. **第2步**：将两个等值表达式相加，得到 $2I=\int_a^b[f(x)+f(a+b-x)]dx$。若括号化为常数或简单函数，积分可立即完成。

  3. **第3步**：关于区间中点的奇函数积分为零，偶函数可化为半区间两倍；使用前必须确认对称中心和积分区间完全匹配。

  4. **第4步**：周期函数还可按周期拆分区间。不要把“函数周期”误写成“原函数周期”，应直接利用定积分平移不变性。

- **典型例示**：【一题反应一类】

  **题目**：利用对称性计算 $I=\int_0^{\pi}x\sin x\,dx$。

  **完整解答**：

  1. 作对称换元 $x=\pi-t$，得到 $I=\int_0^{\pi}(\pi-t)\sin t\,dt$。

  2. 将变量 $t$ 改写为 $x$，与原式相加。

  3. $2I=\int_0^{\pi}\pi\sin x\,dx=2\pi$。

  4. 因此 $I=\pi$。

- **书目出处**：《基础30讲》第9讲（约第230-262页）；《1000题数二》第9章相关题型。

### 易错点与纠正

- **易错点1**：换元后忘记换上下限。

- **易错点2**：分部积分符号错误。

- **易错点3**：部分分式拆分前未先做除法。

- **易错点4**：定积分硬算，错过对称性。
