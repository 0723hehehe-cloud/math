# 一元函数积分学的概念与性质全书复盘 总结复盘

### 涉及知识点

- **核心知识点1**：不定积分是原函数族，必须带积分常数；定积分是和式极限，与原函数值无关。

- **核心知识点2**：可积的常用充分条件包括连续、单调或仅有限个间断点。

- **核心知识点3**：定积分具有线性、区间可加、保号、比较与积分中值性质。

- **核心知识点4**：变限积分函数把积分转化为函数，连续性和求导由微积分基本定理控制。

- **核心知识点5**：反常积分先写极限，再讨论收敛；无穷区间与瑕点必须分开处理。

### 核心公式与使用边界

- **公式1**：$\frac{d}{dx}\int_a^{g(x)}f(t)dt=f(g(x))g^{\prime}(x)$。

- **公式2**：$\int_a^b f(x)dx=F(b)-F(a)$。

- **公式3**：$\int_1^\infty x^{-p}dx$ 在 $p>1$ 时收敛。

### 📌 强化核心：输入题目关键词 $\to$ 输出秒杀方法

| 题目表面信号 / 关键词 | 对应解题突破口 / 判定方法 |
| :--- | :--- |
| 积分上限含 $x$ | 先看上下限，再用链式法则求导。 |
| 判断变限积分奇偶性 | 代入 $-x$，换元并利用原函数奇偶性。 |
| 反常积分收敛性 | 找无穷端或瑕点，分段后做比较。 |
| 积分号内函数只知连续 | 优先用保号、比较和中值定理。 |

### 核心题型与解法

#### 题型模型一：变限积分求导模型

- **核心方法**：【核心解题模型与思维框架】

  1. **步骤1**：规范上下限；

  2. **步骤2**：外层链式；

  3. **步骤3**：内层必要时换元；

  **关键提醒**：根号下 $x^2$ 要写 $|x|$。

- **典型例示**：【一题反应一类】

  **题目**：设 $F(x)=\int_0^{x^2}\sin t\,dt$，求 $F^{\prime}(x)$。

  **完整解答**：

  1. 识别为变上限积分，外层上限是 $g(x)=x^2$。

  2. 由基本定理，先把被积函数代入上限得到 $\sin(x^2)$。

  3. 再乘上限导数 $2x$，所以 $F^{\prime}(x)=2x\sin(x^2)$。

  4. 复核：不能把积分变量 $t$ 与外部变量 $x$ 混为一谈。

- **书目出处**：《基础30讲》第8讲（约第195-229页）；《1000题数二》第8章相关题型。

#### 题型模型二：反常积分判敛模型

- **核心方法**：【核心解题模型与思维框架】

  1. **步骤1**：找异常点；

  2. **步骤2**：拆区间；

  3. **步骤3**：写极限；

  4. **步骤4**：比较标准模型；

  **关键提醒**：多个异常点需分别收敛。

- **典型例示**：【一题反应一类】

  **题目**：判断并计算 $\int_1^{\infty}\frac1{x^2}\,dx$。

  **完整解答**：

  1. 先写成极限 $\lim_{b\to\infty}\int_1^b x^{-2}dx$。

  2. 原函数为 $-1/x$。

  3. 代入得 $\lim_{b\to\infty}(1-1/b)=1$。

  4. 积分收敛，值为 $1$。

- **书目出处**：《基础30讲》第8讲（约第195-229页）；《1000题数二》第8章相关题型。

#### 题型模型三：积分性质模型

- **核心方法**：【核心解题模型与思维框架】

  1. **步骤1**：先看区间与对称；

  2. **步骤2**：再看被积函数符号；

  3. **步骤3**：使用比较；

  **关键提醒**：未知原函数时性质比硬算重要。

- **典型例示**：【一题反应一类】

  **题目**：已知 $1\le f(x)\le3$（$0\le x\le2$），估计 $\int_0^2f(x)\,dx$。

  **完整解答**：

  1. 定积分具有保序性，对不等式 $1\le f(x)\le3$ 在 $[0,2]$ 上逐项积分。

  2. 得到 $\int_0^2 1\,dx\le\int_0^2f(x)\,dx\le\int_0^2 3\,dx$。

  3. 左右两端分别为 $2$ 和 $6$。

  4. 所以 $2\le\int_0^2f(x)\,dx\le6$。

- **书目出处**：《基础30讲》第8讲（约第195-229页）；《1000题数二》第8章相关题型。

### 易错点与纠正

- **易错点1**：不定积分漏写 $+C$。

- **易错点2**：变限积分求导漏乘上限导数。

- **易错点3**：反常积分不写极限就直接代上下限。

- **易错点4**：含多个瑕点却只检查一个。
