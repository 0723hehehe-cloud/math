# 一元函数积分学的概念与性质全书复盘 总结复盘

### 涉及知识点

- **核心知识点1**：不定积分是原函数族，必须带积分常数；定积分是和式极限，与原函数值无关。

- **核心知识点2**：可积的常用充分条件包括连续、单调或仅有限个间断点。

- **核心知识点3**：定积分具有线性、区间可加、保号、比较与积分中值性质。

- **核心知识点4**：变限积分函数把积分转化为函数，连续性和求导由微积分基本定理控制。

- **核心知识点5**：反常积分先写极限，再讨论收敛；无穷区间与瑕点必须分开处理。

### 核心公式与使用边界

- **公式1**：$\frac{d}{dx}\int_a^{g(x)}f(t)dt=f(g(x))g^{\prime}(x)$。

- **公式2**：$\int_a^b f(x)dx=F(b)-F(a)$。

- **公式3**：$\int_1^\infty x^{-p}dx$ 在 $p>1$ 时收敛。

### 📌 强化核心：输入题目关键词 $\to$ 输出秒杀方法

| 题目表面信号 / 关键词 | 对应解题突破口 / 判定方法 |
| :--- | :--- |
| 积分上限含 $x$ | 先看上下限，再用链式法则求导。 |
| 判断变限积分奇偶性 | 代入 $-x$，换元并利用原函数奇偶性。 |
| 反常积分收敛性 | 找无穷端或瑕点，分段后做比较。 |
| 积分号内函数只知连续 | 优先用保号、比较和中值定理。 |

### 核心题型与解法

#### 题型模型一：变限积分求导模型

- **核心方法**：【核心解题模型与思维框架】

  1. **第1步**：先把变限积分写成 $F(x)=\int_{u(x)}^{v(x)}f(t)\,dt$，积分变量必须使用与外部自变量不同的字母，避免把 $x$ 同时当作积分变量。

  2. **第2步**：分别处理上下限：上限贡献 $f(v(x))v^{\prime}(x)$，下限贡献 $-f(u(x))u^{\prime}(x)$。若被积函数还显含 $x$，还要增加对参数求偏导后的积分项。

  3. **第3步**：复合函数套在积分外面时继续使用链式法则，例如 $[\int_0^{g(x)}f(t)dt]^2$ 要先求外层平方，再求变限积分。

  4. **第4步**：求完后用常上限或常下限特例检查符号；尤其下限含 $x$ 时最容易漏掉负号。

- **典型例示**：【一题反应一类】

  **题目**：设 $F(x)=\int_0^{x^2}\sin t\,dt$，求 $F^{\prime}(x)$。

  **完整解答**：

  1. 识别为变上限积分，外层上限是 $g(x)=x^2$。

  2. 由基本定理，先把被积函数代入上限得到 $\sin(x^2)$。

  3. 再乘上限导数 $2x$，所以 $F^{\prime}(x)=2x\sin(x^2)$。

  4. 复核：不能把积分变量 $t$ 与外部变量 $x$ 混为一谈。

- **书目出处**：《基础30讲》第8讲（约第195-229页）；《1000题数二》第8章相关题型。

#### 题型模型二：反常积分判敛模型

- **核心方法**：【核心解题模型与思维框架】

  1. **第1步**：先找反常点：无穷区间端点、被积函数无界点都要单独处理。若区间内有多个瑕点，必须拆成多个反常积分。

  2. **第2步**：把每个反常积分写成普通定积分的极限，例如 $\int_a^{\infty}f=\lim_{b\to\infty}\int_a^bf$。不能直接把无穷代入原函数。

  3. **第3步**：分别判断每个极限是否为有限数。只有所有部分都收敛，原反常积分才收敛；任何一部分发散都会导致整体发散。

  4. **第4步**：无法直接积分时使用比较判别：在无穷远与 $1/x^p$ 比较，在瑕点附近与 $1/(x-a)^p$ 比较，并写清 $p$ 的收敛条件。

- **典型例示**：【一题反应一类】

  **题目**：判断并计算 $\int_1^{\infty}\frac1{x^2}\,dx$。

  **完整解答**：

  1. 先写成极限 $\lim_{b\to\infty}\int_1^b x^{-2}dx$。

  2. 原函数为 $-1/x$。

  3. 代入得 $\lim_{b\to\infty}(1-1/b)=1$。

  4. 积分收敛，值为 $1$。

- **书目出处**：《基础30讲》第8讲（约第195-229页）；《1000题数二》第8章相关题型。

#### 题型模型三：积分性质模型

- **核心方法**：【核心解题模型与思维框架】

  1. **第1步**：使用保序性前先确认两个函数在整个积分区间上逐点满足大小关系，而不是只比较端点或平均值。

  2. **第2步**：对不等式各项在相同区间积分，积分方向保持不变；若乘了可能为负的函数，必须先处理其符号。

  3. **第3步**：估值时可先找 $m\le f(x)\le M$，得到 $m(b-a)\le\int_a^bf\le M(b-a)$；这给出最基本的上下界。

  4. **第4步**：涉及绝对值时使用 $|\int f|\le\int|f|$。等号条件需要考察函数是否几乎处处同号，不能机械认为总能取等。

- **典型例示**：【一题反应一类】

  **题目**：已知 $1\le f(x)\le3$（$0\le x\le2$），估计 $\int_0^2f(x)\,dx$。

  **完整解答**：

  1. 定积分具有保序性，对不等式 $1\le f(x)\le3$ 在 $[0,2]$ 上逐项积分。

  2. 得到 $\int_0^2 1\,dx\le\int_0^2f(x)\,dx\le\int_0^2 3\,dx$。

  3. 左右两端分别为 $2$ 和 $6$。

  4. 所以 $2\le\int_0^2f(x)\,dx\le6$。

- **书目出处**：《基础30讲》第8讲（约第195-229页）；《1000题数二》第8章相关题型。

### 易错点与纠正

- **易错点1**：不定积分漏写 $+C$。

- **易错点2**：变限积分求导漏乘上限导数。

- **易错点3**：反常积分不写极限就直接代上下限。

- **易错点4**：含多个瑕点却只检查一个。
