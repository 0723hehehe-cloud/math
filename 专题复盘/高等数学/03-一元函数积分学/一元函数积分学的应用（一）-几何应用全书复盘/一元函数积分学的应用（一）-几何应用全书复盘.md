# 一元函数积分学的应用（一）-几何应用全书复盘 总结复盘

### 涉及知识点

- **核心知识点1**：平面图形面积的本质是“上减下”或“右减左”，交点决定分段。

- **核心知识点2**：旋转体体积按垫片法或柱壳法选择，旋转轴位置影响半径。

- **核心知识点3**：弧长公式来自微元勾股，直角坐标、参数方程和极坐标形式不同。

- **核心知识点4**：已知截面积求体积时直接积分截面积函数。

- **核心知识点5**：无界区域面积与体积必须作为反常积分判断收敛。

### 核心公式与使用边界

- **公式1**：$A=\int_a^b|f(x)-g(x)|dx$。

- **公式2**：$V=\pi\int_a^b(R^2-r^2)dx$，柱壳法 $V=2\pi\int (半径)(高)\,dx$。

- **公式3**：$L=\int_a^b\sqrt{1+[y^{\prime}(x)]^2}\,dx$。

### 📌 强化核心：输入题目关键词 $\to$ 输出秒杀方法

| 题目表面信号 / 关键词 | 对应解题突破口 / 判定方法 |
| :--- | :--- |
| 两曲线围成面积 | 先求交点，画草图，再决定上减下或右减左。 |
| 绕非坐标轴旋转 | 半径写成到旋转轴的距离。 |
| 参数曲线求弧长 | 用 $\int\sqrt{(x^{\prime})^2+(y^{\prime})^2}\,dt$。 |
| 区域无界但问面积 | 写反常积分并先判敛。 |

### 核心题型与解法

#### 题型模型一：面积模型

- **核心方法**：【核心解题模型与思维框架】

  1. **第1步**：先求曲线交点并画出区域，确定在每个横坐标区间内谁是上方函数、谁是下方函数。上下关系改变时必须按交点分段。

  2. **第2步**：竖条法面积微元为 $dA=[y_{上}(x)-y_{下}(x)]dx$；若横条表示更简单，可改用 $dA=[x_{右}(y)-x_{左}(y)]dy$。

  3. **第3步**：在正确投影区间上积分，并保证被积函数非负。若直接积分两曲线之差出现负值，说明上下顺序或分段有误。

  4. **第4步**：计算后用外接矩形面积估计数量级，结果应为非负且不超过明显的几何上界。

- **典型例示**：【一题反应一类】

  **题目**：求曲线 $y=x$ 与 $y=x^2$ 在 $[0,1]$ 围成的面积。

  **完整解答**：

  1. 求交点 $x=x^2$，得到 $x=0,1$。

  2. 在 $(0,1)$ 上有 $x>x^2$，高度为 $x-x^2$。

  3. 面积 $A=\int_0^1(x-x^2)dx=\left[\frac{x^2}{2}-\frac{x^3}{3}\right]_0^1$。

  4. 结果 $A=\frac16$，为正且小于外接矩形面积，数量级合理。

- **书目出处**：《基础30讲》第10讲（约第263-281页）；《1000题数二》第10章相关题型。

#### 题型模型二：旋转体模型

- **核心方法**：【核心解题模型与思维框架】

  1. **第1步**：先确定旋转轴和切片方向。切片垂直于旋转轴时用圆盘或垫片法，平行于旋转轴时可考虑圆柱壳法。

  2. **第2步**：垫片法写 $dV=\pi(R^2-r^2)dx$，外半径 $R$ 与内半径 $r$ 都是到旋转轴的距离，不能直接拿函数值而忽略轴的平移。

  3. **第3步**：壳层法写 $dV=2\pi\times半径\times高度\,dx$，半径同样是切片到旋转轴的距离。选择积分变量时以边界表达最简单为准。

  4. **第4步**：检查体积单位和量级；半径必须平方，而壳层法的高度不能与半径混淆。

- **典型例示**：【一题反应一类】

  **题目**：求 $y=\sqrt{x}$、$0\le x\le1$ 与 $x$ 轴围成区域绕 $x$ 轴旋转的体积。

  **完整解答**：

  1. 使用垫片法，半径为 $R(x)=\sqrt{x}$。

  2. 体积 $V=\pi\int_0^1R^2(x)dx=\pi\int_0^1x\,dx$。

  3. 积分得到 $V=\pi/2$。

  4. 检查点：体积公式中半径需要平方。

- **书目出处**：《基础30讲》第10讲（约第263-281页）；《1000题数二》第10章相关题型。

#### 题型模型三：弧长模型

- **核心方法**：【核心解题模型与思维框架】

  1. **第1步**：先确认曲线能否写成 $y=f(x)$、$x=g(y)$ 或参数方程。选择能使导数和积分限最简单的表示。

  2. **第2步**：直角坐标下弧长微元为 $ds=\sqrt{1+[f^{\prime}(x)]^2}\,dx$；参数方程则为 $ds=\sqrt{(x^{\prime})^2+(y^{\prime})^2}\,dt$。

  3. **第3步**：把端点转换为所选变量的上下限，再计算积分。根式常需配方、三角换元或识别完全平方。

  4. **第4步**：弧长至少不小于两端点直线距离；若结果更小，通常是导数、上下限或根式化简出错。

- **典型例示**：【一题反应一类】

  **题目**：求曲线 $y=\frac23x^{3/2}$ 在 $[0,1]$ 上的弧长。

  **完整解答**：

  1. $y^{\prime}=\sqrt{x}$。

  2. 弧长 $L=\int_0^1\sqrt{1+x}\,dx$。

  3. 积分得 $\frac23(1+x)^{3/2}\big|_0^1$。

  4. 结果为 $\frac23(2\sqrt2-1)$。

- **书目出处**：《基础30讲》第10讲（约第263-281页）；《1000题数二》第10章相关题型。

### 易错点与纠正

- **易错点1**：未画图就判断上下函数。

- **易错点2**：绕平移轴旋转仍把 $x$ 或 $y$ 直接当半径。

- **易错点3**：面积积分忘记绝对值或分段。

- **易错点4**：无界区域直接代入无穷。
