# 一元函数积分学的应用（一）-几何应用全书复盘 总结复盘

### 涉及知识点

- **核心知识点1**：平面图形面积的本质是“上减下”或“右减左”，交点决定分段。

- **核心知识点2**：旋转体体积按垫片法或柱壳法选择，旋转轴位置影响半径。

- **核心知识点3**：弧长公式来自微元勾股，直角坐标、参数方程和极坐标形式不同。

- **核心知识点4**：已知截面积求体积时直接积分截面积函数。

- **核心知识点5**：无界区域面积与体积必须作为反常积分判断收敛。

### 核心公式与使用边界

- **公式1**：$A=\int_a^b|f(x)-g(x)|dx$。

- **公式2**：$V=\pi\int_a^b(R^2-r^2)dx$，柱壳法 $V=2\pi\int (半径)(高)\,dx$。

- **公式3**：$L=\int_a^b\sqrt{1+[y^{\prime}(x)]^2}\,dx$。

### 📌 强化核心：输入题目关键词 $\to$ 输出秒杀方法

| 题目表面信号 / 关键词 | 对应解题突破口 / 判定方法 |
| :--- | :--- |
| 两曲线围成面积 | 先求交点，画草图，再决定上减下或右减左。 |
| 绕非坐标轴旋转 | 半径写成到旋转轴的距离。 |
| 参数曲线求弧长 | 用 $\int\sqrt{(x^{\prime})^2+(y^{\prime})^2}\,dt$。 |
| 区域无界但问面积 | 写反常积分并先判敛。 |

### 核心题型与解法

#### 题型模型一：面积模型

- **核心方法**：【核心解题模型与思维框架】

  1. **步骤1**：画图；

  2. **步骤2**：求交点；

  3. **步骤3**：选积分方向；

  4. **步骤4**：分段；

  5. **步骤5**：积分；

  **关键提醒**：绝对值代表几何高度，不能随意去掉。

- **典型例示**：【一题反应一类】

  **题目**：求曲线 $y=x$ 与 $y=x^2$ 在 $[0,1]$ 围成的面积。

  **完整解答**：

  1. 求交点 $x=x^2$，得到 $x=0,1$。

  2. 在 $(0,1)$ 上有 $x>x^2$，高度为 $x-x^2$。

  3. 面积 $A=\int_0^1(x-x^2)dx=\left[\frac{x^2}{2}-\frac{x^3}{3}\right]_0^1$。

  4. 结果 $A=\frac16$，为正且小于外接矩形面积，数量级合理。

- **书目出处**：《基础30讲》第10讲（约第263-281页）；《1000题数二》第10章相关题型。

#### 题型模型二：旋转体模型

- **核心方法**：【核心解题模型与思维框架】

  1. **步骤1**：确定旋转轴；

  2. **步骤2**：选垫片或柱壳；

  3. **步骤3**：写半径和高度；

  4. **步骤4**：积分；

  **关键提醒**：内外半径必须非负。

- **典型例示**：【一题反应一类】

  **题目**：求 $y=\sqrt{x}$、$0\le x\le1$ 与 $x$ 轴围成区域绕 $x$ 轴旋转的体积。

  **完整解答**：

  1. 使用垫片法，半径为 $R(x)=\sqrt{x}$。

  2. 体积 $V=\pi\int_0^1R^2(x)dx=\pi\int_0^1x\,dx$。

  3. 积分得到 $V=\pi/2$。

  4. 检查点：体积公式中半径需要平方。

- **书目出处**：《基础30讲》第10讲（约第263-281页）；《1000题数二》第10章相关题型。

#### 题型模型三：弧长模型

- **核心方法**：【核心解题模型与思维框架】

  1. **步骤1**：选参数；

  2. **步骤2**：写微元；

  3. **步骤3**：确定区间；

  4. **步骤4**：积分；

  **关键提醒**：先化简根式再积分。

- **典型例示**：【一题反应一类】

  **题目**：求曲线 $y=\frac23x^{3/2}$ 在 $[0,1]$ 上的弧长。

  **完整解答**：

  1. $y^{\prime}=\sqrt{x}$。

  2. 弧长 $L=\int_0^1\sqrt{1+x}\,dx$。

  3. 积分得 $\frac23(1+x)^{3/2}\big|_0^1$。

  4. 结果为 $\frac23(2\sqrt2-1)$。

- **书目出处**：《基础30讲》第10讲（约第263-281页）；《1000题数二》第10章相关题型。

### 易错点与纠正

- **易错点1**：未画图就判断上下函数。

- **易错点2**：绕平移轴旋转仍把 $x$ 或 $y$ 直接当半径。

- **易错点3**：面积积分忘记绝对值或分段。

- **易错点4**：无界区域直接代入无穷。
