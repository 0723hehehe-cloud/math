# 一元函数积分学的应用（二）-积分等式与积分不等式全书复盘 总结复盘

### 涉及知识点

- **核心知识点1**：积分等式常由换元对称、分部积分或构造变限积分函数得到。

- **核心知识点2**：积分不等式优先利用被积函数点态比较、保号性和积分中值定理。

- **核心知识点3**：含 $f^{\prime}$ 与积分时可用分部积分把导数转移。

- **核心知识点4**：证明存在积分中值点要验证连续性，并明确 $\xi\in(a,b)$。

- **核心知识点5**：复杂不等式可构造参数积分或差函数，求导后转化为单调性。

### 核心公式与使用边界

- **公式1**：$m(b-a)\le\int_a^b f(x)dx\le M(b-a)$。

- **公式2**：$\left(\int_a^b fg\right)^2\le\int_a^b f^2\int_a^b g^2$。

- **公式3**：$\int_a^b f(x)dx=(b-a)f(\xi)$。

### 📌 强化核心：输入题目关键词 $\to$ 输出秒杀方法

| 题目表面信号 / 关键词 | 对应解题突破口 / 判定方法 |
| :--- | :--- |
| 区间关于中点对称 | 做 $x\mapsto a+b-x$ 并与原式相加。 |
| 积分中含 $f^{\prime}$ | 尝试分部积分或构造 $F(x)=\int f$。 |
| 证明积分上下界 | 先做点态放缩，再在区间积分。 |
| 存在 $\xi$ 使积分等于函数值 | 使用积分中值定理或 Rolle 定理。 |

### 核心题型与解法

#### 题型模型一：换元配对模型

- **核心方法**：【核心解题模型与思维框架】

  1. **步骤1**：写原积分；

  2. **步骤2**：中心换元；

  3. **步骤3**：两式相加；

  4. **步骤4**：化简；

  **关键提醒**：区间端点变换要准确。

- **典型例示**：【一题反应一类】

  **题目**：计算 $I=\int_0^{\pi}x\sin x\,dx$，要求使用对称换元。

  **完整解答**：

  1. 作换元 $x\mapsto\pi-x$，得到 $I=\int_0^{\pi}(\pi-x)\sin x\,dx$。

  2. 两式相加：$2I=\pi\int_0^{\pi}\sin x\,dx$。

  3. 右侧为 $2\pi$。

  4. 所以 $I=\pi$。

- **书目出处**：《基础30讲》第11讲（约第282-293页）；《1000题数二》第11章相关题型。

#### 题型模型二：点态放缩模型

- **核心方法**：【核心解题模型与思维框架】

  1. **步骤1**：确定函数范围；

  2. **步骤2**：建立逐点不等式；

  3. **步骤3**：积分；

  4. **步骤4**：写等号条件；

  **关键提醒**：积分保序需要可积性。

- **典型例示**：【一题反应一类】

  **题目**：估计 $\int_0^1e^x\,dx$ 的上下界。

  **完整解答**：

  1. 在 $[0,1]$ 上有 $1\le e^x\le e$。

  2. 利用积分保序性在区间上积分。

  3. 得到 $1\le\int_0^1e^x dx\le e$。

  4. 实际值 $e-1$ 落在该区间内，验证估计合理。

- **书目出处**：《基础30讲》第11讲（约第282-293页）；《1000题数二》第11章相关题型。

#### 题型模型三：变限积分辅助函数模型

- **核心方法**：【核心解题模型与思维框架】

  1. **步骤1**：把目标差写成 $F(x)$；

  2. **步骤2**：求导；

  3. **步骤3**：判符号或用 Rolle；

  **关键提醒**：端点值常是构造依据。

- **典型例示**：【一题反应一类】

  **题目**：设 $F(x)=\int_0^x(t-x)f(t)\,dt$，求 $F^{\prime}(x)$。

  **完整解答**：

  1. 被积函数与上限都含 $x$，使用 Leibniz 求导法则。

  2. 上限项为 $(x-x)f(x)\cdot1=0$。

  3. 积分内部对 $x$ 求偏导：$\frac{\partial}{\partial x}[(t-x)f(t)]=-f(t)$。

  4. 所以 $F^{\prime}(x)=-\int_0^xf(t)\,dt$。

- **书目出处**：《基础30讲》第11讲（约第282-293页）；《1000题数二》第11章相关题型。

### 易错点与纠正

- **易错点1**：点态不等式方向随分母符号改变却未检查。

- **易错点2**：积分中值定理遗漏连续条件。

- **易错点3**：换元后上下限与负号同时出错。

- **易错点4**：只证明不等式，遗漏等号成立条件。
