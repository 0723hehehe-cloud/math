# 一元函数微分学的应用（三）-物理与经济应用全书复盘 总结复盘

### 涉及知识点

- **核心知识点1**：相关变化率题先建立变量关系，再对时间求导，最后代入时刻数据。

- **核心知识点2**：最优化问题要先建立目标函数和可行区间，再比较驻点与端点。

- **核心知识点3**：边际量是总量函数的导数，弹性描述相对变化率。

- **核心知识点4**：线性近似与微分可快速估算测量误差和函数增量。

- **核心知识点5**：物理量单位是检查模型是否正确的重要手段。

### 核心公式与使用边界

- **公式1**：$dy\approx f^{\prime}(x_0)dx$。

- **公式2**：边际成本 $C^{\prime}(q)$，边际收益 $R^{\prime}(q)$。

- **公式3**：弹性 $E(x)=\frac{x}{f(x)}f^{\prime}(x)$。

### 📌 强化核心：输入题目关键词 $\to$ 输出秒杀方法

| 题目表面信号 / 关键词 | 对应解题突破口 / 判定方法 |
| :--- | :--- |
| 半径、高度、体积随时间变化 | 先写几何关系，再整体对 $t$ 求导。 |
| 最大利润或最小成本 | 利润 $P=R-C$，求驻点并比较边界。 |
| 给出测量误差 | 用微分估计绝对误差与相对误差。 |
| 边际或弹性 | 先确认总量函数，再求导并代入产量。 |

### 核心题型与解法

#### 题型模型一：相关变化率模型

- **核心方法**：【核心解题模型与思维框架】

  1. **步骤1**：画图设变量；

  2. **步骤2**：写约束；

  3. **步骤3**：对时间求导；

  4. **步骤4**：代时刻；

  **关键提醒**：不要提前代入常数变量。

- **典型例示**：【一题反应一类】

  **题目**：球半径以 $2\,\mathrm{cm/s}$ 增长，半径为 $3\,\mathrm{cm}$ 时体积变化率是多少？

  **完整解答**：

  1. 球体积 $V=\frac43\pi r^3$，其中 $r=r(t)$。

  2. 对时间求导：$\frac{dV}{dt}=4\pi r^2\frac{dr}{dt}$。

  3. 代入 $r=3$、$dr/dt=2$，得 $dV/dt=72\pi\,\mathrm{cm^3/s}$。

  4. 量纲检查：面积乘速度得到体积每时间，单位正确。

- **书目出处**：《基础30讲》第7讲（第8讲前）；《1000题数二》第7章相关题型。

#### 题型模型二：实际最优化模型

- **核心方法**：【核心解题模型与思维框架】

  1. **步骤1**：设自变量；

  2. **步骤2**：建目标函数；

  3. **步骤3**：定义域；

  4. **步骤4**：求极值；

  5. **步骤5**：解释单位；

  **关键提醒**：数学极值必须满足实际约束。

- **典型例示**：【一题反应一类】

  **题目**：周长为 $P$ 的矩形何时面积最大？

  **完整解答**：

  1. 设一边为 $x$，另一边为 $P/2-x$，定义域 $0<x<P/2$。

  2. 面积 $A(x)=x(P/2-x)$。

  3. $A^{\prime}(x)=P/2-2x=0$，得 $x=P/4$。

  4. 两边相等时面积最大，最大值为 $P^2/16$。

- **书目出处**：《基础30讲》第7讲（第8讲前）；《1000题数二》第7章相关题型。

#### 题型模型三：微分误差模型

- **核心方法**：【核心解题模型与思维框架】

  1. **步骤1**：写 $dy$；

  2. **步骤2**：代误差上界；

  3. **步骤3**：求相对误差；

  **关键提醒**：区分 $\Delta y$ 与 $dy$。

- **典型例示**：【一题反应一类】

  **题目**：球半径测得为 $10\,\mathrm{cm}$，测量误差不超过 $0.02\,\mathrm{cm}$，估计体积的最大绝对误差。

  **完整解答**：

  1. 球体积 $V=\frac43\pi r^3$，微分为 $dV=4\pi r^2dr$。

  2. 用微分近似增量：$|\Delta V|\approx|dV|=4\pi r^2|dr|$。

  3. 代入 $r=10$、$|dr|\le0.02$，得 $|dV|\le4\pi\times100\times0.02$。

  4. 最大绝对误差约为 $8\pi\,\mathrm{cm^3}$。

- **书目出处**：《基础30讲》第7讲（第8讲前）；《1000题数二》第7章相关题型。

### 易错点与纠正

- **易错点1**：建立关系后先代数值，导致变化变量被当成常数。

- **易错点2**：只求驻点不比较端点。

- **易错点3**：遗漏单位或把相对误差写成绝对误差。

- **易错点4**：边际量与平均量混淆。
