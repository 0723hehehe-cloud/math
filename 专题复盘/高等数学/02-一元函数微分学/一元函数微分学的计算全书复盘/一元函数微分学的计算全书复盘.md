# 一元函数微分学的计算全书复盘 总结复盘

### 涉及知识点

- **核心知识点1**：复合函数求导遵循链式法则，先画变量层级再逐层相乘。

- **核心知识点2**：隐函数优先直接求导；含幂指、连乘或复杂根式时先取对数。

- **核心知识点3**：参数方程求导用 $\frac{dy}{dx}=\frac{dy/dt}{dx/dt}$，二阶导数还要再除一次 $dx/dt$。

- **核心知识点4**：高阶导数重点掌握指数、三角、幂函数、乘积以及奇偶性降维。

- **核心知识点5**：分段与绝对值复合函数的高阶导数要先分区间化简。

### 核心公式与使用边界

- **公式1**：$(uv)^{(n)}=\sum_{k=0}^n\binom nk u^{(k)}v^{(n-k)}$。

- **公式2**：$\frac{d^2y}{dx^2}=\frac{d}{dt}(dy/dx)\big/\frac{dx}{dt}$。

- **公式3**：$y=x^x\Rightarrow y^{\prime}=x^x(\ln x+1)$。

### 📌 强化核心：输入题目关键词 $\to$ 输出秒杀方法

| 题目表面信号 / 关键词 | 对应解题突破口 / 判定方法 |
| :--- | :--- |
| 多层复合函数 | 画变量树，沿路径相乘，不同路径相加。 |
| 未知函数同时出现在方程两侧 | 隐式求导，并把含 $y^{\prime}$ 的项集中。 |
| 求 $n$ 阶导数 | 找周期、用莱布尼茨公式或先做级数展开。 |
| 参数方程求二阶导 | 先求 $dy/dx$，再对参数求导并除以 $dx/dt$。 |

### 核心题型与解法

#### 题型模型一：链式树模型

- **核心方法**：【核心解题模型与思维框架】

  1. **第1步**：先画变量依赖关系：最外层函数依赖哪些中间变量，每个中间变量又依赖哪个自变量。求导时沿每条路径逐层相乘，多条路径最后相加。

  2. **第2步**：对幂指函数 $u(x)^{v(x)}$，只要底数为正，优先取对数：$\ln y=v\ln u$，再隐式求导。这样能同时处理底数和指数都变化的情况。

  3. **第3步**：复合层数较多时每求一层就保留该层自变量，例如 $f^{\prime}(g(x))g^{\prime}(x)$，不要过早展开导致漏乘内层导数。

  4. **第4步**：求完后用简单特例检查：把中间函数换成 $x$ 或常数，公式应退化为熟悉的一元求导结果。

- **典型例示**：【一题反应一类】

  **题目**：求 $y=x^x$（$x>0$）的导数。

  **完整解答**：

  1. 幂和指数都含 $x$，先取对数：$\ln y=x\ln x$。

  2. 两边求导：$\frac{y^{\prime}}y=\ln x+1$。

  3. 乘回 $y=x^x$，得 $y^{\prime}=x^x(\ln x+1)$。

  4. 复核定义域 $x>0$，避免忽略取对数条件。

- **书目出处**：《基础30讲》第4讲（约第119-138页）；《1000题数二》第4章相关题型。

#### 题型模型二：隐函数求导模型

- **核心方法**：【核心解题模型与思维框架】

  1. **第1步**：把隐式方程统一写成 $F(x,y)=0$，先确认目标点满足原方程，并在局部满足 $F_y\ne0$，这样才能把 $y$ 看作 $x$ 的函数。

  2. **第2步**：对方程两边关于 $x$ 求导。凡是含 $y$ 的项都要乘 $y^{\prime}$，例如 $(y^2)^{\prime}=2yy^{\prime}$。

  3. **第3步**：把所有含 $y^{\prime}$ 的项移到一侧并提取，得到 $y^{\prime}=-F_x/F_y$。需要二阶导数时，应对这个关系再次求导，而不是把 $y$ 当常数。

  4. **第4步**：最后检查分母是否为零。若 $F_y=0$，当前公式失效，曲线可能存在竖直切线，应改求 $dx/dy$ 或回到参数表示。

- **典型例示**：【一题反应一类】

  **题目**：由 $x^2+y^2=1$ 求 $dy/dx$。

  **完整解答**：

  1. 对方程两边关于 $x$ 求导。

  2. 得到 $2x+2y y^{\prime}=0$。

  3. 解出 $y^{\prime}=-x/y$。

  4. 检查点：公式仅适用于 $y\ne0$ 的局部隐函数分支。

- **书目出处**：《基础30讲》第4讲（约第119-138页）；《1000题数二》第4章相关题型。

#### 题型模型三：高阶导数模型

- **核心方法**：【核心解题模型与思维框架】

  1. **第1步**：低阶导数先直接计算两三次，观察系数、符号和函数类型是否呈周期或递推规律，再写 $n$ 阶猜想。

  2. **第2步**：乘积的高阶导数使用 Leibniz 公式 $ (uv)^{(n)}=\sum_{k=0}^n\binom nk u^{(k)}v^{(n-k)}$；不要逐次展开造成项数失控。

  3. **第3步**：指数乘三角函数可写成复指数或建立二阶递推；有理函数可先拆成 $(x-a)^{-m}$，再按幂函数公式求高阶导。

  4. **第4步**：用 $n=0,1,2$ 代回通项检查初始几阶，特别检查组合数、相位和 $(-1)^n$ 的符号。

- **典型例示**：【一题反应一类】

  **题目**：求 $f(x)=e^x\sin x$ 的二阶导数。

  **完整解答**：

  1. 先用乘积法则：$f^{\prime}(x)=e^x\sin x+e^x\cos x=e^x(\sin x+\cos x)$。

  2. 再次求导时仍用乘积法则。

  3. 得到 $f^{\prime\prime}(x)=e^x(\sin x+\cos x)+e^x(\cos x-\sin x)$。

  4. 合并同类项，$f^{\prime\prime}(x)=2e^x\cos x$。

- **书目出处**：《基础30讲》第4讲（约第119-138页）；《1000题数二》第4章相关题型。

### 易错点与纠正

- **易错点1**：链式法则漏乘内层导数。

- **易错点2**：参数方程二阶导只对 $t$ 求一次导。

- **易错点3**：隐函数代点过早导致结构丢失。

- **易错点4**：高阶导数阶数与组合数下标错位。
