# 一元函数微分学的应用（一）-几何应用全书复盘 总结复盘

### 涉及知识点

- **核心知识点1**：用一阶导数研究单调区间与极值，用二阶导数研究凹凸性与拐点。

- **核心知识点2**：驻点只是极值候选点；不可导点和区间端点也必须检查。

- **核心知识点3**：拐点是曲线上的点，要求函数连续且凹凸性发生改变，不等同于 $f^{\prime\prime}(x)=0$。

- **核心知识点4**：曲线作图顺序：定义域、奇偶周期、交点、渐近线、单调极值、凹凸拐点。

- **核心知识点5**：曲率与曲率圆需要同时求 $y^{\prime}$、$y^{\prime\prime}$ 并根据凹向确定圆心方向。

### 核心公式与使用边界

- **公式1**：$K=\frac{|y^{\prime\prime}|}{[1+(y^{\prime})^2]^{3/2}}$，曲率半径 $\rho=1/K$。

- **公式2**：$f^{\prime}$ 变号：$+\to-$ 为极大，$-\to+$ 为极小。

- **公式3**：$f^{\prime\prime}$ 变号才可确认拐点。

### 📌 强化核心：输入题目关键词 $\to$ 输出秒杀方法

| 题目表面信号 / 关键词 | 对应解题突破口 / 判定方法 |
| :--- | :--- |
| 求单调区间或极值 | 找定义域与临界点，画一阶导数符号表。 |
| 求拐点 | 找二阶导为零或不存在的点，再检验左右凹凸。 |
| 求渐近线并作图 | 先处理定义域边界，再检查无穷远。 |
| 求曲率圆 | 算曲率半径，再沿单位法向量确定圆心。 |

### 核心题型与解法

#### 题型模型一：导数符号表模型

- **核心方法**：【核心解题模型与思维框架】

  1. **第1步**：先求定义域和一阶导数，把 $f^{\prime}(x)=0$ 的点、导数不存在的点以及定义域断点按从小到大排列，它们共同切分讨论区间。

  2. **第2步**：在每个区间选一个测试点判断 $f^{\prime}$ 的符号，画出“$+$ / $-$”符号表。正号区间单调增加，负号区间单调减少。

  3. **第3步**：导数由正变负得到极大值点，由负变正得到极小值点；若不变号，即使 $f^{\prime}=0$ 也不是极值点。

  4. **第4步**：把候选点函数值代回，并结合端点值比较。闭区间最值必须同时比较内部极值点和两个端点，不能只看驻点。

- **典型例示**：【一题反应一类】

  **题目**：研究 $f(x)=x^3-3x$ 的单调性、极值和拐点。

  **完整解答**：

  1. 一阶导数 $f^{\prime}(x)=3(x^2-1)$，临界点为 $x=\pm1$。

  2. 按 $(-\infty,-1),(-1,1),(1,\infty)$ 画符号表，得到增、减、增。

  3. $x=-1$ 为极大值点，$x=1$ 为极小值点。

  4. 二阶导数 $f^{\prime\prime}(x)=6x$ 在 $0$ 两侧变号，所以 $(0,0)$ 是拐点。

- **书目出处**：《基础30讲》第5讲（约第139-163页）；《1000题数二》第5章相关题型。

#### 题型模型二：拐点模型

- **核心方法**：【核心解题模型与思维框架】

  1. **第1步**：先求 $f^{\prime\prime}(x)$，把二阶导数为零或不存在的点列为候选分界点。$f^{\prime\prime}(x_0)=0$ 本身不是拐点的充分条件。

  2. **第2步**：判断候选点左右两侧 $f^{\prime\prime}$ 的符号。符号发生改变才表示曲线凹凸性改变，候选点才可能成为拐点。

  3. **第3步**：还要检查函数在该点连续，并写出拐点坐标 $(x_0,f(x_0))$。如果函数在该点没有定义，只能说凹凸区间在此分开，不能称为曲线拐点。

  4. **第4步**：若二阶导数难判断，可研究 $f^{\prime}$ 的单调性：一阶导数由增转减或由减转增，同样反映凹凸性的变化。

- **典型例示**：【一题反应一类】

  **题目**：判断曲线 $y=x^3$ 的凹凸区间与拐点。

  **完整解答**：

  1. $y^{\prime}=3x^2$，$y^{\prime\prime}=6x$。

  2. 当 $x<0$ 时 $y^{\prime\prime}<0$；当 $x>0$ 时 $y^{\prime\prime}>0$，凹凸性在 $x=0$ 两侧改变。

  3. $y^{\prime\prime}(0)=0$ 只给出候选点，真正依据是二阶导数变号。

  4. 所以 $(0,0)$ 是拐点，两侧分别属于不同凹凸区间。

- **书目出处**：《基础30讲》第5讲（约第139-163页）；《1000题数二》第5章相关题型。

#### 题型模型三：曲线综合作图模型

- **核心方法**：【核心解题模型与思维框架】

  1. **第1步**：作图前依次确定定义域、奇偶性、周期性和与坐标轴交点，这些信息先固定图形的整体范围与对称关系。

  2. **第2步**：用一阶导数确定单调区间和极值，用二阶导数确定凹凸区间和拐点；把所有关键横坐标放在同一张分区表中。

  3. **第3步**：计算定义域边界和无穷远处的极限，补齐垂直、水平或斜渐近线。渐近线两侧的趋向必须分开判断。

  4. **第4步**：最后按“截距—极值—拐点—渐近线”的顺序连线，并用若干测试点检查分支位置，不能仅凭函数表达式想象图形。

- **典型例示**：【一题反应一类】

  **题目**：求 $f(x)=\frac{x^2+1}{x-1}$ 的渐近线。

  **完整解答**：

  1. 定义域缺口 $x=1$ 附近函数趋于无穷，因此 $x=1$ 是垂直渐近线。

  2. 多项式除法：$f(x)=x+1+\frac{2}{x-1}$。

  3. 当 $x\to\pm\infty$，余项趋于 $0$。

  4. 斜渐近线为 $y=x+1$。

- **书目出处**：《基础30讲》第5讲（约第139-163页）；《1000题数二》第5章相关题型。

### 易错点与纠正

- **易错点1**：把所有驻点都判为极值点。

- **易错点2**：把 $f^{\prime\prime}(x_0)=0$ 直接判为拐点。

- **易错点3**：忽略定义域断点导致区间写错。

- **易错点4**：曲率公式漏绝对值或分母指数。
