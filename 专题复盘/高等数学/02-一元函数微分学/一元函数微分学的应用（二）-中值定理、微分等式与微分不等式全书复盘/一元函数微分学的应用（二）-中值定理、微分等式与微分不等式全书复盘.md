# 一元函数微分学的应用（二）-中值定理、微分等式与微分不等式全书复盘 总结复盘

### 涉及知识点

- **核心知识点1**：Rolle、Lagrange、Cauchy 三个中值定理的使用核心是区间条件与辅助函数。

- **核心知识点2**：证明“存在 $\xi$”时，从结论倒推导数形式，再构造满足端点条件的辅助函数。

- **核心知识点3**：含两个中间点时常分区间使用中值定理，或引入最大值、最小值。

- **核心知识点4**：微分不等式可通过单调性、Lagrange 中值定理、Taylor 展开或凸性证明。

- **核心知识点5**：Taylor 公式既用于极限，也用于局部估值与余项控制。

### 核心公式与使用边界

- **公式1**：$f(b)-f(a)=f^{\prime}(\xi)(b-a)$。

- **公式2**：$\frac{f(b)-f(a)}{g(b)-g(a)}=\frac{f^{\prime}(\xi)}{g^{\prime}(\xi)}$。

- **公式3**：$f(x)=\sum_{k=0}^n\frac{f^{(k)}(x_0)}{k!}(x-x_0)^k+R_n(x)$。

### 📌 强化核心：输入题目关键词 $\to$ 输出秒杀方法

| 题目表面信号 / 关键词 | 对应解题突破口 / 判定方法 |
| :--- | :--- |
| 证明至少存在一个 $\xi$ | 把目标式整理成某个辅助函数导数为零。 |
| 出现函数值差与导数 | 优先考虑 Lagrange 中值定理。 |
| 出现两个函数的增量比 | 尝试 Cauchy 中值定理。 |
| 证明局部不等式或估值 | 构造差函数判单调，或用 Taylor 控余项。 |

### 核心题型与解法

#### 题型模型一：辅助函数反推模型

- **核心方法**：【核心解题模型与思维框架】

  1. **步骤1**：整理目标式；

  2. **步骤2**：识别导数；

  3. **步骤3**：构造 $F$；

  4. **步骤4**：验证端点；

  5. **步骤5**：Rolle；

  **关键提醒**：先写条件再套定理。

- **典型例示**：【一题反应一类】

  **题目**：对 $f(x)=x^2-x$ 在 $[0,1]$ 使用 Rolle 定理并求中值点。

  **完整解答**：

  1. $f$ 在 $[0,1]$ 连续、在 $(0,1)$ 可导。

  2. $f(0)=f(1)=0$，满足 Rolle 端点条件。

  3. $f^{\prime}(x)=2x-1$，令其为零得 $\xi=1/2$。

  4. $\xi\in(0,1)$，定理条件与结论完整。

- **书目出处**：《基础30讲》第6讲（约第164页起）；《1000题数二》第6章相关题型。

#### 题型模型二：差函数单调模型

- **核心方法**：【核心解题模型与思维框架】

  1. **步骤1**：移项成 $F(x)$；

  2. **步骤2**：求导；

  3. **步骤3**：判符号；

  4. **步骤4**：比端点；

  **关键提醒**：定义域和等号条件要写。

- **典型例示**：【一题反应一类】

  **题目**：证明对任意 $x>0$，有 $\ln x\le x-1$。

  **完整解答**：

  1. 把不等式移项，设 $F(x)=x-1-\ln x$。

  2. 求导 $F^{\prime}(x)=1-\frac1x=\frac{x-1}{x}$。

  3. $F$ 在 $(0,1)$ 递减、在 $(1,\infty)$ 递增，因此 $x=1$ 取得最小值。

  4. $F(1)=0$，故 $F(x)\ge0$；等号仅在 $x=1$ 成立。

- **书目出处**：《基础30讲》第6讲（约第164页起）；《1000题数二》第6章相关题型。

#### 题型模型三：Taylor 估值模型

- **核心方法**：【核心解题模型与思维框架】

  1. **步骤1**：选展开点；

  2. **步骤2**：保留有效阶；

  3. **步骤3**：判断余项符号或界；

  **关键提醒**：展开阶数由抵消程度决定。

- **典型例示**：【一题反应一类】

  **题目**：用 Taylor 公式证明当 $x>0$ 时 $e^x>1+x$。

  **完整解答**：

  1. 在 $x_0=0$ 处对 $e^x$ 使用一阶 Taylor 公式并保留 Lagrange 余项。

  2. 存在 $\xi\in(0,x)$，使 $e^x=1+x+\frac{e^{\xi}}{2}x^2$。

  3. 因为 $e^{\xi}>0$ 且 $x^2>0$，余项严格为正。

  4. 因此 $e^x>1+x$；当 $x=0$ 时取等号。

- **书目出处**：《基础30讲》第6讲（约第164页起）；《1000题数二》第6章相关题型。

### 易错点与纠正

- **易错点1**：没有验证闭区间连续、开区间可导。

- **易错点2**：辅助函数凭空出现，无法对应目标式。

- **易错点3**：中值定理中的 $\xi$ 所属区间写错。

- **易错点4**：Taylor 展开阶数不足导致主项抵消。
