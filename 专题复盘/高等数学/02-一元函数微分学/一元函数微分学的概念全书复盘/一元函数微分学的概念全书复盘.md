# 一元函数微分学的概念全书复盘 总结复盘

### 涉及知识点

- **核心知识点1**：导数是差商极限，既表示瞬时变化率，也表示切线斜率。

- **核心知识点2**：可导必连续，连续不一定可导；尖点、角点、竖直切线与振荡点需要用定义判断。

- **核心知识点3**：分段函数在分界点可导必须左右导数存在且相等。

- **核心知识点4**：微分 $dy=f^{\prime}(x_0)\,dx$ 是函数增量的线性主部，可微与可导在一元函数中等价。

- **核心知识点5**：导数定义的变形题关键是把陌生差商还原成 $\frac{f(x_0+h)-f(x_0)}h$。

### 核心公式与使用边界

- **公式1**：$f^{\prime}(x_0)=\lim_{h\to0}\frac{f(x_0+h)-f(x_0)}h$。

- **公式2**：$\Delta y=f^{\prime}(x_0)\Delta x+o(\Delta x)$。

- **公式3**：$f^{\prime}_-(x_0)=f^{\prime}_+(x_0)$ 是分段点可导的充要条件。

### 📌 强化核心：输入题目关键词 $\to$ 输出秒杀方法

| 题目表面信号 / 关键词 | 对应解题突破口 / 判定方法 |
| :--- | :--- |
| 题目给出含 $f(x_0+ah)$ 的极限 | 提取倍数并凑成导数定义。 |
| 绝对值、分段或最大值函数 | 在分界点分别求左右导数。 |
| 问可导、连续之间关系 | 按“可导推出连续”单向逻辑判断。 |
| 求切线或法线 | 先确认点在曲线上，再由导数求斜率。 |

### 核心题型与解法

#### 题型模型一：导数定义还原模型

- **核心方法**：【核心解题模型与思维框架】

  1. **步骤1**：令增量为 $h$；

  2. **步骤2**：对齐函数值；

  3. **步骤3**：提取常数；

  4. **步骤4**：识别导数；

  **关键提醒**：分母和自变量增量必须同步。

- **典型例示**：【一题反应一类】

  **题目**：判断 $f(x)=|x|$ 在 $x=0$ 处是否可导。

  **完整解答**：

  1. 先验连续：$\lim_{x\to0}|x|=0=f(0)$。

  2. 左导数为 $\lim_{h\to0^-}\frac{|h|}{h}=-1$。

  3. 右导数为 $\lim_{h\to0^+}\frac{|h|}{h}=1$。

  4. 左右导数不相等，因此连续但不可导；几何上对应尖点。

- **书目出处**：《基础30讲》第3讲（约第99-118页）；《1000题数二》第3章相关题型。

#### 题型模型二：分段点可导模型

- **核心方法**：【核心解题模型与思维框架】

  1. **步骤1**：连续性；

  2. **步骤2**：左导数；

  3. **步骤3**：右导数；

  4. **步骤4**：联立参数；

  **关键提醒**：可导题通常先隐含连续条件。

- **典型例示**：【一题反应一类】

  **题目**：设 $f(0)=0$，$f(x)=x\sin\frac1x$（$x\ne0$），判断在 $0$ 处的连续性与可导性。

  **完整解答**：

  1. 由 $|x\sin(1/x)|\le|x|\to0$，所以 $f$ 在 $0$ 连续。

  2. 导数定义给出 $f^{\prime}(0)=\lim_{h\to0}\sin\frac1h$。

  3. 该极限振荡不存在，因此 $f$ 在 $0$ 不可导。

  4. 此例再次说明连续不是可导的充分条件。

- **书目出处**：《基础30讲》第3讲（约第99-118页）；《1000题数二》第3章相关题型。

#### 题型模型三：局部线性化模型

- **核心方法**：【核心解题模型与思维框架】

  1. **步骤1**：写 $\Delta y$；

  2. **步骤2**：提取线性项；

  3. **步骤3**：控制高阶无穷小；

  **关键提醒**：近似计算要标明展开点。

- **典型例示**：【一题反应一类】

  **题目**：用线性化估算 $\sqrt{4.04}$。

  **完整解答**：

  1. 取 $f(x)=\sqrt{x}$，在接近 $4.04$ 且便于计算的 $x_0=4$ 处展开。

  2. $f(4)=2$，$f^{\prime}(x)=\frac1{2\sqrt{x}}$，所以 $f^{\prime}(4)=\frac14$。

  3. 由 $f(4+\Delta x)\approx f(4)+f^{\prime}(4)\Delta x$，取 $\Delta x=0.04$。

  4. 得到 $\sqrt{4.04}\approx2+\frac14\times0.04=2.01$。

- **书目出处**：《基础30讲》第3讲（约第99-118页）；《1000题数二》第3章相关题型。

### 易错点与纠正

- **易错点1**：把连续当作可导的充分条件。

- **易错点2**：只算右导数，不检查左导数。

- **易错点3**：差商分母与函数自变量增量不匹配。

- **易错点4**：法线斜率在 $f^{\prime}(x_0)=0$ 时仍机械取负倒数。
