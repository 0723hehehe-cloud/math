# 反函数 总结复盘

### 涉及知识点

- **定义**：设函数 $y = f(x)$ 的定义域为 $D$，值域为 $R$。如果对于 $R$ 内的任意一个 $y$，在 $D$ 内都有唯一确定的 $x$ 使得 $y = f(x)$，则在 $R$ 上确定了一个以 $y$ 为自变量的函数，称为 $f(x)$ 的反函数，记作 $x = f^{-1}(y)$ 或交换自变量后写为 $y = f^{-1}(x)$。
- **几何意义**：函数 $y = f(x)$ 及其反函数 $y = f^{-1}(x)$ 的图像关于直线 $y = x$ 对称。
- **基本存在性**：严格单调连续函数必存在单调连续的反函数，且单调性与原函数一致。
- **常见反三角函数恒等式**：
  1. $\arcsin x + \arccos x = \frac{\pi}{2} \quad (x \in [-1, 1]), \quad \arctan x + \text{arccot } x = \frac{\pi}{2} \quad (x \in \mathbb{R})$
  2. $\arcsin(-x) = -\arcsin x, \quad \arccos(-x) = \pi - \arccos x, \quad \arctan(-x) = -\arctan x$
- **反双曲函数对数表达式**：
  1. 反双曲正弦：$\text{arsinh } x = \ln(x + \sqrt{x^2+1})$
  2. 反双曲余弦：$\text{arcosh } x = \ln(x + \sqrt{x^2-1}) \quad (x \ge 1)$
  3. 反双曲正切：$\text{artanh } x = \frac{1}{2} \ln \frac{1+x}{1-x} \quad (|x| < 1)$

### 强化核心：输入关键词 $\to$ 输出秒杀方法

| 题目特征关键词 | 核心秒杀方法 |
| :--- | :--- |
| 求分段函数反函数 | 1. 算各段值域（作为反函数定义域）；2. 反解 $x=g(y)$；3. 结合原 $x$ 区间符号决定开方/反三角主值正负号 | | 反函数的一阶导数 $\frac{dx}{dy}$ | 直接套用倒数公式： $\frac{dx}{dy} = \frac{1}{y'}$ | | 反函数的二阶导数 $\frac{d^2 x}{dy^2}$ | 秒杀公式： $\frac{d^2 x}{dy^2} = -\frac{y''}{(y')^3}$ | | 反函数的三阶导数 $\frac{d^3 x}{dy^3}$ | 秒杀公式： $\frac{d^3 x}{dy^3} = \frac{3(y'')^2 - y''' y'}{(y')^5}$ | | 复合方程中脱去反函数符号（如 $f^{-1}(x)$ ） | 两边同取 $f(x)$ 运算，利用 $f[f^{-1}(x)] = x$ 脱去符号 |

### 核心题型与解法

### 题型一：求分段函数与复合函数的反函数

- **核心方法**：1. **求值域**：算出原函数在各分段区间下的值域，作为反函数对应分段的定义域。
  2. **独立反解**：在每一段中反解出 $x = g(y)$。
3. **正负号判定**：涉及开方、绝对值或反三角函数时，严格根据原自变量 $x$ 的正负及取值范围判定正负号（如当 $x < -1$ 时，由 $x^2 = A$ 解得 $x = -\sqrt{A}$）。
- **典型例示**：求

$$
f(x) = \begin{cases} 1-2x^2, & x < -1 \\ x^3, & -1 \le x \le 2 \\ 12x-16, & x > 2 \end{cases}
$$

的反函数表达式。
- **书目出处**：《张宇1000题》第一章第3题 （《基础30讲》第1讲第13页 [例 1.6] 同类强化题）

### 题型二：求反函数的一阶与高阶导数

- **核心方法**：直接套用反函数求导法则及链式法则：
  1. 一阶导数：$\frac{dx}{dy} = \frac{1}{y'}$
  2. 二阶导数：对一阶导关于 $y$ 再求导，即 $\frac{d^2 x}{dy^2} = \frac{d}{dx}(\frac{1}{y'}) \cdot \frac{dx}{dy} = -\frac{y''}{(y')^2} \cdot \frac{1}{y'} = -\frac{y''}{(y')^3}$。
3. 三阶导数：继续对二阶导求导，得到 $\frac{d^3 x}{dy^3} = \frac{3(y'')^2 - y''' y'}{(y')^5}$。
- **典型例示**：已知 $y = x^3 + x$，求反函数在 $y=2$ 处的一阶与二阶导数。
- **书目出处**：《基础30讲》第3讲第45页 [例 3.12]

### 题型三：反函数复合恒等式 $f[f^{-1}(x)] = x$ 的应用 - **核心方法**：1. **恒等脱帽**：利用 $f[f^{-1}(x)] = x$ 或 $f^{-1}[f(x)] = x$ 解方程。

2. **两边求导**：对含有 $f^{-1}(x)$ 的恒等式两边同时求导，转化为关于导数的方程关系。
- **典型例示**：若 $f(x)$ 满足 $f^{-1}(x) = \ln(x + \sqrt{x^2+1})$，求 $f(x)$ 的解析式。
- **书目出处**：《基础30讲》第1讲第13页 [重要结论 (2)]

### 易错点 & 避坑指南

- **易错点 1**：求分段反函数时忽略原函数在各段的值域，导致反函数的定义域没写或写错。
- **易错点 2**：反解 $x$ 开方时漏掉负号（如当 $x < -1$ 时，$x^2 = y \implies x = -\sqrt{y}$）。
- **易错点 3**：求反函数高阶导数时记错公式，误将 $\frac{d^2 x}{dy^2}$ 记为 $\frac{1}{y''}$（正确为 $-\frac{y''}{(y')^3}$）。
