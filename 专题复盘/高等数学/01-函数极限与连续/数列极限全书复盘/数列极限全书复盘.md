# 数列极限全书复盘 总结复盘

### 涉及知识点

- **核心知识点1**：数列收敛定义强调从某项以后全部进入任意小邻域；收敛数列必有界，但有界未必收敛。

- **核心知识点2**：单调有界定理是递推数列的主线：先证单调，再证有界，最后令极限满足递推方程。

- **核心知识点3**：夹逼准则适合和式、根式与阶乘结构；先找统一上下界，再让误差趋零。

- **核心知识点4**：子列与原数列：原数列收敛则任意子列同极限；找两条不同极限子列可证发散。

- **核心知识点5**：数列极限可转成函数极限、定积分定义或 Stolz 型差分比。

### 核心公式与使用边界

- **公式1**：$a_n\to A \Rightarrow a_{n_k}\to A$。

- **公式2**：若 $a_n$ 单调且有界，则 $a_n$ 收敛。

- **公式3**：$\frac1n\sum_{k=1}^n f(k/n)\to\int_0^1 f(x)\,dx$。

### 📌 强化核心：输入题目关键词 $\to$ 输出秒杀方法

| 题目表面信号 / 关键词 | 对应解题突破口 / 判定方法 |
| :--- | :--- |
| 递推式 $a_{n+1}=\varphi(a_n)$ | 不动点猜极限，差分或导数证单调，归纳证有界。 |
| 前 $n$ 项和或和式极限 | 尝试放缩、裂项或识别黎曼和。 |
| 幂次、根次随 $n$ 变化 | 取对数，把幂指型转为乘积型极限。 |
| 怀疑数列不收敛 | 构造奇偶子列或其他两条不同极限子列。 |

### 核心题型与解法

#### 题型模型一：递推数列模型

- **核心方法**：【核心解题模型与思维框架】

  1. **第1步**：先假设数列已经收敛并令极限为 $A$，把递推式两边取极限得到不动点方程 $A=\varphi(A)$。这一步只能给出候选值，不能代替收敛性证明。

  2. **第2步**：证明有界时先观察递推函数把哪个区间映回自身，再用数学归纳法证明 $a_n$ 始终留在该区间。候选极限通常能提示上界或下界的选取。

  3. **第3步**：证明单调时计算 $a_{n+1}-a_n$，通过有理化、因式分解或利用 $\varphi$ 的单调性判断符号。分母的正负必须先由有界性结论保证。

  4. **第4步**：单调且有界后才能引用单调有界定理确认极限存在，再回到不动点方程，并结合数列所在区间排除不合适的根。

- **典型例示**：【一题反应一类】

  **题目**：设 $a_1=\sqrt2$，$a_{n+1}=\sqrt{2+a_n}$，求极限。

  **完整解答**：

  1. 由递推式猜测极限满足 $A=\sqrt{2+A}$，候选为 $A=2$。

  2. 用归纳法证明 $0<a_n<2$，得到上界。

  3. 比较 $a_{n+1}$ 与 $a_n$，利用平方或递推关系证明单调递增。

  4. 单调有界保证收敛，再代入递推式确定极限为 $2$。

- **书目出处**：《基础30讲》第2讲（约第76-98页）；《1000题数二》第2章相关题型。

#### 题型模型二：黎曼和模型

- **核心方法**：【核心解题模型与思维框架】

  1. **第1步**：先把和式整理出统一步长 $\Delta x=(b-a)/n$。若原式缺少 $1/n$，应从每一项中提取；若下标从 $0$ 或 $1$ 开始，有限个端点差异通常不影响极限。

  2. **第2步**：把求和项写成 $f(a+k\Delta x)\Delta x$，同时明确采样点、积分区间和被积函数。不能只看到 $k/n$ 就直接写积分。

  3. **第3步**：检查 $f$ 在积分区间上是否连续或至少可积，然后使用 Riemann 和定义，把数列极限改写为 $\int_a^b f(x)\,dx$。

  4. **第4步**：积分算完后检查数量级：若每项均非负，结果不能为负；若每项有统一上界，极限也不应超过对应矩形面积。

- **典型例示**：【一题反应一类】

  **题目**：计算 $\lim_{n\to\infty}\frac1n\sum_{k=1}^n\left(\frac{k}{n}\right)^2$。

  **完整解答**：

  1. 先识别步长 $\Delta x=1/n$，节点为 $x_k=k/n$。

  2. 原式正是 $\sum_{k=1}^n f(x_k)\Delta x$，其中 $f(x)=x^2$，积分区间为 $[0,1]$。

  3. 因此极限等于 $\int_0^1x^2\,dx$。

  4. 计算得 $\left.\frac{x^3}{3}\right|_0^1=\frac13$。

- **书目出处**：《基础30讲》第2讲（约第76-98页）；《1000题数二》第2章相关题型。

#### 题型模型三：子列判敛模型

- **核心方法**：【核心解题模型与思维框架】

  1. **第1步**：要证明数列发散，应优先寻找由结构自然产生的子列，例如奇数项、偶数项，或按周期余数分类的子列。

  2. **第2步**：分别写出子列的一般项并求极限。只指出“数列振荡”不够，必须给出至少两条收敛到不同值的子列。

  3. **第3步**：如果原数列收敛到 $A$，它的每一条子列都必须收敛到同一个 $A$。两条子列极限不同与这一必要条件矛盾，因此原数列发散。

  4. **第4步**：子列法只能用于否定收敛或继承已知极限；找到一条收敛子列不能证明原数列收敛。

- **典型例示**：【一题反应一类】

  **题目**：判断数列 $a_n=(-1)^n$ 是否收敛。

  **完整解答**：

  1. 取偶数子列 $a_{2n}=1$，其极限为 $1$。

  2. 取奇数子列 $a_{2n-1}=-1$，其极限为 $-1$。

  3. 同一数列存在两条极限不同的子列。

  4. 因此原数列发散；有界并不能推出收敛。

- **书目出处**：《基础30讲》第2讲（约第76-98页）；《1000题数二》第2章相关题型。

### 易错点与纠正

- **易错点1**：直接令 $n\to\infty$ 解递推方程，却没有证明收敛。

- **易错点2**：单调性计算中分母符号未先确认。

- **易错点3**：黎曼和漏掉步长或积分区间。

- **易错点4**：把“有界”误当成“收敛”。
