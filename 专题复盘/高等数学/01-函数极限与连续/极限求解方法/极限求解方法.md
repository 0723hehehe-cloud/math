# 极限求解方法 总结复盘

[!info] 涉及知识点
- **定义**：
  1. **数列极限**：设 $\{x_n\}$ 为一数列，若存在常数 $a$，对任意 $\epsilon > 0$，总存在正整数 $N$，当 $n > N$ 时，恒有 $|x_n - a| < \epsilon$，则称数列 $\{x_n\}$ 收敛于 $a$，记为 $\lim_{n \to \infty} x_n = a$。 2. **函数极限**：设函数 $f(x)$ 在点 $x_0$ 的去心邻域内有定义，若存在常数 $A$，对任意 $\epsilon > 0$，总存在 $\delta > 0$，当 $0 < |x - x_0| < \delta$ 时，恒有 $|f(x) - A| < \epsilon$，则称 $\lim_{x \to x_0} f(x) = A$。
- **核心基本性质**：
  1. **唯一性**：若极限存在，则极限唯一。
  2. **局部有界性**：若 $\lim_{x \to x_0} f(x) = A$ 存在，则 $f(x)$ 在 $x_0$ 的去心邻域内有界。 3. **局部保号性**：若 $\lim_{x \to x_0} f(x) = A > 0$（或 $<0$），则存在 $\delta > 0$，当 $0 < |x - x_0| < \delta$ 时，恒有 $f(x) > 0$（或 $<0$）。 4. **海涅定理 (归结原则)**：$\lim_{x \to x_0} f(x) = A$ 的充要条件是：对任意以 $x_0$ 为极限且满足 $x_n \neq x_0$ 的数列 $\{x_n\}$，恒有 $\lim_{n \to \infty} f(x_n) = A$。 - **无穷大比较阶**：当 $x \to +\infty$ 时，有常用无穷大比较链：
$\ln x \ll x^\alpha \ll a^x \ll x! \ll x^x \quad (\alpha > 0, a > 1)$
- **常用等价无穷小**：当 $x \to 0$ 时：
$\sin x \sim x, \quad \tan x \sim x, \quad \arcsin x \sim x, \quad \arctan x \sim x \ln(1+x) \sim x, \quad e^x - 1 \sim x, \quad 1-\cos x \sim \frac{1}{2}x^2, \quad (1+x)^\alpha - 1 \sim \alpha x$
- **高阶差额等价无穷小 (秒杀利器)**：当 $x \to 0$ 时：
$x - \sin x \sim \frac{1}{6}x^3, \quad \tan x - x \sim \frac{1}{3}x^3, \quad x - \ln(1+x) \sim \frac{1}{2}x^2 \arcsin x - x \sim \frac{1}{6}x^3, \quad x - \arctan x \sim \frac{1}{3}x^3, \quad e^x - 1 - x \sim \frac{1}{2}x^2$
- **常用泰勒展开公式**：当 $x \to 0$ 时： 1. $e^x = 1 + x + \frac{1}{2}x^2 + \frac{1}{6}x^3 + o(x^3)$
  2. $\sin x = x - \frac{1}{6}x^3 + o(x^3)$
  3. $\cos x = 1 - \frac{1}{2}x^2 + \frac{1}{24}x^4 + o(x^4)$
  4. $\ln(1+x) = x - \frac{1}{2}x^2 + \frac{1}{3}x^3 - \frac{1}{4}x^4 + o(x^4)$
  5. $(1+x)^\alpha = 1 + \alpha x + \frac{\alpha(\alpha-1)}{2}x^2 + o(x^2)$
### 强化核心：输入关键词 $\to$ 输出秒杀方法
| 题目特征关键词 | 核心秒杀方法 |
| :--- | :--- |
| $f(x) - g(x)$ 且 $f(x) \sim x, g(x) \sim x$ 相减 | 严禁直接代换！改用高阶差额等价无穷小代换，或使用泰勒展开至能消去最低阶差项为止 | | 未定式 $\frac{0}{0}$ 或 $\frac{\infty}{\infty}$，且求导简便 | 使用洛必达法则。求导前尽可能先用等价无穷小提取乘除因子，简化乘积项 | | 指数幂极限 $u(x)^{v(x)}$ 且为 $1^\infty$ 型 | 直接秒杀公式： $u^v = e^{\lim v(u-1)}$ | | 项数随 $n$ 增加的数列求和极限 $\lim \sum_{i=1}^n f_i(n)$ | 1. 若分母变化缓慢且容易放缩 $\to$ 用夹逼定理；2. 若项形式为 $\frac{1}{n} g(\frac{i}{n})$ $\to$ 转化为定积分定义计算 | | 递推数列 $x_{n+1} = g(x_n)$ 极限 | 单调有界性判定：1. 证明有界（数学归纳法）；2. 证明单调（用 $x_{n+1}-x_n$ 符号或 $g'(x)>0$ 判定）；3. 令 $\lim x_n = L$，解 $L = g(L)$ | | 多元函数二重极限 $\lim_{(x,y) \to (0,0)} f(x,y)$ | 1. 极坐标代换 $x=r\cos\theta, y=r\sin\theta$，证与 $\theta$ 无关则极限存在；2. 沿不同路径（如 $y=kx$）极限不同则证明极限不存在 |

### 题型一：一元函数未定式的等价无穷小与泰勒公式求解
- **核心方法**：对于 $\frac{0}{0}$ 型极限：
  1. **能代换先代换**：被积函数或分式中的**乘除因子**可以直接用等价无穷小代换。
  2. **相减项差额代换**：若相减的两项等价于同一阶无穷小，必须使用高阶差额等价无穷小公式代换，或通过泰勒公式展开。展开阶数遵循“分母是几阶，分子就展开到几阶”的原则。
- **典型例示**：求 $\lim_{x \to 0} \frac{x - \sin x}{x^2 \ln(1+x)}$ 的值。
- **书目出处**：《基础30讲》第3讲第31页 [重要结论 (5)] & 第33页 [例 3.6]
### 题型二：洛必达法则的应用及其失效判定
- **核心方法**：1. 必须在满足 $\frac{0}{0}$ 或 $\frac{\infty}{\infty}$ 且导数比例的极限存在（或为 $\infty$）时才能使用。 2. **振荡失效判定**：当求导后的极限因为三角函数振荡而不存在时（如 $\lim_{x \to \infty} \frac{x - \sin x}{x + \sin x}$），洛必达法则失效，必须改用分子分母同除以最高阶项（提公因式）方法计算。 - **典型例示**：求 $\lim_{x \to +\infty} \frac{x - \sin x}{x + \sin x}$ 的值。
- **书目出处**：《基础30讲》第3讲第33页 [重要定理 (定理 3.2)] & 第34页 [例 3.8]
### 题型三：幂指函数未定式（$1^\infty, 0^0, \infty^0$）的求解 - **核心方法**：1. **$1^\infty$ 型**：利用公式 $u(x)^{v(x)} = [1 + (u(x)-1)]^{v(x)}$，若 $\lim u(x) = 1, \lim v(x) = \infty$，则极限直接转化为 $e^{\lim v(x)[u(x)-1]}$。 2. **$0^0, \infty^0$ 型**：利用指数恒等式 $u^v = e^{v \ln u}$，将极限转化为求指数上的乘积极限 $\lim v \ln u$。 - **典型例示**：求 $\lim_{x \to 0} (\cos x)^{\frac{1}{x^2}$ 的值。
- **书目出处**：《基础30讲》第3讲第35页 [例 3.10]
### 题型四：夹逼定理求解数列极限
- **核心方法**：当求和式共有 $n$ 项且项数随 $n$ 变化，而各项分母或分子有微小差异导致无法直接求和时，使用放缩法：
  1. **放大**：将所有项替换为最大的一项（通常为分母最小或分子最大的一项），求和后取极限。
  2. **缩小**：将所有项替换为最小的一项，求和后取极限。
  3. 若放大和缩小的两端数列极限相等，则中间求和极限亦相等。
- **典型例示**：求 $\lim_{n \to \infty} \sum_{i=1}^n \frac{1}{\sqrt{n^2 + i}$ 的值。
- **书目出处**：《基础30讲》第2讲第21页 [重要定理 (定理 2.1)] & 第22页 [例 2.2]
### 题型五：单调有界准则求解递推数列极限
- **核心方法**：对于 $x_{n+1} = f(x_n)$ 形式的数列： 1. **有界性**：由首项 $x_1$ 结合数学归纳法证明 $x_n \le M$ 或 $x_n \ge m$。
  2. **单调性**：
     - 法一：考察差值 $x_{n+1} - x_n = f(x_n) - x_n$ 的正负。 - 法二：若 $f'(x) > 0$，则数列具有单调性（若 $x_2 > x_1$ 则单调递增；若 $x_2 < x_1$ 则单调递减）。 3. **求极限**：设极限存在为 $L$，对递推式两边取极限解方程 $L = f(L)$，并根据有界性舍去不合题意的解。 - **典型例示**：已知 $x_1 = \sqrt{2}, x_{n+1} = \sqrt{2} + x_n}$，求 $\lim_{n \to \infty} x_n$ 的值。
- **书目出处**：《基础30讲》第2讲第21页 [重要定理 (定理 2.2)] & 第23页 [例 2.5]
### 题型六：定积分定义求解数列极限
- **核心方法**：当求和项形如 $\sum_{i=1}^n \frac{1}{n} g(\frac{i}{n})$ 且 $g(x)$ 连续时，直接将其转化为区间 $[0,1]$ 上的定积分计算：
$\lim_{n \to \infty} \sum_{i=1}^n \frac{1}{n} g\left(\frac{i}{n}\right) = \int_0^1 g(x) dx$
  关键是提取出 $\frac{1}{n}$ 因子作为 $dx$，并将剩余部分写为以 $\frac{i}{n}$ 为自变量的表达式。 - **典型例示**：求 $\lim_{n \to \infty} \frac{1}{n^2} (\sqrt{n^2-1^2} + \sqrt{n^2-2^2} + \dots + \sqrt{n^2-n^2})$ 的值。
- **书目出处**：《基础30讲》第8讲第196页 [定义 8.1] & 第197页 [例 8.1]
### 题型七：海涅定理与数列极限向函数极限的转化
- **核心方法**：对于某些较复杂的数列极限 $\lim_{n \to \infty} x_n$，可以通过将离散的 $n$ 连续化为 $x \to +\infty$，求出连续函数极限 $\lim_{x \to +\infty} f(x) = A$。根据海涅定理，离散数列极限亦为 $A$。此法便于使用泰勒公式和洛必达法则。 - **典型例示**：求 $\lim_{n \to \infty} n \sin(\frac{1}{n})$ 的值。
- **书目出处**：《基础30讲》第2讲第22页 [重要结论]
### 题型八：二重极限的极坐标代换与路径不存在判定
- **核心方法**：对于多元极限 $\lim_{(x,y) \to (0,0)} f(x,y)$： 1. **极坐标代换法**：令 $x=r\cos\theta, y=r\sin\theta$。若 $|f(r\cos\theta, r\sin\theta) - L| \le g(r)$ 且 $\lim_{r \to 0^+} g(r) = 0$（即极限与极角 $\theta$ 独立），则二重极限存在，值为 $L$。 2. **路径不存在判定**：若令 $y=kx$（或 $y=kx^2$ 等）沿直线方向逼近，求出的极限值与 $k$ 相关，则说明从不同方向逼近得到的极限不同，二重极限不存在。 - **典型例示**：证明 $\lim_{(x,y) \to (0,0)} \frac{xy}{x^2 + y^2}$ 不存在。
- **书目出处**：《基础30讲》第13讲第303页 [定义 13.2] & 第304页 [例 13.1, 例 13.2]

### 易错点 & 避坑指南

- **易错点 1**：使用洛必达法则前没有验证是否为 $\frac{0}{0}$ 或 $\frac{\infty}{\infty}$ 未定式，滥用求导导致错误。 - **易错点 2**：在 $1^\infty$ 型未定式中，使用 $e^{\lim (u-1)v}$ 时未先验证 $u \to 1$ 且 $v \to \infty$。
- **易错点 3**：泰勒展开项数不够或展开层数不匹配，导致高阶项被错误忽略。
