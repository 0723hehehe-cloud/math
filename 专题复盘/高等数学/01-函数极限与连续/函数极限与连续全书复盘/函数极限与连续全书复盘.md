# 函数极限与连续全书复盘 总结复盘

### 涉及知识点

- **核心知识点1**：函数的定义域、奇偶性、周期性、单调性与有界性必须先于极限计算检查。

- **核心知识点2**：极限的本质是去心邻域内的趋势；左右极限都存在且相等，双侧极限才存在。

- **核心知识点3**：无穷小比较、等价替换、洛必达、泰勒、夹逼和单调有界是六条主计算路线。

- **核心知识点4**：连续性判断由“极限存在、函数有定义、极限等于函数值”三条件组成；间断点按左右极限分类。

- **核心知识点5**：渐近线分为垂直、水平和斜渐近线，根式在 $x\to-\infty$ 时必须处理 $\sqrt{x^2}=|x|=-x$。

### 核心公式与使用边界

- **公式1**：$\lim_{x\to0}\frac{\sin x}{x}=1$，$\lim_{x\to0}(1+x)^{1/x}=e$。

- **公式2**：$f(x)\sim g(x)$ 的可替换前提：作为乘除因子使用；在加减结构中应先比较阶数。

- **公式3**：$a=\lim_{x\to\infty}\frac{f(x)}x$，$b=\lim_{x\to\infty}[f(x)-ax]$。

### 📌 强化核心：输入题目关键词 $\to$ 输出秒杀方法

| 题目表面信号 / 关键词 | 对应解题突破口 / 判定方法 |
| :--- | :--- |
| 出现 $0/0$ 或 $\infty/\infty$ | 先化简与等价无穷小，再判断是否使用洛必达。 |
| 根式与多项式在无穷远处相减 | 先有理化或提取 $|x|$，再做同阶展开。 |
| 分段函数在分界点连续 | 左极限、右极限、函数值三者联立。 |
| 求渐近线条数 | 先找无定义点的垂直线，再分别检查 $\pm\infty$ 的水平或斜线。 |

### 核心题型与解法

#### 题型模型一：等价无穷小与泰勒模型

- **核心方法**：【核心解题模型与思维框架】

  1. **第1步**：先代入极限点判断未定式类型。只有出现 $0/0$、$\infty/\infty$ 等未定式时才需要继续变形；如果直接代入已有确定值，就不能为了套公式而使用洛必达。

  2. **第2步**：观察分子、分母是乘除结构还是加减抵消结构。乘除结构可用等价无穷小；加减结构必须先通分、有理化或作 Taylor 展开，直到找到第一个没有抵消的非零项。

  3. **第3步**：把分子、分母都化为“最低阶主项 $+$ 高阶无穷小”，约去共同幂次后再取极限。若展开后仍然得到 $0/0$，说明阶数不够，应继续多展开一阶。

  4. **第4步**：最后用另一条路线复核：根式差可有理化，三角式可用重要极限，指数对数式可用 Taylor。两种方法应得到相同结果。

- **典型例示**：【一题反应一类】

  **题目**：计算 $\lim_{x\to0}\frac{\sqrt{1+x}-1}{x}$。

  **完整解答**：

  1. 先识别为 $0/0$ 型，根式差优先有理化。

  2. 分子分母同乘 $\sqrt{1+x}+1$，原式化为 $\frac{1}{\sqrt{1+x}+1}$。

  3. 令 $x\to0$，得到极限 $\frac12$。

  4. 复核：也可用 $\sqrt{1+x}-1\sim\frac{x}{2}$，两种方法结果一致。

- **书目出处**：《基础30讲》第1讲（约第1-75页）；《1000题数二》第1章相关题型。

#### 题型模型二：间断点分类模型

- **核心方法**：【核心解题模型与思维框架】

  1. **第1步**：先找函数可能不连续的点：分母为零点、分段连接点、根式或对数定义域边界。普通初等函数在其定义域内部连续，不需要逐点检查。

  2. **第2步**：在可疑点 $x_0$ 分别计算左极限与右极限。两者不相等是跳跃间断；某一侧趋于无穷是无穷间断；极限因振荡不存在是振荡间断。

  3. **第3步**：若左右极限相等且为有限数 $L$，再比较 $f(x_0)$。没有定义或 $f(x_0)\ne L$ 时是可去间断；只有 $f(x_0)=L$ 时才连续。

  4. **第4步**：含参数的连续题要把“左极限 $=$ 右极限 $=$ 函数值”写成方程组。先由极限确定参数，再回代检查定义域，不能只满足其中一个等号。

- **典型例示**：【一题反应一类】

  **题目**：设 $f(x)=\frac{\sin x}{x}$（$x\ne0$），$f(0)=a$，求使 $f$ 在 $0$ 连续的 $a$。

  **完整解答**：

  1. 连续条件是 $\lim_{x\to0}f(x)=f(0)$。

  2. 利用重要极限 $\lim_{x\to0}\frac{\sin x}{x}=1$。

  3. 因此必须取 $a=1$。

  4. 检查点：题目问连续，不需要再求导。

- **书目出处**：《基础30讲》第1讲（约第1-75页）；《1000题数二》第1章相关题型。

#### 题型模型三：渐近线模型

- **核心方法**：【核心解题模型与思维框架】

  1. **第1步**：垂直渐近线只在有限的可疑点寻找。若 $x\to x_0^+$ 或 $x\to x_0^-$ 时函数至少有一侧趋于无穷，就有垂直渐近线 $x=x_0$。

  2. **第2步**：对 $x\to+\infty$ 与 $x\to-\infty$ 分别计算。若 $f(x)\to A$，得到水平渐近线 $y=A$；两端可能得到不同的水平线。

  3. **第3步**：若函数按一次函数增长，先算 $a=\lim f(x)/x$。当 $a$ 为有限非零数时，再算 $b=\lim[f(x)-ax]$；两者都有限才有斜渐近线 $y=ax+b$。

  4. **第4步**：根式在负无穷方向必须使用 $\sqrt{x^2}=|x|=-x$。求完后把 $f(x)-(ax+b)$ 的极限重新算一遍，等于零才算验证完成。

- **典型例示**：【一题反应一类】

  **题目**：求 $f(x)=\frac{x^2+1}{x-1}$ 的全部渐近线。

  **完整解答**：

  1. 先检查定义域边界。$x=1$ 使分母为零，且分子不为零，所以 $x=1$ 是垂直渐近线。

  2. 作多项式除法：$\frac{x^2+1}{x-1}=x+1+\frac{2}{x-1}$。

  3. 当 $x\to\pm\infty$ 时，$\frac{2}{x-1}\to0$，所以斜渐近线为 $y=x+1$。

  4. 最终共有两条渐近线：$x=1$ 与 $y=x+1$；不存在水平渐近线。

- **书目出处**：《基础30讲》第1讲（约第1-75页）；《1000题数二》第1章相关题型。

### 易错点与纠正

- **易错点1**：把等价无穷小直接用于加减项。

- **易错点2**：忽略左右极限或只算一侧。

- **易错点3**：在 $x<0$ 时把 $\sqrt{x^2}$ 写成 $x$。

- **易错点4**：洛必达后仍是未定式却提前停止。
