# 二重积分全书复盘 总结复盘

### 涉及知识点

- **核心知识点1**：二重积分先研究区域，再研究被积函数；画准积分域是第一优先级。

- **核心知识点2**：直角坐标下按 X 型或 Y 型区域选积分次序，必要时分区。

- **核心知识点3**：圆、扇形、环域及含 $x^2+y^2$ 的被积函数优先考虑极坐标。

- **核心知识点4**：对称性包括奇偶对称、轮换对称与平移中心对称，可先化简再积分。

- **核心知识点5**：一般变量代换必须乘 Jacobian 绝对值，椭圆域可用广义极坐标化圆。

### 核心公式与使用边界

- **公式1**：$\iint_D f\,d\sigma=\int_a^b dx\int_{\varphi_1(x)}^{\varphi_2(x)}f\,dy$。

- **公式2**：$x=r\cos\theta,y=r\sin\theta,d\sigma=r\,dr\,d\theta$。

- **公式3**：$d\sigma=|J|\,du\,dv$。

### 📌 强化核心：输入题目关键词 $\to$ 输出秒杀方法

| 题目表面信号 / 关键词 | 对应解题突破口 / 判定方法 |
| :--- | :--- |
| 积分限交换 | 由旧积分限画区域，再投影到新轴重写。 |
| 圆域且函数含 $x^2+y^2$ | 转极坐标并牢记 Jacobian 的 $r$。 |
| 椭圆区域 | 按半轴缩放到单位圆，计算 $J=abr$。 |
| 区域关于轴或 $y=x$ 对称 | 检查奇偶或交换 $x,y$ 后的函数关系。 |

### 核心题型与解法

#### 题型模型一：交换积分次序模型

- **核心方法**：【核心解题模型与思维框架】

  1. **步骤1**：读旧限；

  2. **步骤2**：画区域；

  3. **步骤3**：找交点；

  4. **步骤4**：新方向投影；

  5. **步骤5**：分段写限；

  **关键提醒**：不能只机械交换 $dx,dy$。

- **典型例示**：【一题反应一类】

  **题目**：交换积分次序：$\int_0^1dx\int_x^1f(x,y)dy$。

  **完整解答**：

  1. 旧积分限表示 $0\le x\le1$ 且 $x\le y\le1$。

  2. 区域是单位正方形中直线 $y=x$ 上方三角形。

  3. 改为先固定 $y$：$0\le y\le1$，此时 $0\le x\le y$。

  4. 新积分为 $\int_0^1dy\int_0^yf(x,y)dx$。

- **书目出处**：《基础30讲》第14讲（约第338-376页）；《1000题数二》第14章相关题型。

#### 题型模型二：极坐标模型

- **核心方法**：【核心解题模型与思维框架】

  1. **步骤1**：画区域；

  2. **步骤2**：定 $\theta$；

  3. **步骤3**：定 $r$；

  4. **步骤4**：变被积函数；

  5. **步骤5**：乘 $r$；

  **关键提醒**：半径必须非负，角度范围要校验。

- **典型例示**：【一题反应一类】

  **题目**：计算单位圆盘 $D$ 上 $\iint_D(x^2+y^2)\,d\sigma$。

  **完整解答**：

  1. 区域是圆盘且被积函数含 $x^2+y^2$，立即使用极坐标。

  2. 有 $x^2+y^2=r^2$、$d\sigma=r\,dr\,d\theta$。

  3. 积分为 $\int_0^{2\pi}d\theta\int_0^1r^3dr$。

  4. 结果为 $2\pi\cdot\frac14=\frac{\pi}{2}$；复核不能漏 Jacobian 的 $r$。

- **书目出处**：《基础30讲》第14讲（约第338-376页）；《1000题数二》第14章相关题型。

#### 题型模型三：对称与换元模型

- **核心方法**：【核心解题模型与思维框架】

  1. **步骤1**：识别区域中心/轴；

  2. **步骤2**：配对函数；

  3. **步骤3**：化简；

  4. **步骤4**：必要时 Jacobian；

  **关键提醒**：一般代换要取 $|J|$。

- **典型例示**：【一题反应一类】

  **题目**：单位圆盘 $D$ 上计算 $\iint_Dx^3y^2\,d\sigma$。

  **完整解答**：

  1. 圆盘关于 $y$ 轴对称。

  2. 被积函数关于 $x$ 是奇函数：$f(-x,y)=-f(x,y)$。

  3. 对称点贡献相互抵消。

  4. 因此积分为 $0$，无需展开计算。

- **书目出处**：《基础30讲》第14讲（约第338-376页）；《1000题数二》第14章相关题型。

### 易错点与纠正

- **易错点1**：交换次序时未画区域。

- **易错点2**：极坐标漏乘 $r$。

- **易错点3**：反三角函数脱帽忽略主值范围。

- **易错点4**：椭圆换元漏 Jacobian 或半轴系数。
