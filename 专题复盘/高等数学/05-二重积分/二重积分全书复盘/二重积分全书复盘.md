# 二重积分全书复盘 总结复盘

### 涉及知识点

- **核心知识点1**：二重积分先研究区域，再研究被积函数；画准积分域是第一优先级。

- **核心知识点2**：直角坐标下按 X 型或 Y 型区域选积分次序，必要时分区。

- **核心知识点3**：圆、扇形、环域及含 $x^2+y^2$ 的被积函数优先考虑极坐标。

- **核心知识点4**：对称性包括奇偶对称、轮换对称与平移中心对称，可先化简再积分。

- **核心知识点5**：一般变量代换必须乘 Jacobian 绝对值，椭圆域可用广义极坐标化圆。

### 核心公式与使用边界

- **公式1**：$\iint_D f\,d\sigma=\int_a^b dx\int_{\varphi_1(x)}^{\varphi_2(x)}f\,dy$。

- **公式2**：$x=r\cos\theta,y=r\sin\theta,d\sigma=r\,dr\,d\theta$。

- **公式3**：$d\sigma=|J|\,du\,dv$。

### 📌 强化核心：输入题目关键词 $\to$ 输出秒杀方法

| 题目表面信号 / 关键词 | 对应解题突破口 / 判定方法 |
| :--- | :--- |
| 积分限交换 | 由旧积分限画区域，再投影到新轴重写。 |
| 圆域且函数含 $x^2+y^2$ | 转极坐标并牢记 Jacobian 的 $r$。 |
| 椭圆区域 | 按半轴缩放到单位圆，计算 $J=abr$。 |
| 区域关于轴或 $y=x$ 对称 | 检查奇偶或交换 $x,y$ 后的函数关系。 |

### 核心题型与解法

#### 题型模型一：交换积分次序模型

- **核心方法**：【核心解题模型与思维框架】

  1. **第1步**：从旧积分限逐条读出不等式，例如先外后内可写成 $a\le x\le b$、$\varphi_1(x)\le y\le\varphi_2(x)$，据此画出全部边界曲线和交点。

  2. **第2步**：把区域投影到新的外层变量轴上。沿新方向作扫描线，记录它进入区域和离开区域时碰到的边界。

  3. **第3步**：若扫描线在不同位置碰到的边界表达式发生变化，就在交点处分段；不能为了写成一个积分而忽略区域形状变化。

  4. **第4步**：按新扫描方向写内层上下限，再写外层投影范围。最后把新积分限重新翻译成不等式，确认与原区域完全一致。

- **典型例示**：【一题反应一类】

  **题目**：交换积分次序：$\int_0^1dx\int_x^1f(x,y)dy$。

  **完整解答**：

  1. 旧积分限表示 $0\le x\le1$ 且 $x\le y\le1$。

  2. 区域是单位正方形中直线 $y=x$ 上方三角形。

  3. 改为先固定 $y$：$0\le y\le1$，此时 $0\le x\le y$。

  4. 新积分为 $\int_0^1dy\int_0^yf(x,y)dx$。

- **书目出处**：《基础30讲》第14讲（约第338-376页）；《1000题数二》第14章相关题型。

#### 题型模型二：极坐标模型

- **核心方法**：【核心解题模型与思维框架】

  1. **第1步**：当区域由圆、扇形、环域组成，或被积函数反复出现 $x^2+y^2$ 时，先尝试极坐标 $x=r\cos\theta$、$y=r\sin\theta$。

  2. **第2步**：先从原点观察区域确定角度范围 $\theta$；再固定一条射线，求它进入和离开区域的半径，得到 $r$ 的上下限。

  3. **第3步**：把被积函数中的 $x,y$ 全部替换，并务必把面积元写成 $d\sigma=r\,dr\,d\theta$。漏掉 Jacobian 的 $r$ 会使次数和结果都错误。

  4. **第4步**：若圆心不在原点，边界方程转成极坐标后通常得到 $r=2a\cos\theta$ 等形式，此时还要由 $r\ge0$ 限制角度范围。

- **典型例示**：【一题反应一类】

  **题目**：计算单位圆盘 $D$ 上 $\iint_D(x^2+y^2)\,d\sigma$。

  **完整解答**：

  1. 区域是圆盘且被积函数含 $x^2+y^2$，立即使用极坐标。

  2. 有 $x^2+y^2=r^2$、$d\sigma=r\,dr\,d\theta$。

  3. 积分为 $\int_0^{2\pi}d\theta\int_0^1r^3dr$。

  4. 结果为 $2\pi\cdot\frac14=\frac{\pi}{2}$；复核不能漏 Jacobian 的 $r$。

- **书目出处**：《基础30讲》第14讲（约第338-376页）；《1000题数二》第14章相关题型。

#### 题型模型三：对称与换元模型

- **核心方法**：【核心解题模型与思维框架】

  1. **第1步**：先确认区域在某个变换下保持不变，例如关于 $x$ 轴、$y$ 轴、原点或直线 $y=x$ 对称。只有区域和面积元都保持不变，才能配对。

  2. **第2步**：再检查被积函数在该变换下的变化：奇函数配对后积分为零；交换 $x,y$ 后可把两个积分相等或取平均化简。

  3. **第3步**：一般换元时同时变换区域边界和被积函数，并计算 $J=\partial(x,y)/\partial(u,v)$。面积元必须乘 $|J|$，因为面积不能为负。

  4. **第4步**：椭圆域可令 $x=ar\cos\theta$、$y=br\sin\theta$ 化为单位圆，此时 $|J|=abr$；半轴系数和极坐标的 $r$ 都不能漏。

- **典型例示**：【一题反应一类】

  **题目**：单位圆盘 $D$ 上计算 $\iint_Dx^3y^2\,d\sigma$。

  **完整解答**：

  1. 圆盘关于 $y$ 轴对称。

  2. 被积函数关于 $x$ 是奇函数：$f(-x,y)=-f(x,y)$。

  3. 对称点贡献相互抵消。

  4. 因此积分为 $0$，无需展开计算。

- **书目出处**：《基础30讲》第14讲（约第338-376页）；《1000题数二》第14章相关题型。

### 易错点与纠正

- **易错点1**：交换次序时未画区域。

- **易错点2**：极坐标漏乘 $r$。

- **易错点3**：反三角函数脱帽忽略主值范围。

- **易错点4**：椭圆换元漏 Jacobian 或半轴系数。
