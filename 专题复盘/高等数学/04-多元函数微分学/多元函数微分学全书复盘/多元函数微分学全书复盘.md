# 多元函数微分学全书复盘 总结复盘

### 涉及知识点

- **五大基本概念及其五大逻辑关系链**：
  在多元函数（以 $z=f(x,y)$ 为例）中，五大基本概念的判定与逻辑关联为：

$$
\text{偏导数连续} \implies \text{函数可微} \implies \begin{cases} \text{偏导数存在} \\ \text{函数连续} \implies \text{极限存在} \end{cases}
$$









  *注：偏导数存在与函数连续之间无必然因果关系。*
- **定义法检验“在 $(x_0,y_0)$ 处可微”的三步判定树**： 1. **求偏导数**：$A = f_x(x_0,y_0) = \lim_{\Delta x \to 0} \frac{f(x_0+\Delta x, y_0) - f(x_0,y_0)}{\Delta x}$，$B = f_y(x_0,y_0)$；若偏导数不存在，则必不可微！
2. **写全增量与线性增量**：$\Delta z = f(x_0+\Delta x, y_0+\Delta y) - f(x_0,y_0)$，线性增量为 $A\Delta x + B\Delta y$；
  3. **计算极限**：计算关键极限：

$$
\lim_{(\Delta x, \Delta y) \to (0,0)} \frac{\Delta z - (A\Delta x + B\Delta y)}{\sqrt{\Delta x^2 + \Delta y^2}}
$$









     若该极限存在且等于 **0**，则 $z=f(x,y)$ 在 $(x_0,y_0)$ 处**可微**；若不为 0 或极限不存在，则**不可微**。
- **无条件极值判定法（黑塞矩阵 $AC-B^2$ 法）**： 设 $(x_0,y_0)$ 为驻点（$f_x=0, f_y=0$），令 $A = f_{xx}'', B = f_{xy}'', C = f_{yy}''$，计算判别式 $\Delta = AC - B^2$： - 若 $AC - B^2 > 0$：当 $A < 0$ 时为**极大值**；当 $A > 0$ 时为**极小值**。
- 若 $AC - B^2 < 0$：**不是极值点**（鞍点）。
- 若 $AC - B^2 = 0$：**方法失效**，需改用定义法或其他方法判定。
- **条件极值与拉格朗日乘数法**：
  求 $z=f(x,y)$ 在约束条件 $\varphi(x,y)=0$ 下的极值： 构造拉格朗日函数：$L(x,y,\lambda) = f(x,y) + \lambda \varphi(x,y)$，联立方程组求驻点：

$$
\begin{cases} L_x' = f_x' + \lambda \varphi_x' = 0 \\ L_y' = f_y' + \lambda \varphi_y' = 0 \\ L_\lambda' = \varphi(x,y) = 0 \end{cases}
$$

### 核心题型与解法

### 题型模型一：多元函数概念判定模型（一图看懂五大概念判定树）

- **核心方法**：【核心解题模型与思维框架】：
  1. **极限判定模型**：沿直线族 $y=kx$ 或抛物线族 $y=cx^2$ 趋近。若结果中残留参数 $k, c$，判定**极限不存在**；若能使用放缩法 $\lvert f(x,y)-L \rvert \le C(x^2+y^2)^\alpha \to 0$（$\alpha>0$），判定**极限存在**；
2. **偏导判定模型**：必须严格用一元导数定义求 $f_x(x_0,y_0) = \lim_{\Delta x \to 0} \frac{f(x_0+\Delta x, y_0)-f(x_0,y_0)}{\Delta x}$；
3. **可微判定模型**：计算增量极限 $\lim_{(\Delta x, \Delta y)\to(0,0)} \frac{\Delta z - (A\Delta x + B\Delta y)}{\sqrt{\Delta x^2+\Delta y^2}}$。若沿某方向趋近非零，判定**不可微**。
- **典型例示**：【一题反应一类】：
  - $f(x,y)=\frac{x^2 y}{x^2+y^2}$ 在 $(0,0)$ 连续，而 $\frac{xy}{x^2+y^2}$ 沿 $y=kx$ 趋近依赖 $k$ 故不连续；
- $f(x,y) = \sqrt{\lvert xy \rvert}$ 在 $(0,0)$ 偏导数存在且均为 0，但增量极限沿 $y=x$ 趋近为 $\frac{1}{\sqrt{2}} \ne 0$，故不可微。
- **书目出处**：《基础30讲》第13讲第331页 [习题 13.1 & 13.3]

### 题型模型二：路径单调性二步放缩模型（已知偏导符号比大小）

- **核心方法**：【核心解题模型与思维框架】：
  已知偏导数符号 $\frac{\partial f}{\partial x} > 0, \frac{\partial f}{\partial y} < 0$，比较平面内任意两点 $A(x_1,y_1)$ 与 $B(x_2,y_2)$ 的函数值大小。
  【折线网格路网模型】：
  采用**二步折线路径** $A(x_1,y_1) \to C(x_2,y_1) \to B(x_2,y_2)$： 1. **水平段**：利用 $f_x' > 0$ 说明 $f(x, y_1)$ 沿 $x$ 轴单调递增 ⟹ $f(x_1,y_1) < f(x_2,y_1)$；
2. **竖直段**：利用 $f_y' < 0$ 说明 $f(x_2, y)$ 沿 $y$ 轴单调递减 ⟹ $f(x_2,y_1) < f(x_2,y_2)$；
3. 传递推出：$f(x_1,y_1) < f(x_2,y_2)$。
- **典型例示**：【一题反应一类】：
  已知 $f_x' > 0, f_y' < 0$，比较 $f(0,1)$ 与 $f(1,0)$ 的大小。
*解法模型*：取路径 $(0,1) \to (1,1) \to (1,0)$，由 $f_x'>0 \implies f(0,1) < f(1,1)$；由 $f_y'<0 \implies f(1,1) < f(1,0)$，直接秒杀 $f(0,1) < f(1,0)$！
- **书目出处**：《基础30讲》第13讲第331页 [习题 13.2]

### 题型模型三：多元复合与隐函数链式求导树模型

- **核心方法**：【核心解题模型与思维框架】：
  1. **变量关系树模型**：根节点为因变量 $z$，中间分叉为中间变量 $u,v$，末端叶节点为自变量 $x,y$。求导遵循“**分道相加，同道相乘**”；
2. **微分形式不变性模型**：$dz = f_1' du + f_2' dv$。在具体点处求全微分，先算中间变量在该点的值，直接带入常数偏导数；
3. **隐函数公式模型**：若 $F(x,y,z)=0$，偏导数为 $\frac{\partial z}{\partial x} = -\frac{F_x'}{F_z'}$（需 $F_z' \ne 0$）；或对方程两边同时求全微分 $dF=0$ 解出 $dz$。
- **典型例示**：【一题反应一类】：
  - 复合结构 $z = f(xy, \ln x + g(xy))$ 恒有 $x z_x' - y z_y' = f_2'$；
- 隐函数 $(z+y)^x = x^2$ 两边取对数 $x \ln(z+y) = 2 \ln x$，对 $x$ 求偏导代入点 $(1,1,0)$ 秒杀偏导数等于 2。
- **书目出处**：《基础30讲》第13讲第331~332页 [习题 13.4, 13.7, 13.8, 13.9, 13.10, 13.11]

### 题型模型四：无条件极值黑塞矩阵（$AC-B^2$）模型

- **核心方法**：【核心解题模型与思维框架】：
  1. **光滑函数黑塞矩阵模型**：
     - 找驻点：解方程组

$$
\begin{cases} f_x' = 0 \\ f_y' = 0 \end{cases}
$$









得候选点 $(x_0,y_0)$；
- 计算二阶偏导矩阵：$A = f_{xx}'', B = f_{xy}'', C = f_{yy}''$；
- 判别式 $\Delta = AC - B^2$：$\Delta > 0$ 时 $A<0$ 为极大值点，$A>0$ 为极小值点；$\Delta < 0$ 为鞍点（非极值点）；$\Delta = 0$ 失效（需改用定义法）；
2. **非光滑绝对值点模型**：遇 $z=|g(x,y)| \ge 0$，利用非负性定义判定 $g(x,y)=0$ 为极小值点。
- **典型例示**：【一题反应一类】：
  - $z_1 = |x+y| \ge 0 = z_1(0,0)$ 由非负性直接判定 $(0,0)$ 为极小值点；
- $dz_2 = (3x^2+6x)dx - (3y^2-6y)dy$ 在 $(0,0)$ 处 $A=6, C=6, AC-B^2=36 > 0$，亦为极小值点；
- 求 $f(x,y) = x^2 y^2 + x \ln x$ 的极值，解驻点 $(1/e, 0)$ 并用 $AC-B^2$ 校验。
- **书目出处**：《基础30讲》第13讲第331~332页 [习题 13.5 & 13.12]

### 题型模型五：二阶混合偏导数双重积分还原模型

- **核心方法**：【核心解题模型与思维框架】：
  已知二阶混合偏导数 $f_{xy}''(x,y)$ 与边界条件 $f_x'(x,0), f(0,y)$，还原 $f(x,y)$ 并求极值。
  【双重不定积分还原模型】：
  1. **一重积分求一阶偏导**：$f_x'(x,y) = \int f_{xy}''(x,y) dy + C(x)$，代入边界条件 $f_x'(x,0)$ 确定未知函数 $C(x)$；
2. **二重积分还原原函数**：$f(x,y) = \int f_x'(x,y) dx + D(y)$，代入边界条件 $f(0,y)$ 确定未知函数 $D(y)$；
3. **极值校验**：对还原出的 $f(x,y)$ 求解驻点并用黑塞矩阵 $AC-B^2$ 校验极值。
- **典型例示**：【一题反应一类】：
  已知 $f_{xy}''(x,y) = 2(y+1)e^x, f_x'(x,0) = (x+1)e^x, f(0,y) = y^2 + 2y$。
*还原模型*：对 $y$ 积分得 $f_x' = (y^2+2y)e^x + C(x)$，代入得 $C(x)=e^x$；再对 $x$ 积分代入 $f(0,y)$ 还原得出 $f(x,y) = (y^2+2y+1)e^x - 1$。
- **书目出处**：《基础30讲》第13讲第332页 [习题 13.13]

### 题型模型六：拉格朗日乘数法条件极值与几何最值模型

- **核心方法**：【核心解题模型与思维框架】：
  求 $f(x,y)$ 在约束条件 $\varphi(x,y)=0$ 下的最值，或求曲线/曲面上的点到原点/平面的最长或最短距离。
  【拉格朗日最值模型】：
  1. **简化目标函数**：求距离最值时，将目标函数设为**距离平方** $f(x,y) = x^2+y^2$（省去根号求导）；
2. **构造拉格朗日函数**：$L(x,y,\lambda) = f(x,y) + \lambda \varphi(x,y)$；
3. **解驻点方程组**：

$$
\begin{cases} L_x' = 0 \\ L_y' = 0 \\ \varphi(x,y) = 0 \end{cases}
$$









解出全部候选点；
  4. **端点与驻点比大小**：比较各候选驻点与区域边界端点的函数值，最大者为最大值，最小者为最小值。
- **典型例示**：【一题反应一类】：
  求曲线 $x^3 - xy + y^3 = 1$ ($x \ge 0, y \ge 0$) 上的点到坐标原点的最长距离与最短距离。
*解法模型*：目标函数 $f(x,y) = x^2+y^2$，约束条件 $x^3-xy+y^3=1$。拉格朗日乘数法求得驻点 $x=y=1$（最短距离 $\sqrt{2}$），端点 $(1,0),(0,1)$（最长距离 1）。
- **书目出处**：《基础30讲》第13讲第332页 [习题 13.14]
