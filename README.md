# 考研数学二高效复习与错题复盘系统

这是一个基于 Obsidian 的考研数学二错题本、专题复盘与典型例题 Vault。笔记按资料类型、学科、章节和具体考点分层，保留原有顶层结构。

## 仓库结构

```text
考研数学/
├── 错题本/
│   └── 高等数学/
│       ├── 01-函数极限与连续/
│       ├── 02-一元函数微分学/
│       ├── 03-一元函数积分学/
│       ├── 04-多元函数微分学/
│       ├── 05-二重积分/
│       └── 06-常微分方程/
├── 专题复盘/
├── 典型例子/
├── 解题技巧与易错陷阱/
├── images/                  # 统一图片资源目录
└── .obsidian/                # Vault 配置与排版样式
```

## 笔记规范

- 每篇笔记使用 YAML frontmatter 标注 `type`、`tags`，正文从一级标题开始。
- 错题笔记按“为什么错 → 题目 → 解析与答案 → 易错点与核心考点”组织。
- 块级公式单独占行，使用成对的 `$$`；图片使用 `.images` 内部嵌入，避免外部临时路径断链。
- 复习主页位于 `错题本/高等数学/02-一元函数微分学/复习主页/复习主页.md`。
