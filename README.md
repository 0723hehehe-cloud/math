# 📐 考研数学二高效复习与错题复盘系统 (Obsidian Vault)

> 基于 Obsidian 构建的 2026 考研数学二结构化知识库、错题本与《基础30讲》专题复盘体系。

---

## 🌟 核心特色

- **🎯 诊断式错题管理**：每篇错题在最头部高亮标注 `❌ 为什么错（个人错因与盲区）`，直击思维盲区，杜绝重复踩坑。
- **📚 《基础30讲》专题串联**：跨章节梳理高频考点与秒杀公式（如 *极限定义的隐式分段函数*、*反三角函数和恒等式*、*交错振荡函数无界面积* 等）。
- **🎨 莫兰迪 3 级层级美化**：配套 `premium-notes.css`，左侧目录树按 **一级章节 (莫兰迪蓝)** $\to$ **二级考点 (莫兰迪橙)** $\to$ **三级笔记 (莫兰迪紫)** 渲染，视觉清晰舒展。
- **🔍 大屏大字号 LaTeX 渲染**：块级公式与行内公式精细放大优化，大屏观看清晰不拥挤。
- **📊 Dataview 动态复习看板**：主页内嵌 Dataview 语法，自动推荐每日待复习错题，按章节动态统计。

## 📝 错题笔记结构规范

每篇错题均遵循标准 Callouts 卡片排版：

1. **`> [!danger] ❌ 为什么错（个人错因与盲区）`**：（置于最顶部）记录真实做题误区。
2. **`> [!question] 题目`**：题目描述与高清题图。
3. **`> [!success] 解析与答案`**：完整推导步骤、关联知识点双链。
4. **`> [!warning] 易错点 & 核心考点`**：总结解题关键与避坑指南。

## 🚀 使用指南

1. **在 Obsidian 中打开**：
   打开 Obsidian $\to$ `Open folder as vault` $\to$ 选择本仓库目录即可。
2. **刷新样式**：
   若需载入最新的侧边栏配色与大字号公式，在 Obsidian 内按下 `Ctrl + R` 重新加载。
3. **查看动态主页**：
   点击打开 `复习主页.md` 即可查看每日推荐复习列表。
