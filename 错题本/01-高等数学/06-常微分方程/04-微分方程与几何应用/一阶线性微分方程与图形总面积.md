# 一阶线性微分方程与图形总面积

> [!danger] ❌ 为什么错（个人错因与盲区）
> - **核心错因**: 第二问求平面图形总面积 $A$ 时，漏掉了绝对值符号 $|y(x)|$（没考虑到 $y(x) = e^{-x} \sin x$ 在 $[0, +\infty)$ 上正负交替振荡，直接求积分 $\int_0^{+\infty} e^{-x} \sin x dx$ 导致正负面积相互抵消算错）。

> [!question] 题目
> 已知函数 $y(x)$ 满足微分方程 $y' + y = e^{-x} \cos x$，且满足初始条件 $y(0) = 0$。
> (1) 求 $y(x)$ 的解析式；
> (2) 求曲线 $y(x)$ 与 $x$ 轴在区间 $[0, +\infty)$ 上所围成图形的总面积 $A$。

> [!success] 解析与答案
> **相关知识点**: [[交错振荡函数图形面积与无穷等比求和]]
> 
> 本题的核心破局点是：**计算波包图形总面积必须带绝对值 $A = \int_0^{+\infty} e^{-x} |\sin x| dx$，利用单周期积分与无穷等比数列求和秒杀**。
> 
> ### (1) 求解一阶线性微分方程 $y(x)$
> 一阶线性微分方程标准形式为 $y' + P(x)y = Q(x)$，此处 $P(x) = 1$，$Q(x) = e^{-x} \cos x$。
> 积分因子为 $\mu(x) = e^{\int 1 dx} = e^x$。
> 方程两边同乘 $e^x$ 得：
> $$(e^x y)' = \cos x$$
> 两边积分得：
> $$e^x y = \int \cos x \, dx = \sin x + C \implies y(x) = e^{-x}(\sin x + C)$$
> 代入初始条件 $y(0) = 0$：
> $$0 = e^0 (\sin 0 + C) \implies C = 0$$
> 故 $y(x)$ 的解析式为：
> $$y(x) = e^{-x} \sin x$$
> 
> ---
> 
> ### (2) 求解曲线与 $x$ 轴围成的总面积 $A$
> **注意：几何面积必须加绝对值！** 
> 函数 $y(x) = e^{-x} \sin x$ 在区间 $[0, +\infty)$ 上随着 $\sin x$ 正负符号的交替变化，在 $x$ 轴上下交替振荡。
> 零点为 $x_k = k\pi \ (k = 0, 1, 2, \dots)$。
> 总面积为各分段面积的无限制绝对值和：
> $$A = \int_0^{+\infty} |y(x)| \, dx = \int_0^{+\infty} e^{-x} |\sin x| \, dx = \sum_{k=0}^{\infty} \int_{k\pi}^{(k+1)\pi} e^{-x} |\sin x| \, dx$$
> 
> #### 1. 计算第 $k$ 段面积 $A_k$
> 令 $t = x - k\pi$，当 $x \in [k\pi, (k+1)\pi]$ 时，$t \in [0, \pi]$。
> 此区间上 $|\sin x| = |\sin(t + k\pi)| = \sin t$（因为 $\sin t \ge 0$），
> 且 $e^{-x} = e^{-(t+k\pi)} = e^{-k\pi} e^{-t}$。
> 故：
> $$A_k = \int_{k\pi}^{(k+1)\pi} e^{-x} |\sin x| \, dx = e^{-k\pi} \int_0^{\pi} e^{-t} \sin t \, dt$$
> 
> #### 2. 计算首段单周期积分 $I_0$
> 利用分部积分法或公式 $\int e^{-t} \sin t \, dt = -\frac{1}{2} e^{-t}(\sin t + \cos t)$：
> $$I_0 = \int_0^{\pi} e^{-t} \sin t \, dt = \left[ -\frac{1}{2} e^{-t}(\sin t + \cos t) \right]_0^{\pi} = \frac{1 + e^{-\pi}}{2}$$
> 
> #### 3. 无穷等比数列求和
> $$A = \sum_{k=0}^{\infty} A_k = I_0 \sum_{k=0}^{\infty} (e^{-\pi})^k = \frac{1 + e^{-\pi}}{2} \cdot \frac{1}{1 - e^{-\pi}}$$
> 分子分母同乘 $e^\pi$ 化简得：
> $$A = \frac{e^\pi + 1}{2(e^\pi - 1)}$$
> 
> 答：
> (1) $y(x) = e^{-x} \sin x$；
> (2) 曲线与 $x$ 轴围成的总面积 $A = \frac{e^\pi + 1}{2(e^\pi - 1)}$。

> [!warning] 易错点 & 核心考点
> - **核心考点**: 一阶线性微分方程求解、交错振荡函数与 $x$ 轴围成图形总面积 (无穷等比数列求和)。
> - **解题关键**: 求图形面积必须带绝对值 $A = \int_a^b |y(x)| dx$；对于交错振荡函数 $e^{-ax}\sin(bx)$，拆成单周期积分 $I_0$ 后，利用公比为 $q = e^{-\frac{a\pi}{b}}$ 的无穷等比数列求和公式 $\sum_{k=0}^\infty q^k = \frac{1}{1-q}$ 秒杀。
> - **易错点**: 第二问直接求无绝对值的代数积分 $\int_0^{+\infty} e^{-x}\sin x dx = \frac{1}{2}$，导致正负波峰/波谷面积相互抵消。
