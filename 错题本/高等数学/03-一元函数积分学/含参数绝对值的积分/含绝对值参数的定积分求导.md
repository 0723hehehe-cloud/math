# 含绝对值参数的定积分求导

### ❌ 为什么错（个人错因与盲区）

- **核心错因**: 变限积分中含有绝对值 $|x-t|$，没有先通过换元 $u = x-t$ 或拆开积分区间消去绝对值符号就直接求导。

### 题目

设 $f(x) = \int_{0}^{1} t |t - x| \, dt$，求 $f'(x)$。
![题目图片](file:///D:/ob/考研数学/.images/media__1784425014075.png)

### 解析与答案

**相关知识点**: [[含参数绝对值的积分]]

本题的核心破局点是：**根据绝对值零点拆分积分区间，消去绝对值符号后再利用变限积分求导公式求导**。

**第一步：分析被积函数与参数讨论区间**
被积函数为 $g(t) = t|t-x|$，积分变量为 $t$，其范围为 $t \in [0, 1]$。 因为含有绝对值且带有参数 $x$，必须以 $t = x$ 作为绝对值正负号的分界点。由于 $t$ 的定义域为 $[0, 1]$，我们需要根据参数 $x$ 的位置分三种情况讨论： > 1. 当 $x \le 0$ 时 2. 当 $x \ge 1$ 时 3. 当 $0 < x < 1$ 时

---

**第二步：分区间展开计算积分 $f(x)$** > 1. **当 $x \le 0$ 时**： 对于任意 $t \in [0, 1]$，有 $t \ge 0 \ge x \implies t - x \ge 0$，因此 $|t-x| = t-x$。 ：
$$\displaystyle f(x) = \int_{0}^{1} t(t-x) \, dt = \int_{0}^{1} (t^2 - xt) \, dt = \left[ \frac{t^3}{3} - x\frac{t^2}{2} \right]_{0}^{1} = \frac{1}{3} - \frac{1}{2}x$$
   对 $x$ 求导得：
$$\displaystyle f'(x) = -\frac{1}{2}$$

2. **当 $x \ge 1$ 时**： 对于任意 $t \in [0, 1]$，有 $t \le 1 \le x \implies t - x \le 0$，因此 $|t-x| = x-t$。 ：
$$\displaystyle f(x) = \int_{0}^{1} t(x-t) \, dt = \int_{0}^{1} (xt - t^2) \, dt = \left[ x\frac{t^2}{2} - \frac{t^3}{3} \right]_{0}^{1} = \frac{1}{2}x - \frac{1}{3}$$
   对 $x$ 求导得：
$$\displaystyle f'(x) = \frac{1}{2}$$

3. **当 $0 < x < 1$ 时**： 此时分界点 $t = x$ 落在积分区间 $[0, 1]$ 内部，需在 $t = x$处断开积分：
$$\displaystyle f(x) = \int_{0}^{x} t|t-x| \, dt + \int_{x}^{1} t|t-x| \, dt$$
   - 在 $t \in [0, x]$ 时，$t \le x \implies |t-x| = x-t$； - 在 $t \in [x, 1]$ 时，$t \ge x \implies |t-x| = t-x$。 所以：
$$\displaystyle f(x) = \int_{0}^{x} t(x-t) \, dt + \int_{x}^{1} t(t-x) \, dt$ $\displaystyle \int_{0}^{x} t(x-t) \, dt = \left[ x\frac{t^2}{2} - \frac{t^3}{3} \right]_{0}^{x} = \frac{x^3}{2} - \frac{x^3}{3} = \frac{x^3}{6}$ $\displaystyle \int_{x}^{1} t(t-x) \, dt = \int_{x}^{1} (t^2 - xt) \, dt = \left[ \frac{t^3}{3} - x\frac{t^2}{2} \right]_{x}^{1} = \left( \frac{1}{3} - \frac{x}{2} \right) - \left( \frac{x^3}{3} - \frac{x^3}{2} \right) = \frac{1}{3} - \frac{x}{2} + \frac{x^3}{6}$ $\displaystyle \implies f(x) = \frac{x^3}{6} + \frac{1}{3} - \frac{x}{2} + \frac{x^3}{6} = \frac{x^3}{3} - \frac{x}{2} + \frac{1}{3}$$
   对 $x$ 求导得：
$$\displaystyle f'(x) = x^2 - \frac{1}{2}$$

---

**第三步：检验分界点处的连续性与导数存在性**
我们求出的分段导数表达式为： $$f'(x) = \begin{cases} $\displaystyle -\frac{1}{2}, & x < 0 \\$ $\displaystyle x^2 - \frac{1}{2}, & 0 < x < 1 \\$ $\displaystyle \frac{1}{2}, & x > 1$
\end{cases}$$
- **在 $x = 0$ 处**： 左导数 $f'_-(0) = -\frac{1}{2}$，右导数 $f'_+(0) = 0^2 - \frac{1}{2} = -\frac{1}{2}$。 因为左导数等于右导数，且原函数在该点连续，所以 $f'(0)$ 存在，且 $f'(0) = -\frac{1}{2}$。 - **在 $x = 1$ 处**： 左导数 $f'_-(1) = 1^2 - \frac{1}{2} = \frac{1}{2}$，右导数 $f'_+(1) = \frac{1}{2}$。 因为左导数等于右导数，且原函数在该点连续，所以 $f'(1)$ 存在，且 $f'(1) = \frac{1}{2}$。 > 综上所述，$f'(x)$ 在整个实数域内连续，其表达式为： $$f'(x) = \begin{cases} $\displaystyle -\frac{1}{2}, & x < 0 \\$ $\displaystyle x^2 - \frac{1}{2}, & 0 \le x \le 1 \\$ $\displaystyle \frac{1}{2}, & x > 1$
\end{cases}$$

---

**💡 极速秒杀技巧（变限积分直接求导法）**
在核心段 $0 < x < 1$ 中，写出分段积分后：
$$\displaystyle f(x) = \int_{0}^{x} t(x-t) \, dt + \int_{x}^{1} t(t-x) \, dt = x \int_{0}^{x} t \, dt - \int_{0}^{x} t^2 \, dt + \int_{x}^{1} t^2 \, dt - x \int_{x}^{1} t \, dt$$
直接对两边关于 $x$ 求导（利用变限积分求导公式）：
$$\displaystyle f'(x) = \left( 1 \cdot \int_{0}^{x} t \, dt + x \cdot x \right) - x^2 + (-x^2) - \left( 1 \cdot \int_{x}^{1} t \, dt + x \cdot (-x) \right)$ $\displaystyle = \int_{0}^{x} t \, dt - \int_{x}^{1} t \, dt = \left[ \frac{t^2}{2} \right]_{0}^{x} - \left[ \frac{t^2}{2} \right]_{x}^{1} = \frac{x^2}{2} - \left( \frac{1}{2} - \frac{x^2}{2} \right) = x^2 - \frac{1}{2}$$
这种方法**完全不需要求出具体的原函数**，在计算更复杂的题目时极其高效！

### 易错点 & 核心考点

- **核心考点**: 含参数绝对值的积分
- **解题关键**: 1. **参数区间分段讨论**：根据绝对值分界点 $t = x$ 与积分变量区间 $[0, 1]$ 的相对位置，分 $x \le 0$, $0 < x < 1$, $x \ge 1$ 进行讨论。 2. **变限积分直接求导**：在 $0 < x < 1$ 内，将参数 $x$ 提取出积分号后，直接应用变限积分求导公式和乘积求导法则求出 $f'(x)$，规避繁琐的定积分计算。 - **易错点**: 1. 漏掉 $x \le 0$ 或 $x \ge 1$ 两个区间的讨论。很多考生误以为只能讨论 $0 < x < 1$。 2. 提取参数 $x$ 时犯错。Leibniz 变限求导的前提是**被积函数中不能含有自变量 $x$**。所以必须把 $x$ 提到积分号外，如：$x \int_0^x t \, dt$，再按乘积求导法微分。
