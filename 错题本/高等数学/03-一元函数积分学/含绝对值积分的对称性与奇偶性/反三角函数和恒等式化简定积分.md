# 反三角函数和恒等式化简定积分

> [!danger] ❌ 为什么错（个人错因与盲区）
> - **核心错因**: 没有第一时间使用互余反三角函数恒等式 $\arcsin x + \arccos x = \frac{\pi}{2}$ 将分子直接化简为常数，而是试图硬算积分导致繁琐。

> [!question] 题目
> 计算定积分：
> ![题目图片](file:///D:/ob/考研数学/.images/media__1784793617349.png)

> [!success] 解析与答案
> **相关知识点**: [[反三角函数与三角函数和恒等式秒杀]]
> 
> 本题的核心破局点是：**第一时间利用互余反三角函数恒等式 $\arcsin x + \arccos x = \frac{\pi}{2}$ 将分子化简为常数**。 > 本题核心解题点在于：**观察到分子中包含 $\arcsin x + \arccos x$，不要硬算积分，直接利用反三角函数互余恒等式化简！**
> 
> ### 1. 利用互余恒等式直接化简分子
> 根据反三角函数基本恒等式，对于任意 $x \in [-1, 1]$ 均有：
> $$\displaystyle \arcsin x + \arccos x = \frac{\pi}{2}$$
> 将此恒等式直接代入原积分式中，原式化简为：
> $$\displaystyle \int_{-\frac{1}{2}}^{\frac{1}{2}} \frac{|x| \cdot \frac{\pi}{2}{\sqrt{1 - x^2} \, dx = \frac{\pi}{2} \int_{-\frac{1}{2}}^{\frac{1}{2}} \frac{|x|}{\sqrt{1 - x^2} \, dx$$
> 
> ### 2. 利用对称区间与函数奇偶性简化
> 被积函数 $f(x) = \frac{|x|}{\sqrt{1 - x^2}}$ 在对称区间 $\left[-\frac{1}{2}, \frac{1}{2}\right]$ 上为**偶函数**（因为 $|-x| = |x|$），故利用偶函数对称区间积分性质：
> $$\displaystyle \frac{\pi}{2} \int_{-\frac{1}{2}}^{\frac{1}{2}} \frac{|x|}{\sqrt{1 - x^2} \, dx = \frac{\pi}{2} \cdot 2 \int_0^{\frac{1}{2}} \frac{x}{\sqrt{1 - x^2}} \, dx = \pi \int_0^{\frac{1}{2}} \frac{x}{\sqrt{1 - x^2}} \, dx$$
> 
> ### 3. 凑微分求定积分
> 凑微分 $x dx = -\frac{1}{2} d(1 - x^2)$：
> $$\displaystyle \pi \int_0^{\frac{1}{2}} \frac{x}{\sqrt{1 - x^2}} \, dx = \pi \left[ -\sqrt{1 - x^2} \right]_0^{\frac{1}{2} = \pi \left( -\sqrt{1 - \frac{1}{4} - (-1) \right) = \pi \left( 1 - \frac{\sqrt{3}}{2} \right) = \frac{(2 - \sqrt{3})\pi}{2}$$
> 
> 填空题答案为 **$\pi \left( 1 - \frac{\sqrt{3}}{2} \right)$** （或 $\frac{(2-\sqrt{3})\pi}{2}$）。

> [!warning] 易错点 & 核心考点
> - **核心考点**: 互余反三角函数恒等式（$\arcsin x + \arccos x = \frac{\pi}{2}$）、偶函数对称区间定积分性质。 - **解题关键**: 看到 $\arcsin x + \arccos x$ 或 $\arctan x + \text{arccot } x$ 时，切记先用和恒等式替换为常数 $\frac{\pi}{2}$，将复杂反三角积分瞬间降维。
> - **易错点**: 忽视了最基础的恒等式，按分步积分法或分段拆开硬算，导致计算极其冗长且容易出错。
