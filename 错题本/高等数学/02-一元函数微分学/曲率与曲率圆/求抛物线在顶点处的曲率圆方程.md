# 求抛物线在顶点处的曲率圆方程

### ❌ 为什么错（个人错因与盲区）

- **核心错因**: 记错曲率半径公式 $R = \frac{(1+y'^2)^{3/2}}{|y''|}$，或在确定曲率圆圆心坐标 $(x_0, y_0)$ 时法线方向的加减号判定错误。

### 题目

曲线 $x^2 = y + 1$ 在点 $(0, -1)$ 的曲率圆方程为 ________。

![[images/media__1784710950436.png|题目图片]]

### 解析与答案

**相关知识点**: [[曲率与曲率圆]]

本题的核心破局点是：**先求出曲线在顶点处的曲率半径 $R = \frac{(1+y'^2)^{3/2}}{|y''|}$，再沿法线方向确定圆心坐标**。

**第一步：整理函数解析式并计算在给定点处的一阶与二阶导数**
将曲线方程整理为显函数形式：
$y = x^2 - 1$
在点 $M(0, -1)$ 处，自变量 $x_0 = 0$，因变量 $y_0 = -1$。
求一阶与二阶导数：
- $y' = 2x \implies y'(0) = 0$
- $y'' = 2 \implies y''(0) = 2$

---

**第二步：计算曲率 $K$ 与曲率半径 $\rho$** 将导数值代入曲率公式：
$K = \frac{|y''|}{(1 + y'^2)^{\frac{3}{2}}} = \frac{2}{(1 + 0^2)^{\frac{3}{2}}} = 2$
曲率半径为曲率的倒数：
$\rho = \frac{1}{K} = \frac{1}{2}$

---

**第三步：计算曲率中心坐标 $(\alpha, \beta)$**
- **方法一（公式法）**：
  将 $x_0 = 0, y_0 = -1, y' = 0, y'' = 2$ 直接代入曲率中心公式：
$\alpha = x_0 - \frac{y'(1 + y'^2)}{y''} = 0 - \frac{0 \cdot (1 + 0)}{2} = 0 \beta = y_0 + \frac{1 + y'^2}{y''} = -1 + \frac{1 + 0}{2} = -1 + \frac{1}{2} = -\frac{1}{2}$
  所以曲率中心为 $(0, -\frac{1}{2})$。
- **方法二（几何快速判定法，最推荐！）**：
由于在 $x=0$ 处的一阶导数 $y'=0$（切线为水平线），因此曲率中心必定落在过点 $M(0, -1)$ 的铅直线上，即 **$\alpha = x_0 = 0$**。 因为 $y'' = 2 > 0$（曲线凹，开口向上），曲率圆必定位于曲线的上方凹侧。
因此曲率中心纵坐标 $\beta$ 应该在点 $M$ 的上方距离 $\rho$ 处：
$\beta = y_0 + \rho = -1 + \frac{1}{2} = -\frac{1}{2}$
  直接得出曲率中心为 $(0, -\frac{1}{2})$。

---

**第四步：写出曲率圆方程**
圆心为 $(\alpha, \beta) = (0, -\frac{1}{2})$，半径 $R = \rho = \frac{1}{2}$。代入圆的标准方程：
$(x - 0)^2 + \left(y - \left(-\frac{1}{2}\right)\right)^2 = \left(\frac{1}{2}\right)^2$
即：
$x^2 + \left(y + \frac{1}{2}\right)^2 = \frac{1}{4}$
*(展开式为：$x^2 + y^2 + y = 0$)*

最终答案为：**$x^2 + \left(y + \frac{1}{2}\right)^2 = \frac{1}{4}$** （或 $x^2 + y^2 + y = 0$）。

### 易错点 & 核心考点

- **核心考点**: 曲率与曲率圆
- **解题关键**: 1. **求导数**：求出给定点处的一阶导数 $y'$ 和二阶导数 $y''$。
2. **算半径**：套用曲率半径公式 $\rho = \frac{(1+y'^2)^{3/2}}{|y''|}$。
3. **定圆心**：利用 $y'=0$ 切线水平的几何直观，结合 $y''>0$ 开口向上的几何凹凸性，直接定出圆心在点 $M$ 正上方 $\rho$ 距离处，避免死记硬背复杂的 $\beta$ 公式。
- **易错点**: 1. **曲率中心坐标公式中 $\beta$ 的正负号错乱**：直接背公式时，分母中的 $y''$ 带有正负号，极易搞错。最安全的方法是**使用几何直观**：$y''>0$ 向上加半径，$y''<0$ 向下减半径。
2. **曲率半径的平方漏掉**：在写圆的方程 $(x-\alpha)^2 + (y-\beta)^2 = R^2$ 时，右侧是**半径的平方** $\rho^2$，容易漏掉平方项直接写成 $\rho$。
