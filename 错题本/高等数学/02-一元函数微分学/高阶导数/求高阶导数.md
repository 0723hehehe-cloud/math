# 求高阶导数

### ❌ 为什么错（个人错因与盲区）

- **核心错因**: 在使用莱布尼茨公式展开 $(u v)^{(n)}$ 时，求导系数 $\binom{n}{k}$ 计算失误，或没有选择最高阶次有限的因子作为 $v$。

### 题目

设 $f(x) = x^2 \ln(1-x)$，则当 $n \ge 3$ 时， $f^{(n)}(0) = (\quad)$。

![题目图片](file:///D:/ob/考研数学/.images/media__1783933020289.png)

### 解析与答案

**相关知识点**: [[高阶导数]]

本题的核心破局点是：**利用莱布尼茨公式 $(uv)^{(n)} = \sum C_n^k u^{(k)} v^{(n-k)}$ 将复杂乘积分解为简单初等函数的高阶导数**。

### 方法一：麦克劳林展开式（泰勒公式）

已知当 $|x| < 1$ 时，对数函数的麦克劳林展开式为：
$\ln(1-x) = -\sum_{k=1}^{\infty} \frac{x^k}{k} = -x - \frac{x^2}{2} - \frac{x^3}{3} - \dots - \frac{x^{n-2}}{n-2} - \dots$

将上述展开式两边同乘以 $x^2$，可得 $f(x)$ 的展开式为：
$f(x) = x^2 \ln(1-x) = -x^2 \sum_{k=1}^{\infty} \frac{x^k}{k} = -\sum_{k=1}^{\infty} \frac{x^{k+2}}{k}$

令展开式中的幂次 $n = k+2$，则 $k = n-2$。由于对数展开式中 $k \ge 1$，故对应幂次 $n \ge 3$。所以：
$f(x) = -\sum_{n=3}^{\infty} \frac{x^n}{n-2}$

而根据麦克劳林公式的一般形式：
$f(x) = \sum_{n=0}^{\infty} \frac{f^{(n)}(0)}{n!} x^n$

对比两个数列/泰勒公式中 $x^n$（$n \ge 3$）的对应系数，可得：
$\frac{f^{(n)}(0)}{n!} = -\frac{1}{n-2}$

解得：
$f^{(n)}(0) = -\frac{n!}{n-2}$

故本题的正确答案为 **(A)**。

---

### 方法二：莱布尼茨求导公式

设 $u(x) = x^2$，$v(x) = \ln(1-x)$。
易求得其各阶导数为：
- $u'(x) = 2x$
- $u''(x) = 2$
- $u^{(k)}(x) = 0$（当 $k \ge 3$ 时） > 根据莱布尼茨求导公式，当 $n \ge 3$ 时：
$f^{(n)}(x) = \sum_{k=0}^{n} \binom{n}{k} u^{(k)}(x) v^{(n-k)}(x) = \binom{n}{0} u(x) v^{(n)}(x) + \binom{n}{1} u'(x) v^{(n-1)}(x) + \binom{n}{2} u''(x) v^{(n-2)}(x)$

代入 $x=0$，由于 $u(0) = 0$，$u'(0) = 0$，上式中前两项在 $0$ 处的值均为 $0$，故仅剩下最后一项：
$f^{(n)}(0) = \binom{n}{2} u''(0) v^{(n-2)}(0) = \frac{n(n-1)}{2} \cdot 2 \cdot v^{(n-2)}(0) = n(n-1) v^{(n-2)}(0)$

下面求 $v(x) = \ln(1-x)$ 的各阶导数在 $x=0$ 处的值： - $v'(x) = -(1-x)^{-1}$
- $v''(x) = -(1-x)^{-2}$
- $v'''(x) = -2!(1-x)^{-3}$
- 一般地，当 $j \ge 1$ 时：
$v^{(j)}(x) = -(j-1)!(1-x)^{-j}$

代入 $j = n-2$（由于 $n \ge 3$，此时 $j \ge 1$）：
$v^{(n-2)}(0) = -(n-3)!$

将此结果代回 $f^{(n)}(0)$ 的式中，可得：
$f^{(n)}(0) = n(n-1) \left[ -(n-3)! \right] = -n(n-1)(n-3)!$

进一步化简：
$-n(n-1)(n-3)! = -\frac{n(n-1)(n-2)(n-3)!}{n-2} = -\frac{n!}{n-2}$

所以当 $n \ge 3$ 时，$f^{(n)}(0) = -\frac{n!}{n-2}$。故正确选项为 **(A)**。

### 易错点 & 核心考点

- **核心考点**: 高阶导数
- **解题关键**: 利用麦克劳林展开式（泰勒公式）法求 $f^{(n)}(0)$ 通常比莱布尼茨公式法更为简便，核心在于对比 $x^n$ 的系数 $\frac{f^{(n)}(0)}{n!}$。
- **易错点**: 1. 对数展开式中的负号不可漏掉：$\ln(1-x) = -\sum \frac{x^k}{k}$；
2. 在使用莱布尼茨公式时，注意 $v^{(n-2)}(0)$ 的符号和阶乘数，容易写错成 $-(n-2)!$。
