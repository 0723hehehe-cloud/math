# 多元函数微分学全书复盘 总结复盘

> [!info] 涉及知识点
> - **五大基本概念及其五大逻辑关系链**：
>   在多元函数（以 $z=f(x,y)$ 为例）中，五大基本概念的判定与逻辑关联为：
>   $$\text{偏导数连续} \implies \text{函数可微} \implies \begin{cases} \text{偏导数存在} \\ \text{函数连续} \implies \text{极限存在} \end{cases}$$
>   *注：偏导数存在与函数连续之间无必然因果关系。*
> - **定义法检验“在 $(x_0,y_0)$ 处可微”的三步判定树**：
>   1. **求偏导数**：$A = f_x(x_0,y_0) = \lim_{\Delta x \to 0} \frac{f(x_0+\Delta x, y_0) - f(x_0,y_0)}{\Delta x}$，$B = f_y(x_0,y_0)$；若偏导数不存在，则必不可微！
>   2. **写全增量与线性增量**：$\Delta z = f(x_0+\Delta x, y_0+\Delta y) - f(x_0,y_0)$，线性增量为 $A\Delta x + B\Delta y$；
>   3. **计算极限**：计算关键极限：
>      $$\lim_{(\Delta x, \Delta y) \to (0,0)} \frac{\Delta z - (A\Delta x + B\Delta y)}{\sqrt{\Delta x^2 + \Delta y^2}}$$
>      若该极限存在且等于 **0**，则 $z=f(x,y)$ 在 $(x_0,y_0)$ 处**可微**；若不为 0 或极限不存在，则**不可微**。
> - **无条件极值判定法（黑塞矩阵 $AC-B^2$ 法）**：
>   设 $(x_0,y_0)$ 为驻点（$f_x=0, f_y=0$），令 $A = f_{xx}'', B = f_{xy}'', C = f_{yy}''$，计算判别式 $\Delta = AC - B^2$：
>   - 若 $AC - B^2 > 0$：当 $A < 0$ 时为**极大值**；当 $A > 0$ 时为**极小值**。
>   - 若 $AC - B^2 < 0$：**不是极值点**（鞍点）。
>   - 若 $AC - B^2 = 0$：**方法失效**，需改用定义法或其他方法判定。
> - **条件极值与拉格朗日乘数法**：
>   求 $z=f(x,y)$ 在约束条件 $\varphi(x,y)=0$ 下的极值：
>   构造拉格朗日函数：$L(x,y,\lambda) = f(x,y) + \lambda \varphi(x,y)$，联立方程组求驻点：
>   $$\begin{cases} L_x' = f_x' + \lambda \varphi_x' = 0 \\ L_y' = f_y' + \lambda \varphi_y' = 0 \\ L_\lambda' = \varphi(x,y) = 0 \end{cases}$$

> ### 题型一：多元函数概念判定（极限、连续、偏导数存在、可微）
> - **核心方法**：【题目特征】：选择题给出分段函数或绝对值函数，判断在原点 $(0,0)$ 处极限是否存在、是否连续、偏导数是否存在及是否可微。
>   【判定套路】：
>   1. **重极限存在**：沿任意路径趋近极限均相同。常用沿直线 $y=kx$ 检验，若结果含 $k$ 则极限不存在；
>   2. **偏导数存在**：必须严格用一元导数定义求 $f_x(0,0) = \lim_{x \to 0} \frac{f(x,0)-f(0,0)}{x}$；
>   3. **可微判定**：求出 $A=f_x(0,0), B=f_y(0,0)$ 后，检验极限 $\lim_{(\Delta x, \Delta y)\to(0,0)} \frac{\Delta z - A\Delta x - B\Delta y}{\sqrt{\Delta x^2+\Delta y^2}}$ 是否为 0。
> - **典型例示**：函数 $f(x,y) = \sqrt{\lvert xy \rvert}$ 在 $(0,0)$ 点处偏导数存在，但不可微。
>   *证明简示*：$f_x(0,0)=0, f_y(0,0)=0$，但 $\lim_{\Delta x \to 0} \frac{\sqrt{|\Delta x \cdot \Delta x|}}{\sqrt{\Delta x^2 + \Delta x^2}} = \frac{1}{\sqrt{2}} \ne 0$，故不可微。
> - **书目出处**：《基础30讲》第13讲第331页 [基础习题精练 13.1 & 13.3]
> ### 题型二：多元复合函数与隐函数偏导数/全微分计算
> - **核心方法**：【题目特征】：给定复合函数 $z = f(u,v)$ 或隐函数方程 $F(x,y,z)=0$，求一阶、二阶偏导数或全微分 $dz$。
>   【计算套路】：
>   1. **画树状结构图**：区分自变量、中间变量与因变量；
>   2. **链式法则求导**：对自变量求偏导时，沿着每一条到达该自变量的路径求导并相加；
>   3. **隐函数公式法**：若 $F(x,y,z)=0$，则 $\frac{\partial z}{\partial x} = -\frac{F_x'}{F_z'}, \frac{\partial z}{\partial y} = -\frac{F_y'}{F_z'}$；也可以对方程两边同时求全微分 $dF = 0$ 解出 $dz$。
> - **典型例示**：设 $z = z(x,y)$ 由 $(z+y)^x = x^2$ 确定，求 $\left.\frac{\partial z}{\partial x}\right|_{(1,1)}$。
>   *解法简示*：两边取对数 $x \ln(z+y) = 2 \ln x$，对 $x$ 求偏导代入 $(1,1,0)$ 解得偏导数。
> - **书目出处**：《基础30讲》第13讲第331~332页 [基础习题精练 13.4, 13.8, 13.9]
> ### 题型三：多元函数的无条件极值判定与计算（$AC-B^2$ 法）
> - **核心方法**：【题目特征】：求二元无约束函数 $z = f(x,y)$ 的极值点与极值。
>   【计算套路】：
>   1. **求驻点**：解方程组 $\begin{cases} f_x'(x,y) = 0 \\ f_y'(x,y) = 0 \end{cases}$ 得驻点 $(x_0,y_0)$；
>   2. **求二阶偏导数**：计算 $A = f_{xx}''(x_0,y_0), B = f_{xy}''(x_0,y_0), C = f_{yy}''(x_0,y_0)$；
>   3. **判别式检验**：计算 $\Delta = AC - B^2$。若 $\Delta > 0$，且 $A < 0$ 为极大值；$A > 0$ 为极小值。
> - **典型例示**：求二元函数 $f(x,y) = x^2 y^2 + x \ln x$ 的极值。
>   *解法简示*：解出驻点并代入黑塞矩阵判别式 $AC-B^2$ 进行检验。
> - **书目出处**：《基础30讲》第13讲第332页 [基础习题精练 13.5 & 13.12]
> ### 题型四：条件极值与拉格朗日乘数法（几何/代数最值应用）
> - **核心方法**：【题目特征】：求 $f(x,y)$ 在约束条件 $\varphi(x,y)=0$ 下的最值，或求几何图形（曲线/曲面）上的点到原点/平面的最大、最小距离。
>   【解题套路】：
>   1. 建立目标函数 $f(x,y)$（如距离平方 $x^2+y^2$）；
>   2. 构造拉格朗日函数 $L(x,y,\lambda) = f(x,y) + \lambda \varphi(x,y)$；
>   3. 求偏导联立方程组 $\begin{cases} L_x' = 0 \\ L_y' = 0 \\ \varphi(x,y) = 0 \end{cases}$ 解出所有候选点；
>   4. 比较各候选点的函数值，最大者为最大值，最小者为最小值。
> - **典型例示**：求曲线 $x^3 - xy + y^3 = 1$ ($x \ge 0, y \ge 0$) 上的点到坐标原点的最长距离与最短距离。
>   *解法简示*：目标函数 $f(x,y) = x^2+y^2$，约束条件 $x^3-xy+y^3-1=0$，构造拉格朗日乘数法求解。
> - **书目出处**：《基础30讲》第13讲第332页 [基础习题精练 13.14]
> ### 题型一：多元函数概念判定（重极限存在性、连续性、偏导数存在性、可微性）
> - **核心方法**：【题目特征】：分段函数或绝对值函数，判断在原点 $(0,0)$ 处极限是否存在、是否连续、偏导数是否存在及是否可微。
>   【判定套路】：
>   1. **重极限存在**：沿任意路径趋近极限均相同。常用沿直线 $y=kx$ 检验，若结果含 $k$ 则极限不存在；
>   2. **偏导数存在**：必须严格用一元导数定义求 $f_x(0,0) = \lim_{x \to 0} \frac{f(x,0)-f(0,0)}{x}$；
>   3. **可微判定**：求出 $A=f_x(0,0), B=f_y(0,0)$ 后，检验极限 $\lim_{(\Delta x, \Delta y)\to(0,0)} \frac{\Delta z - A\Delta x - B\Delta y}{\sqrt{\Delta x^2+\Delta y^2}}$ 是否为 0。
> - **典型例示**：(1) $f(x,y)=\frac{x^2 y}{x^2+y^2}$ 在 $(0,0)$ 连续，而 $\frac{xy}{x^2+y^2}$ 与 $\frac{x^2 y}{x^4+y^2}$ 不连续；
>   (2) $f(x,y) = \sqrt{\lvert xy \rvert}$ 在 $(0,0)$ 偏导数存在且均为 0，但增量极限沿 $y=x$ 趋近为 $\frac{1}{\sqrt{2}} \ne 0$，故不可微。
> - **书目出处**：《基础30讲》第13讲第331页 [基础习题精练 13.1 & 13.3]
> ### 题型二：已知偏导数符号比较多元函数值大小（路径单调性放缩法）
> - **核心方法**：【题目特征】：已知 $f_x'(x,y) > 0, f_y'(x,y) < 0$，比较 $f(0,1)$ 与 $f(1,0)$ 等不同点处函数值的大小。
>   【判定套路】：
>   利用偏导数的物理意义：$f_x' > 0$ 表示沿 $x$ 轴正方向单调递增；$f_y' < 0$ 表示沿 $y$ 轴正方向单调递减。采用**两步折线路径**比较：如由 $(0,1) \to (1,1) \to (1,0)$，由 $f_x' > 0 \implies f(0,1) < f(1,1)$；由 $f_y' < 0 \implies f(1,1) < f(1,0)$，传递得出 $f(0,1) < f(1,0)$。
> - **典型例示**：设 $f(x,y)$ 满足 $f_x' > 0, f_y' < 0$，证明 $f(0,1) < f(1,0)$。
>   *解法简示*：取路径 $(0,1) \to (1,1) \to (1,0)$ 连不等式即可。
> - **书目出处**：《基础30讲》第13讲第331页 [基础习题精练 13.2]
> ### 题型三：多元复合函数与隐函数一阶/二阶偏导数及全微分计算
> - **核心方法**：【题目特征】：给定复合函数 $z = f(u,v)$ 或隐函数方程 $F(x,y,z)=0$，求偏导数或全微分 $dz$。
>   【计算套路】：
>   1. **链式法则**：画树状图，对自变量求偏导沿着到达该变量的所有路径求导相加；如 $z=f(xy, \ln x + g(xy))$ 时 $x z_x' - y z_y' = f_2'$；
>   2. **全微分求法**：$dz = f_x' dx + f_y' dy$。遇到 $z = f(4x^2-y^2)$，代入 $f'(0)=\frac{1}{2}$ 直接得 $\left.dz\right|_{(1,2)} = 4dx - 2dy$；
>   3. **隐函数求导**：对 $(z+y)^x = x^2$ 两边取对数 $x \ln(z+y) = 2 \ln x$，对 $x$ 求偏导代入点解得结果。
> - **典型例示**：设 $z = z(x,y)$ 由 $(z+y)^x = x^2$ 确定，求 $\left.\frac{\partial z}{\partial x}\right|_{(1,1)}$。
>   *解法简示*：代入 $(1,1)$ 时 $z=0$，求导得出偏导数等于 2。
> - **书目出处**：《基础30讲》第13讲第331~332页 [基础习题精练 13.4, 13.7, 13.8, 13.9, 13.10, 13.11]
> ### 题型四：多元函数的无条件极值判定与计算（黑塞矩阵 $AC-B^2$ 法）
> - **核心方法**：【题目特征】：求二元无约束函数 $z = f(x,y)$ 的极值点与极值，或判断非光滑点 $z_1=|x+y|$ 的极值。
>   【计算套路】：
>   1. **光滑函数黑塞矩阵法**：解驻点方程 $\begin{cases} f_x' = 0 \\ f_y' = 0 \end{cases}$，求二阶偏导 $A=f_{xx}'', B=f_{xy}'', C=f_{yy}''$。算 $\Delta = AC-B^2$：$\Delta > 0$ 时 $A<0$ 为极大值，$A>0$ 为极小值；
>   2. **绝对值非光滑点**：如 $z_1 = |x+y| \ge 0 = z_1(0,0)$，由绝对值定义直接判定 $(0,0)$ 为极小值点。
> - **典型例示**：(1) $z_1 = |x+y|$ 在 $(0,0)$ 为极小值点；$dz_2 = (3x^2+6x)dx - (3y^2-6y)dy$ 在 $(0,0)$ 处 $A=6, C=6, AC-B^2=36 > 0$，亦为极小值点；
>   (2) 求 $f(x,y) = x^2 y^2 + x \ln x$ 的极值，解得驻点 $(1/e, 0)$ 并用 $AC-B^2$ 判定。
> - **书目出处**：《基础30讲》第13讲第331~332页 [基础习题精练 13.5 & 13.12]
> ### 题型五：二阶混合偏导数积分还原原函数及极值求解
> - **核心方法**：【题目特征】：已知二阶偏导数 $f_{xy}''(x,y)$ 及边界条件 $f_x'(x,0)$ 与 $f(0,y)$，求原函数 $f(x,y)$ 及极值。
>   【解题套路】：
>   1. **对 $y$ 不定积分**：$f_x'(x,y) = \int f_{xy}''(x,y) dy + C(x)$，代入 $f_x'(x,0)$ 确定任意函数 $C(x)$；
>   2. **对 $x$ 不定积分**：$f(x,y) = \int f_x'(x,y) dx + D(y)$，代入 $f(0,y)$ 确定任意函数 $D(y)$ 还原出 $f(x,y)$；
>   3. **求极值**：根据还原出的原函数求驻点，代入 $AC-B^2$ 进行检验。
> - **典型例示**：已知 $f_{xy}''(x,y) = 2(y+1)e^x, f_x'(x,0) = (x+1)e^x, f(0,y) = y^2 + 2y$，求 $f(x,y)$ 及其极值。
>   *解法简示*：积分还原得 $f(x,y) = (y^2+2y+1)e^x - 1$，进一步求解驻点与极值。
> - **书目出处**：《基础30讲》第13讲第332页 [基础习题精练 13.13]
> ### 题型六：条件极值与拉格朗日乘数法（几何/代数最值应用）
> - **核心方法**：【题目特征】：求 $f(x,y)$ 在约束条件 $\varphi(x,y)=0$ 下的最值，或求曲线 $x^3-xy+y^3=1$ 上的点到坐标原点的最长/最短距离。
>   【解题套路】：
>   1. 建立目标函数（距离平方 $f(x,y) = x^2+y^2$）；
>   2. 构造拉格朗日函数 $L(x,y,\lambda) = x^2+y^2 + \lambda (x^3-xy+y^3-1)$；
>   3. 求偏导联立方程组 $\begin{cases} L_x' = 2x + \lambda (3x^2-y) = 0 \\ L_y' = 2y + \lambda (3y^2-x) = 0 \\ x^3-xy+y^3 = 1 \end{cases}$ 解出所有候选点；
>   4. 比较各候选点函数值得出最大值与最小值。
> - **典型例示**：求曲线 $x^3 - xy + y^3 = 1$ ($x \ge 0, y \ge 0$) 上的点到坐标原点的最长距离与最短距离。
>   *解法简示*：用拉格朗日乘数法求得极值点 $x=y=1$（最短距离为 $\sqrt{2}$），端点 $(1,0)$ 与 $(0,1)$ 最长距离为 1。
> - **书目出处**：《基础30讲》第13讲第332页 [基础习题精练 13.14]
