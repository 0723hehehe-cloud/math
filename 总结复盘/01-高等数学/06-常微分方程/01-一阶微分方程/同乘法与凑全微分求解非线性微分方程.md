# 同乘法与凑全微分求解非线性微分方程 总结复盘

> [!info] 涉及知识点
> - **概念定义**：在考研微分方程中，有一类看起来无法分离变量的“非线性方程”，只要通过**两边同乘某个因子**，就能利用复合求导公式把 $y' f'(y)$ 凑成 $(f(y))'$，从而通过换元 $u = f(y)$ **秒化为标准一阶线性微分方程**！
> 
> - **三大核心同乘秒杀模式**：
>   1. **指数型（同乘 $e^y$）**：
>      $$y' + P(x) = Q(x) e^{-y} \xrightarrow{\times e^y} e^y y' + P(x) e^y = Q(x) \implies (e^y)' + P(x) e^y = Q(x)$$
>      令 $u = e^y$，方程化为 $u' + P(x)u = Q(x)$。
>   2. **幂函数型/一阶非线性微分方程（换元法）（同乘 $y^{-n}$）**：
>      $$y' + P(x) y = Q(x) y^n \xrightarrow{\times y^{-n}} y^{-n}y' + P(x) y^{1-n} = Q(x)$$
>      令 $u = y^{1-n}$，则 $u' = (1-n) y^{-n} y'$，化为一阶线性。
>   3. **三角函数型（同乘 $\cos y$ 或 $\sec^2 y$）**：
>      $$y' + P(x) \tan y = Q(x) \sec y \xrightarrow{\times \cos y} \cos y y' + P(x) \sin y = Q(x)$$
>      令 $u = \sin y$，则 $u' = \cos y y'$，化为一阶线性。

> [!todo] 核心题型与解法
> ### 题型一：同乘 $e^y$ 求解非线性方程
> - **核心方法**：同乘 $e^y$ 凑出 $(e^y)' + e^y = Q(x)$，令 $u = e^y$ 解一阶线性方程。
> - **典型例示**：$y' + 1 = e^{-y}\sin x \implies (e^y)' + e^y = \sin x \implies e^y = \frac{1}{2}(\sin x - \cos x) + C e^{-x}$。
> - **书目出处**：《基础30讲》第12讲第254页 [一阶非线性微分方程变换]
> 
> ### 题型二：一阶非线性微分方程（换元法）（同乘 $y^{-n}$）
> - **核心方法**：同乘 $y^{-n}$，令 $u = y^{1-n}$ 转化。
> - **典型例示**：$y' + \frac{y}{x} = x y^2 \xrightarrow{\times y^{-2}} y^{-2}y' + \frac{1}{x} y^{-1} = x \implies \frac{1}{y} = C x - x^2$。
> - **书目出处**：《基础30讲》第12讲第255页 [一阶非线性微分方程（换元法）]
