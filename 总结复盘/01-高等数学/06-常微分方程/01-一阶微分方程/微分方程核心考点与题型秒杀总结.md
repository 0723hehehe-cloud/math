# 微分方程核心考点与题型秒杀总结

> [!info] 数二微分方程考纲地图与决策树
> 考研数学二对微分方程的考察极为集中且规律性强，**严格遵循 4 种基本类型 + 2 种降阶模式 + 2 种常系数非齐次特解设法**。
> 
> ### 🌳 微分方程解题一维决策树
> 1. **看阶数与结构**：
>    - **一阶微分方程** $\to$ 分离变量法 / 齐次换元法 ($u=\frac{y}{x}$) / 一阶线性通解公式 / 同乘 $e^y$ 凑导数法。
>    - **可降阶高阶方程** $\to$ 不显含 $y$ ($y'=p$) / 不显含 $x$ ($y'=p, y''=p\frac{dp}{dy}$)。
>    - **二阶常系数线性方程** $\to$ 特征方程法求齐次解 + 待定系数法求特解。
>    - **变限积分方程** $\to$ 先求初值 $y(0)$，再两边求导转化为一阶线性微分方程。

> [!todo] 一、一阶微分方程四大核心解法（数二必备）

### 1. 可分离变量微分方程
- **标准形式**：$\frac{dy}{dx} = f(x)g(y)$
- **秒杀步骤**：将同类变量移至同侧 $\frac{1}{g(y)} dy = f(x) dx \implies \int \frac{1}{g(y)} dy = \int f(x) dx + C$。

### 2. 齐次微分方程
- **标准形式**：$\frac{dy}{dx} = \varphi\left(\frac{y}{x}\right)$
- **秒杀步骤**：
  1. 令 $u = \frac{y}{x} \implies y = ux \implies \frac{dy}{dx} = u + x \frac{du}{dx}$。
  2. 代入得 $u + x \frac{du}{dx} = \varphi(u) \implies \frac{du}{\varphi(u) - u} = \frac{dx}{x}$。
  3. 积分后再将 $u = \frac{y}{x}$ 代回。

### 3. 一阶线性微分方程（核心重中之重）
- **标准形式**：$y' + P(x)y = Q(x)$
- **通用公式**：
  $$y(x) = e^{-\int P(x)dx} \left[ \int Q(x) e^{\int P(x)dx} dx + C \right]$$
- **变限积分表达法**（当 $Q(x)$ 积不出初等函数时）：
  $$y(x) = e^{-\int_a^x P(t)dt} \left[ \int_a^x Q(t) e^{\int_a^t P(u)du} dt + C \right]$$

### 4. 同乘凑导数法（非线性转化为线性）
- **模式**：$y' + P(x) = Q(x) e^{-y} \xrightarrow{\times e^y} e^y y' + P(x) e^y = Q(x) \implies (e^y)' + P(x) e^y = Q(x)$。
- **解法**：令 $u = e^y \implies u' + P(x) u = Q(x)$，化为一阶线性。

> [!todo] 三、二阶常系数线性微分方程（通解与特解）

### 1. 齐次方程 $y'' + p y' + q y = 0$
特征方程：$r^2 + p r + q = 0$，判别式 $\Delta = p^2 - 4q$：
1. **$\Delta > 0$（两个不等实根 $r_1 \neq r_2$）**：$y = C_1 e^{r_1 x} + C_2 e^{r_2 x}$
2. **$\Delta = 0$（两个相等实根 $r_1 = r_2 = r$）**：$y = (C_1 + C_2 x) e^{r x}$
3. **$\Delta < 0$（一对共轭复根 $r_{1,2} = \alpha \pm i \beta$）**：$y = e^{\alpha x} (C_1 \cos \beta x + C_2 \sin \beta x)$

### 2. 非齐次方程 $y'' + p y' + q y = f(x)$ 特解设法

#### 类型 I：$f(x) = P_m(x) e^{\lambda x}$
- **特解设法**：$y^* = x^k Q_m(x) e^{\lambda x}$
- **$k$ 的判定**：
  - 若 $\lambda$ **不是**特征根 $\implies k = 0$
  - 若 $\lambda$ 是**单特征根** $\implies k = 1$
  - 若 $\lambda$ 是**双重特征根** $\implies k = 2$

#### 类型 II：$f(x) = e^{\alpha x} [P_m(x) \cos \beta x + P_n(x) \sin \beta x]$
- **特解设法**：$y^* = x^k e^{\alpha x} [R_l(x) \cos \beta x + S_l(x) \sin \beta x]$，其中 $l = \max(m, n)$。
- **$k$ 的判定**：
  - 若 $\alpha \pm i \beta$ **不是**特征根 $\implies k = 0$
  - 若 $\alpha \pm i \beta$ 是**特征根** $\implies k = 1$

> [!warning] 四、考研高频陷阱与避坑指南

1. **求图形面积/旋转体积综合题**：
   - 看到面积必须加绝对值：$A = \int_a^b |y(x)| dx$。
   - 二重积分中出现 $f\left(\sqrt{x^2+y^2}\right) \to$ 第一时间转极坐标降维为一元积分。
2. **积分方程求导法则**：
   - $\frac{d}{dx} \int_0^x u f(u) du = x f(x)$；
   - 两边求导前，务必先代入 $x=0$ 求出初始条件 $y(0) = y_0$！
