# 反三角函数与三角函数和恒等式秒杀 总结复盘

> [!info] 涉及知识点
> - **概念定义**：在考研数学的求极限、求导数与定积分计算中，常常出现多个反三角函数或三角函数相加的复合结构。**凡是能直接加出常数（如 $\frac{\pi}{2}, \pi, 1$）的恒等式，必须在第一步直接化简**，避免进入繁琐的求导或分部积分误区。
> 
> - **核心常用加法/和恒等式汇总（必背）**：
>   - **1. 互余反三角函数常数和**： $\displaystyle \arcsin x + \arccos x = \frac{\pi}{2} \quad (|x| \le 1)$ $\displaystyle \arctan x + \text{arccot } x = \frac{\pi}{2} \quad (x \in \mathbb{R})$ $\displaystyle \arctan x + \arctan \frac{1}{x} = \begin{cases} \frac{\pi}{2}, & x > 0 \\ -\frac{\pi}{2}, & x < 0 \end{cases}$
>   - **2. 反三角函数对称负号和**： $\displaystyle \arccos x + \arccos(-x) = \pi \quad (|x| \le 1)$ $\displaystyle \text{arccot } x + \text{arccot}(-x) = \pi \quad (x \in \mathbb{R})$ $\displaystyle \arcsin(-x) = -\arcsin x \implies \arcsin x + \arcsin(-x) = 0$ $\displaystyle \arctan(-x) = -\arctan x \implies \arctan x + \arctan(-x) = 0$
>   - **3. 三角函数平方和与倍角和**： $\displaystyle \sin^2 x + \cos^2 x = 1, \quad 1 + \tan^2 x = \sec^2 x, \quad 1 + \cot^2 x = \csc^2 x$ $\displaystyle 1 + \cos 2x = 2\cos^2 x, \quad 1 - \cos 2x = 2\sin^2 x$ $\displaystyle \sin x + \cos x = \sqrt{2} \sin\left(x + \frac{\pi}{4}\right)$
> 
> - **强化核心：输入关键词 $\to$ 输出秒杀方法**：
>   - 看到 $\arcsin x + \arccos x \to$ 直接替换为常数 $\frac{\pi}{2}$
>   - 看到 $\arctan x + \text{arccot } x \to$ 直接替换为常数 $\frac{\pi}{2}$
>   - 对称区间积分包含 $\arccos x \to$ 换元 $x = -t$ 后两式相加，利用 $\arccos x + \arccos(-x) = \pi$ 消除反三角函数

> [!todo] 核心题型与解法
> ### 题型一：反三角函数互余/和恒等式直接化简求定积分
> - **核心方法**：在定积分中看到 $\arcsin x + \arccos x$ 或 $\arctan x + \text{arccot } x$，直接用 $\frac{\pi}{2}$ 替换提出来，将积分转化为纯代数或偶函数积分。
> - **典型例示**：$\int_{-\frac{1}{2}}^{\frac{1}{2}} \frac{|x|(\arcsin x + \arccos x)}{\sqrt{1-x^2}} dx = \frac{\pi}{2} \int_{-\frac{1}{2}}^{\frac{1}{2}} \frac{|x|}{\sqrt{1-x^2}} dx = \pi \left(1 - \frac{\sqrt{3}}{2}\right)$。
> - **书目出处**：《基础30讲》第1讲第14页 [反三角函数性质] 及 《基础30讲》第6讲第142页 [定积分计算技巧]
> 
> ### 题型二：对称区间积分中利用 $x = -t$ 构造相加化简（区间再现法）
> - **核心方法**：积分区间为 $[-a, a]$，被积函数中含有单项 $\arccos x$。设 $x = -t$，原积分变为 $I = \int_{-a}^a f(-t) \arccos(-t) dt$。利用 $\arccos(-t) = \pi - \arccos t$，将两式相加 $2I$ 即可消去 $\arccos t$。
> - **典型例示**：计算 $\int_{-1}^1 \frac{x^2 \arccos x}{\sqrt{1-x^2}} dx$。令 $x = -t$，相加得 $2I = \pi \int_{-1}^1 \frac{x^2}{\sqrt{1-x^2}} dx$，求得 $I = \frac{\pi^2}{4}$。
> - **书目出处**：《基础30讲》第6讲第144页 [例 6.10]
> 
> ### 题型三：倒数型反三角函数和 $\arctan x + \arctan \frac{1}{x}$ 的分段秒杀
> - **核心方法**：注意根据 $x$ 的正负符号拆开区间：$x > 0$ 时和为 $\frac{\pi}{2}$；$x < 0$ 时和为 $-\frac{\pi}{2}$。在求极限或求导时直接代入常数。
> - **典型例示**：求解 $\lim_{x \to 0^+} \left( \arctan x + \arctan \frac{1}{x} \right) = \frac{\pi}{2}$。
> - **书目出处**：《基础30讲》第1讲第15页 [反三角函数性质]
