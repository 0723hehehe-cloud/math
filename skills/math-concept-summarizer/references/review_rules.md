# 考研数学总结复盘格式规范 (Review Formatting Guidelines)

## 1. 目录结构规范
- **根目录**: `D:/ob/考研数学`
- **复盘目录**: `D:/ob/考研数学/总结复盘/<二级学科>/<章节>/`
  - 例如对于高数函数性质：`D:/ob/考研数学/总结复盘/高等数学/01-函数极限与连续/01-函数及其性质/`
  - 文件命名：`<知识点名称>.md`，例如 `周期性.md`。

## 2. 笔记内容排版与 Callouts 规范
每个复盘笔记应包含以下核心部分：

### A. Frontmatter (元数据)
包含 `type: 总结复盘` 以及相应的层次化 tags：
```yaml
---
type: 总结复盘
tags:
  - 总结复盘/高等数学/01-函数极限与连续/01-函数及其性质/周期性
---
```

### B. 标题与结构
- 笔记唯一的一级标题：`# <知识点名称> 总结复盘`
- 结构由两个特定的 Obsidian 呼应卡 (Callouts) 组成：
  1. `> [!info] 涉及知识点`：概念的精确定义、考研秒杀公式与核心定理。
  2. `> [!todo] 核心题型与解法`：考研中该概念的各种常考题型以及对应的极简解题套路。

## 3. LaTeX 公式书写规范
为确保在 Obsidian 中的公式渲染效果最佳且不会与 Markdown 标记冲突，必须严格遵守以下规则：
1. **独立行公式**：使用双美元符号 `$$ ... $$`。公式前后必须换行，独立成行。
   - **错误示例**：`这里是公式 $$f(x+T)=f(x)$$ 下文...`
   - **正确示例**：
     ```markdown
     这里是公式：
     $$f(x+T)=f(x)$$
     下文...
     ```
2. **行内公式**：使用单美元符号 `$ ... $`。公式内部不能包含换行。
3. **公式加粗与突出显示**：
   - 使用 Obsidian 内置语法高亮行内公式：`==$公式$==`。
   - 在公式内部对核心项加粗：`\mathbf{...}` 或 `\pmb{...}`。
4. **多步推导对齐**：使用 `\begin{aligned} ... \end{aligned}` 块，并在每步前使用 `&` 对齐。
5. **严禁在块引用或列表的同一行书写块级公式**：
   - **错误示例**：
     `> $$f(x) = \sin x$$`
   - **正确示例**：
     ```markdown
     > $$
     > f(x) = \sin x
     > $$
     ```

## 4. 出处规范 (Citation Standards)
为方便强化阶段快速翻书查阅，各题型下的出处必须极其精准，禁止使用模糊表达。必须符合以下标准：
1. **要素齐备**：必须同时写明：`第几讲`、`书中的印刷物理页码`（通过 PDF页码 - 5 换算），以及具体到例题或结论的编号。
2. **标明具体例题**：格式应如 `[例 X.Y]` 或 `[重要结论 (X)]` 或 `[定理 X]`，例如：
   - `《基础30讲》第1讲第14页 [例 1.9]`
   - `《基础30讲》第8讲第199页 [重要结论 (4)]`
   - `《基础30讲》第13讲第306页 [偏导数性质]`
