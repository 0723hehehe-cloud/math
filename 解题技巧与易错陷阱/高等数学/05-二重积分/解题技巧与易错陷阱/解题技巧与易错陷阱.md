# 05-二重积分 解题技巧与易错陷阱

## 🔍 维度一：表面信号 ⟹ 隐藏条件（题意解码）

### 📌 看见“偏心圆区域 $x^2+y^2 \le ax+by$” ⟹ 隐藏条件：坐标平移移至原点 $u=x-\frac{a}{2}, v=y-\frac{b}{2}$ 秒杀奇函数项 **【表面信号】**：区域为非原点圆 $x^2+y^2 \le ax+by$；**【隐藏条件】**：先配方为 $(x-\frac{a}{2})^2 + (y-\frac{b}{2})^2 \le \frac{a^2+b^2}{4}$，令 $u=x-\frac{a}{2}, v=y-\frac{b}{2}$ 平移至原点。平移后区域 $D'$ 变为关于原点对称的标准圆，展开被积函数后，所有一次奇函数项 $u, v$ 积分直接归零，偶函数项 $v^2$ 利用轮换对称性化为 $\frac{1}{2}(u^2+v^2)=\frac{1}{2}r^2$ 极速求解！

### - 📖 溯源例题（考研数学经典二重积分计算题 第22题）

**题目**：计算二重积分 $\iint_D (x+y^2) \, d\sigma$，其中 $D = \{(x,y) \mid x^2+y^2 \le x+y\}$。

### 🚨 偏心圆坐标平移展开展开式项丢失与轮换对称遗忘

平移 $y = v + \frac{1}{2}$ 代入 $y^2 = (v+\frac{1}{2})^2 = v^2 + v + \frac{1}{4}$ 时，切勿漏掉交叉项 $v$ 或常数项 $\frac{1}{4}$；计算 $int v^2 dudv$ 时，若直接套极坐标易算错，一定要利用轮换对称性化为 $\frac{1}{2}int (u^2+v^2) dudv = \frac{1}{2}\int_0^{2\pi}d\theta \int_0^R r^3 dr$！
