# 05-二重积分 解题技巧与易错陷阱

## 🔍 维度一：表面信号 ⟹ 隐藏条件（题意解码）

> [!info] 📌 看见“二重积分达到最大” ⟹ 隐藏条件：积分区域必为 $f(x,y) \ge 0$
> **【表面信号】**：求使 $\iint_D f(x,y) \, d\sigma$ 最大的区域 $D$；**【隐藏条件】**：必须把所有 $f \ge 0$ 的正贡献点全部纳入，排除所有 $f < 0$ 的负贡献点，故区域必定精确为 $D = \{(x,y) \mid f(x,y) \ge 0\}$。
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第210页 [例 14.12]）
> > **题目**：(1) 设积分区域 $D$ 能使二重积分 $\iint_D (1-2x^2-y^2) \, d\sigma$ 的值达到最大，求出该积分区域 $D$；(2) 对 (1) 中的二重积分，求其最大值。

> [!info] 📌 看见“二重积分达到最小” ⟹ 隐藏条件：积分区域必为 $f(x,y) \le 0$
> **【表面信号】**：求使 $\iint_D f(x,y) \, d\sigma$ 最小的区域 $D$；**【隐藏条件】**：区域必定精确为 $D = \{(x,y) \mid f(x,y) \le 0\}$。
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第212页 [例 14.15]）
> > **题目**：设积分区域 $D$ 能使二重积分 $\iint_D (x^2+y^2-4) \, d\sigma$ 的值达到最小，求出该积分区域 $D$ 及最小值。

> [!info] 📌 看见“被积函数原函数不可求” ⟹ 隐藏条件：交换积分次序 $dxdy \leftrightarrow dydx$
> **【表面信号】**：被积函数含 $e^{-x^2}, \frac{\sin x}{x}, \cos(x^2), \frac{1}{\sqrt{1+y^4}}$ 等一元不可积项；**【隐藏条件】**：原次序无法积分，必须先画图交换积分次序才能积出！
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第213页 [课后习题 14.1]）
> > **题目**：计算二重积分 $I = \int_0^1 dy \int_y^1 e^{-x^2} \, dx$。

> [!info] 📌 看见被积函数含 $|x-y|$ 或 $\max\{x,y\}$ ⟹ 隐藏条件：以零线 $y=x$ 为界拆分区域
> **【表面信号】**：被积函数含分段或绝对值；**【隐藏条件】**：必须画出分界线 $y=x$ 将区域 $D$ 拆为 $D_1(y < x)$ 与 $D_2(y > x)$ 两块分别去绝对值积分。
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第213页 [课后习题 14.2]）
> > **题目**：计算二重积分 $\iint_D \lvert x-y \rvert \, dxdy$，其中 $D: 0 \le x \le 1, 0 \le y \le 1$。

> [!info] 📌 看见被积函数非负且二重积分为 0 ⟹ 隐藏条件：在 $D$ 上 $f(x,y) \equiv 0$
> **【表面信号】**：$\iint_D f(x,y) \, d\sigma = 0$ 且已知 $f(x,y) \ge 0$ 连续；**【隐藏条件】**：由连续函数性质，在 $D$ 上必有 $f(x,y) \equiv 0$。
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第205页 [定理 14.2]）
> > **题目**：设 $f(x,y)$ 在闭区域 $D$ 上连续，且 $f(x,y) \ge 0$。若 $\iint_D f(x,y) \, d\sigma = 0$，证明：在 $D$ 上 $f(x,y) \equiv 0$。

> [!info] 📌 看见“区域关于 $y=x$ 对称” ⟹ 隐藏条件：轮换对称性
> **【表面信号】**：区域 $D$ 在 $x,y$ 互换下保持不变；**【隐藏条件】**：$\iint_D f(x,y) \, d\sigma = \iint_D f(y,x) \, d\sigma = \frac{1}{2}\iint_D [f(x,y)+f(y,x)] \, d\sigma$。特别地，若 $f(x,y)+f(y,x)=0$，积分直接为 0。
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第208页 [例 14.8]）
> > **题目**：计算二重积分 $\iint_D \frac{\sin x}{\sin x + \sin y} \, d\sigma$，其中 $D: 0 \le x \le \frac{\pi}{2}, 0 \le y \le \frac{\pi}{2}$。

> [!info] 📌 看见“已知图形形心坐标 $(\bar{x},\bar{y})$” ⟹ 隐藏条件：直接利用积分形心公式秒杀
> **【表面信号】**：被积函数含一次项 $x$ 或 $y$，区域几何面积 $A(D)$ 已知；**【隐藏条件】**：利用 $\iint_D x \, d\sigma = \bar{x} \cdot A(D)$ 和 $\iint_D y \, d\sigma = \bar{y} \cdot A(D)$ 直接代入秒杀，无需积分。
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第207页 [例 14.6]）
> > **题目**：设 $D$ 为由 $x^2+y^2 \le 1, y \ge 0$ 围成的半圆区域，求二重积分 $\iint_D y \, d\sigma$。

> [!info] 📌 看见“求一元不可积的高斯积分 $\int_0^{+\infty} e^{-x^2} \, dx$” ⟹ 隐藏条件：平方化为二重极坐标秒杀
> **【表面信号】**：求一元正态分布积分 $I = \int_0^{+\infty} e^{-x^2} \, dx$；**【隐藏条件】**：先平方得 $I^2 = \int_0^{+\infty}\int_0^{+\infty} e^{-(x^2+y^2)} \, dxdy$，转第一象限极坐标瞬间求出 $I = \frac{\sqrt{\pi}}{2}$。
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第214页 [课后习题 14.13]）
> > **题目**：计算积分 $I = \int_0^{+\infty} e^{-x^2} \, dx$。

## 💡 维度二：核心秒杀技巧与极速换元

> [!tip] ⚡ 二重积分区域椭圆换元化圆秒杀法
> 当被积函数或区域含 $ax^2 + by^2 \le 1$ 时，令 $x = \frac{r\cos\theta}{\sqrt{a}}, y = \frac{r\sin\theta}{\sqrt{b}}$，雅可比行列式为 $J = \frac{r}{\sqrt{ab}}$，积分区域瞬间化为 $r \le 1$ 的标准单位圆。
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第210页 [例 14.12]）
> > **题目**：计算 $\iint_D (1-2x^2-y^2) \, d\sigma$，其中 $D: 2x^2+y^2 \le 1$。

> [!tip] ⚡ 倾斜椭圆区域 $ax^2 + bxy + cy^2 \le 1$ 配方换元法
> 配方为 $a\left(x + \frac{b}{2a}y\right)^2 + \left(c - \frac{b^2}{4a}\right)y^2 \le 1$，令 $u = \sqrt{a}(x + \frac{b}{2a}y), v = \sqrt{c - \frac{b^2}{4a}}y$，转为标准圆 $u^2+v^2 \le 1$。
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第214页 [课后习题 14.8]）
> > **题目**：计算二重积分 $\iint_D (x+y)^2 \, dxdy$，其中区域 $D: x^2 + xy + y^2 \le 1$。

> [!tip] ⚡ 平行四边形区域 $a_1 \le ax+by \le a_2, b_1 \le cx+dy \le b_2$ 一般线性变换法
> 令 $u = ax+by, v = cx+dy$，积分区域瞬间化为矩形 $[a_1, a_2] \times [b_1, b_2]$，面积元 $dxdy = \frac{1}{\lvert ad-bc \rvert} \, dudv$。
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第214页 [课后习题 14.7]）
> > **题目**：计算二重积分 $\iint_D (x+y) \, dxdy$，其中区域 $D$ 由 $x+y=1, x+y=2, x-y=0, x-y=1$ 围成。

> [!tip] ⚡ 极坐标下心形线 $r=a(1+\cos\theta)$ 与玫瑰线对称性计算法
> 心形线关于极轴对称，求面积或积分时只需计算 $\theta \in [0, \pi]$ 并乘以 2 倍；双叶玫瑰线 $r^2 = a^2 \cos 2\theta$ 关于坐标轴全对称，只需计算 $\theta \in [0, \pi/4]$ 乘以 4 倍。
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第213页 [课后习题 14.5]）
> > **题目**：求由心形线 $r = a(1+\cos\theta)$ ($a>0$) 所围成图形的面积。

> [!tip] ⚡ 立体体积投影法：$V = \iint_D (z_{	ext{上}} - z_{	ext{下}}) \, d\sigma$
> 求由上下两曲面 $z_1(x,y)$ 与 $z_2(x,y)$ 围成的立体体积时，先联立消去 $z$ 得到在 $xy$ 平面上的投影区域 $D$，则体积 $V = \iint_D (z_{	ext{上}} - z_{	ext{下}}) \, d\sigma$。
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第214页 [课后习题 14.15]）
> > **题目**：求由旋转抛物面 $z = x^2+y^2$ 与平面 $z = 2-x^2-y^2$ 围成的立体体积。

## ⚠️ 维度三：隐蔽死穴与防坑指南

> [!warning] 🚨 交换积分次序画图时交点坐标计算失误
> 交换积分次序 $dxdy \leftrightarrow dydx$ 时，必须先求出两条边界曲线的精确交点，若区域被交点分割为上下或左右多块，必须拆分为多个累次积分和！
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第213页 [课后习题 14.1 拓展]）
> > **题目**：计算二重积分 $I = \int_0^1 dx \int_x^{\sqrt{2-x^2}} f(x,y) \, dy$，试交换积分次序。

> [!warning] 🚨 极坐标下交换积分次序漏拆极点角度区间
> 极坐标先对 $\theta$ 积分再对 $r$ 积分时，若边界由圆与直线复合而成，$r$ 的最大边界在交点处发生突变，必须按交点角度把 $\theta$ 拆分为多段区间！
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第213页 [课后习题 14.3]）
> > **题目**：改变累次积分 $I = \int_0^{\pi/4} d\theta \int_0^{2\cos\theta} f(r,\theta) \, dr$ 的积分次序。

> [!warning] 🚨 二重积分最大区域确定陷阱
> 使二重积分达到最大的区域 $D$ 必须精确等于被积函数 $f(x,y) \ge 0$ 的区域，多包含 $f < 0$ 的区域会导致积分值减小。
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第210页 [例 14.12 变式]）
> > **题目**：设 $D$ 使 $\iint_D (1-2x^2-y^2) \, d\sigma$ 极大，若误将区域扩大至 $x^2+y^2 \le 1$，分析二重积分值的变化。

> [!warning] 🚨 椭圆换元漏乘雅可比行列式 $J$
> 用 $x = a r\cos\theta, y = b r\sin\theta$ 换元时，面积元素 $d\sigma = ab r \, dr \, d\theta$，绝不能漏掉缩放因子 $ab$。
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第210页 [例 14.12 扩展]）
> > **题目**：计算 $\iint_D \sqrt{1 - \frac{x^2}{a^2} - \frac{y^2}{b^2}} \, d\sigma$，其中 $D: \frac{x^2}{a^2} + \frac{y^2}{b^2} \le 1$。

> [!warning] 🚨 极坐标下开方漏考虑绝对值正负号
> 极坐标下 $x = r\cos\theta$，遇到被积函数 $\sqrt{x^2} = \lvert x \rvert = r\lvert \cos\theta \rvert$，不能直接写成 $r\cos\theta$！必须按 $\theta$ 所在象限拆分区间（一四象限取 $\cos\theta$，二三象限取 $-\cos\theta$）。
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第213页 [课后习题 14.4]）
> > **题目**：计算二重积分 $\iint_D \sqrt{x^2} \, dxdy$，其中区域 $D: x^2+y^2 \le 1$。

> [!warning] 🚨 极坐标下极点在圆周上时的角度范围误判
> 圆 $x^2+y^2 \le 2x$ 极坐标方程为 $r \le 2\cos\theta$，因极点在圆周上，$\theta$ 范围为 $[-\frac{\pi}{2}, \frac{\pi}{2}]$，绝不能错写成 $[0, 2\pi]$（错写会导致下半部分被重复算或越界）。
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第209页 [例 14.10]）
> > **题目**：计算二重积分 $\iint_D \sqrt{x^2+y^2} \, d\sigma$，其中 $D: x^2+y^2 \le 2x$。

> [!warning] 🚨 二重积分中值定理盲目去掉中值点符号
> 利用二重积分中值定理 $\iint_D f(x,y) \, d\sigma = f(\xi, \eta) A(D)$ 时，$(\xi, \eta)$ 是 $D$ 内部的某个特定点，不能直接写成 $f(x,y) A(D)$！
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第214页 [课后习题 14.6]）
> > **题目**：设 $f(x,y)$ 连续，证明存在 $(\xi, \eta) \in D$，使得 $\iint_D f(x,y) \, d\sigma = f(\xi, \eta) A(D)$。

> [!warning] 🚨 轮换对称性 $x \leftrightarrow y$ 使用前提失误
> 轮换对称性 $x$ 与 $y$ 互换仅当区域 $D$ 关于直线 $y=x$ 完全对称时才成立！若区域仅关于原点对称或关于坐标轴对称，绝不能使用 $x \leftrightarrow y$ 轮换！
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第208页 [概念辨析]）
> > **题目**：判断在 $D: x^2+y^2 \le 1, x \ge 0, y \ge 0$ 与 $D': x^2+y^2 \le 1, x \ge 0$ 上能否分别使用轮换对称性。

> [!warning] 🚨 瑕点二重积分/无界二重积分收敛性条件死穴
> 对于瑕点在原点的二重积分 $\iint_D \frac{d\sigma}{(x^2+y^2)^p}$，收敛充要条件是 $p < 1$（一元反常积分是 $p < 1$ 瑕点收敛，但二重积分因为面积元 $r\,dr$ 的存在，使得二重积分次幂阈值为 1）；对无界区域 $p > 1$ 才收敛。
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第214页 [课后习题 14.9]）
> > **题目**：讨论反常二重积分 $\iint_{x^2+y^2 \le 1} \frac{1}{(x^2+y^2)^p} \, dxdy$ 的收敛性。

> [!warning] 🚨 累次积分极限 $t \to 0$ 忽视极坐标变量代换
> 求 $\lim_{t \to 0} \frac{1}{t^4} \iint_{x^2+y^2 \le t^2} f(x,y) \, dxdy$ 时，若直接代入会得到未定式。正确做法是令 $x=tr\cos\theta, y=tr\sin\theta$，把 $t^2$ 提出来消去分母。
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第214页 [课后习题 14.11]）
> > **题目**：设 $f(x,y)$ 连续，求极限 $\lim_{t \to 0^+} \frac{1}{\pi t^2} \iint_{x^2+y^2 \le t^2} f(x,y) \, dxdy$。

> [!warning] 🚨 含变限积分二重积分直接求导死穴
> 若二重积分的区域边界依赖于外层变限参数 $x$，对 $x$ 求导前必须先画图把二重积分化为一元变限积分，或用高斯/莱布尼茨公式，切勿直接对二重积分符号内部求导。
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第214页 [课后习题 14.12]）
> > **题目**：设 $F(x) = \iint_{y^2 \le 2x} f(x,y) \, dxdy$，对 $x$ 求一阶导数 $F'(x)$。

## 🚀 维度四：强化速查表（表面信号 $\to$ 隐藏条件 / 秒杀结论）

| 题目表面信号 / 关键词 | 背后隐含条件 / 秒杀结论 |
| :--- | :--- |
| 看见“二重积分达到最大” | 隐含条件：积分区域必定为被积函数 $f(x,y) \ge 0$ 的集合 |
| 看见“二重积分达到最小” | 隐含条件：积分区域必定为被积函数 $f(x,y) \le 0$ 的集合 |
| 看见被积函数原函数不可求（如 $e^{-x^2}, \frac{\sin x}{x}$） | 隐含条件：必须画图交换积分次序 $dxdy \leftrightarrow dydx$ 才能积出 |
| 看见被积函数含 $\lvert x-y \rvert$ 或 $\max\{x,y\}$ | 以零线 $y=x$ 为界将区域拆分为 $y<x$ 与 $y>x$ 分别去绝对值积分 |
| 看见“非负函数 $f \ge 0$ 二重积分为 0” | 隐含条件：在区域 $D$ 上恒有 $f(x,y) \equiv 0$ |
| 看见“区域 $D$ 关于 $y=x$ 对称” | 隐含条件：轮换对称性 $\iint_D f(x,y) \, d\sigma = \frac{1}{2}\iint_D [f(x,y)+f(y,x)] \, d\sigma$ |
| 看见被积函数含一次项 $x, y$ 且形心已知 | 直接套形心公式：$\iint_D x \, d\sigma = \bar{x} A(D)$ |
| 看见求一元高斯积分 $\int_0^{+\infty} e^{-x^2} \, dx$ | 平方化为二重积分 $I^2 = \int_0^{+\infty}\int_0^{+\infty} e^{-(x^2+y^2)} \, dxdy$，转极坐标得 $I=\frac{\sqrt{\pi}}{2}$ |
| 积分区域为椭圆 $ax^2 + by^2 \le 1$ | 令 $x=\frac{r\cos\theta}{\sqrt{a}}, y=\frac{r\sin\theta}{\sqrt{b}}$，乘雅可比 $J=\frac{r}{\sqrt{ab}}$ |
| 区域为平行四边形 $a_1 \le ax+by \le a_2$ | 令 $u=ax+by, v=cx+dy$，利用雅可比 $J=\frac{1}{\lvert ad-bc \rvert}$ 转为矩形 |
| 区域边界为心形线 $r=a(1+\cos\theta)$ | 利用极轴对称算 $\theta \in [0,\pi]$ 乘 2 倍；双叶玫瑰线算 $[0,\pi/4]$ 乘 4 倍 |
| 极坐标下遇 $\sqrt{x^2} = \lvert x \rvert$ | 化为 $r\lvert \cos\theta \rvert$，按象限正负拆分角度区间，切勿漏掉绝对值 |
| 瑕点在原点的二重积分 $\iint_D \frac{d\sigma}{(x^2+y^2)^p}$ | 收敛条件为 $p < 1$（极坐标 $r\,dr$ 降幂一阶），无界区域收敛条件为 $p > 1$ |
| 立体体积由上下曲面围成 | 联立求 $xy$ 平面投影区域 $D$，体积 $V = \iint_D (z_{\text{上}} - z_{\text{下}}) \, d\sigma$ |
