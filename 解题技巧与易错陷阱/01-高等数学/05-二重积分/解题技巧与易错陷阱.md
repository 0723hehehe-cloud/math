# 05-二重积分 解题技巧与易错陷阱

## 🔍 维度一：表面信号 ⟹ 隐藏条件（题意解码）

> [!info] 📌 看见“二重和式双重极限” ⟹ 隐藏条件：转换为矩形区域 $[0,1]\times[0,1]$ 上的二重定积分
> **【表面信号】**：求 $\lim_{n \to \infty} \sum_{i=1}^n \sum_{j=1}^n \frac{n}{(n+i)(n^2+j^2)}$；**【隐藏条件】**：分子分母同除以 $n^3$ 得到 $\frac{1}{n^2} \sum_{i=1}^n \sum_{j=1}^n \frac{1}{(1+\frac{i}{n})(1+(\frac{j}{n})^2)}$，令 $x=\frac{i}{n}, y=\frac{j}{n}, dxdy=\frac{1}{n^2}$，瞬间化为二重定积分 $\int_0^1 dx \int_0^1 \frac{1}{(1+x)(1+y^2)} dy$。
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第371页 [基础习题精练 14.1]）
> > **题目**：$\lim_{n \to \infty} \sum_{i=1}^n \sum_{j=1}^n \frac{n}{(n+i)(n^2+j^2)} = (\quad)$

> [!info] 📌 看见“积分区域为偏移圆 $x^2+y^2 \le 2y$” ⟹ 隐藏条件：极坐标下 $r \le 2\sin\theta, \theta \in [0, \pi]$
> **【表面信号】**：区域 $D = \{(x,y) \mid x^2+y^2 \le 2y\}$；**【隐藏条件】**：配方为 $x^2+(y-1)^2 \le 1$，极坐标下方程为 $r \le 2\sin\theta$，由于切于原点，$\theta$ 范围必须为 $[0, \pi]$，面积元 $d\sigma = r\,dr\,d\theta$。
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第371页 [基础习题精练 14.2]）
> > **题目**：设函数 $f(t)$ 连续，区域 $D = \{(x,y) \mid x^2+y^2 \le 2y\}$，则 $\iint_D f(xy) \, dxdy = (\quad)$

> [!info] 📌 看见“极坐标累次积分上限 $r \le \cos\theta$” ⟹ 隐藏条件：还原为直角坐标圆 $(x-\frac{1}{2})^2+y^2 \le \frac{1}{4}$
> **【表面信号】**：$\int_0^{\pi/2} d\theta \int_0^{\cos\theta} f(r\cos\theta, r\sin\theta) r \, dr$；**【隐藏条件】**：$r = \cos\theta \implies r^2 = r\cos\theta \implies x^2+y^2=x$，直角坐标下先对 $x$ 积分得 $\int_0^1 dy \int_0^{\sqrt{y-y^2}} f(x,y) \, dx$。
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第372页 [基础习题精练 14.3]）
> > **题目**：累次积分 $\int_0^{\pi/2} d\theta \int_0^{\cos\theta} f(r\cos\theta, r\sin\theta) r \, dr$ 可以写成 $(\quad)$

> [!info] 📌 看见“直角坐标下积分限出现 $\sqrt{2-x^2}$” ⟹ 隐藏条件：转极坐标圆扇形区域秒杀
> **【表面信号】**：$\int_{-1}^1 dx \int_{\lvert x \rvert}^{\sqrt{2-x^2}} \sin(x^2+y^2) \, dy$；**【隐藏条件】**：直角坐标极难积分，画图发现区域为圆心在原点、半径为 $\sqrt{2}$ 的扇形区域，$\theta \in [\frac{\pi}{4}, \frac{3\pi}{4}]$，转极坐标 $\int_{\pi/4}^{3\pi/4} d\theta \int_0^{\sqrt{2}} \sin(r^2) r \, dr$ 秒杀得 $\frac{\pi}{4}(1-\cos 2)$。
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第372页 [基础习题精练 14.4]）
> > **题目**：$\int_{-1}^1 dx \int_{\lvert x \rvert}^{\sqrt{2-x^2}} \sin(x^2+y^2) \, dy = (\quad)$

> [!info] 📌 看见“卷积型二重积分 $\iint_D f(x)g(y-x) \, dxdy$” ⟹ 隐藏条件：区域受双重阶梯函数截断为平行四边形
> **【表面信号】**：$f(x)=g(x)=a$ ($0 \le x \le 1$)，其余为 0；**【隐藏条件】**：$f(x)$ 限制 $0 \le x \le 1$，$g(y-x)$ 限制 $0 \le y-x \le 1 \implies x \le y \le x+1$，积分区域截断为底为1、高为1的平行四边形，积分直接得 $a^2$。
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第372页 [基础习题精练 14.5]）
> > **题目**：设 $a>0, f(x)=g(x)=\begin{cases} a, & 0 \le x \le 1 \\ 0, & \text{其他} \end{cases}$，而 $D$ 表示全平面，则 $I = \iint_D f(x)g(y-x) \, dxdy = \underline{\hspace{2em}}$

> [!info] 📌 看见“二重变限积分 $F(t) = \int_0^t dy \int_y^t f(x) \, dx$” ⟹ 隐藏条件：先交换积分次序再求导
> **【表面信号】**：变限积分内外层限均含 $t$；**【隐藏条件】**：先画图交换积分次序得 $\int_0^t dx \int_0^x f(x) \, dy = \int_0^t x f(x) \, dx$，再由变上限积分求导定理直接得出 $F'(t) = t f(t)$。
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第372页 [基础习题精练 14.6]）
> > **题目**：设 $f(x)$ 为连续函数，$F(t) = \int_0^t dy \int_y^t f(x) \, dx$，则 $F'(t) = \underline{\hspace{2em}}$

> [!info] 📌 看见“被积函数含奇函数项与常数项” ⟹ 隐藏条件：利用对称性奇函数项归零
> **【表面信号】**：求 $\iint_D (xy^5 - 1) \, d\sigma$，$D$ 由 $y=\sin x, x=\pm\frac{\pi}{2}, y=1$ 围成；**【隐藏条件】**：区域关于 $y$ 轴对称，$xy^5$ 关于 $x$ 为奇函数，积分直接归零！只剩 $-\iint_D 1 \, d\sigma = -A(D) = -(\pi-2)$。
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第372页 [基础习题精练 14.7]）
> > **题目**：设区域 $D$ 是由曲线 $y = \sin x$ 与直线 $x = \pm \frac{\pi}{2}, y = 1$ 围成的平面区域，则 $\iint_D (xy^5 - 1) \, d\sigma = \underline{\hspace{2em}}$

> [!info] 📌 看见“半圆区域 $x^2+y^2 \le 1, x \ge 0$” ⟹ 隐藏条件：关于 $x$ 轴对称奇函数项归零
> **【表面信号】**：求 $\iint_D \frac{1+xy}{1+x^2+y^2} \, dxdy$；**【隐藏条件】**：拆为 $\frac{1}{1+x^2+y^2} + \frac{xy}{1+x^2+y^2}$，由于区域关于 $x$ 轴对称，$xy$ 关于 $y$ 为奇函数，后项积分归零，只算极坐标前项！
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第372页 [基础习题精练 14.8]）
> > **题目**：设区域 $D = \{(x,y) \mid x^2+y^2 \le 1, x \ge 0\}$，计算二重积分 $I = \iint_D \frac{1+xy}{1+x^2+y^2} \, dxdy$

> [!info] 📌 看见被积函数含 $\max\{x^2, y^2\}$ ⟹ 隐藏条件：以对称轴 $y=x$ 为界拆分翻倍
> **【表面信号】**：求 $\iint_D e^{\max\{x^2,y^2\}} \, dxdy$（$D: 0 \le x \le 1, 0 \le y \le 1$）；**【隐藏条件】**：以 $y=x$ 分界，$y<x$ 时为 $e^{x^2}$，$y>x$ 时为 $e^{y^2}$。由轮换对称性积分等于 $2 \int_0^1 dx \int_0^x e^{x^2} \, dy = 2 \int_0^1 x e^{x^2} \, dx = e-1$。
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第372页 [基础习题精练 14.9]）
> > **题目**：计算二重积分 $\iint_D e^{\max\{x^2,y^2\}} \, dxdy$，其中 $D = \{(x,y) \mid 0 \le x \le 1, 0 \le y \le 1\}$

> [!info] 📌 看见“极坐标含 $\sqrt{1-r^2 \cos 2\theta}$” ⟹ 隐藏条件：还原为直角坐标 $x^2-y^2$
> **【表面信号】**：$\iint_D r^2 \sin\theta \sqrt{1-r^2 \cos 2\theta} \, drd\theta$；**【隐藏条件】**：$r^2 \cos 2\theta = r^2(\cos^2\theta-\sin^2\theta) = x^2-y^2$，$r \le \sec\theta \implies x \le 1$，转化为直角坐标积分轻松求解。
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第372页 [基础习题精练 14.10]）
> > **题目**：计算二重积分 $I = \iint_D r^2 \sin\theta \sqrt{1-r^2 \cos 2\theta} \, drd\theta$，其中 $D = \{(r,\theta) \mid 0 \le r \le \sec\theta, 0 \le \theta \le \frac{\pi}{4}\}$

> [!info] 📌 看见“二重积分达到最大/最小” ⟹ 隐藏条件：区域必为被积函数 $f \ge 0$ 或 $f \le 0$ 的集合
> **【表面信号】**：求使 $\iint_D (1-2x^2-y^2) \, d\sigma$ 达到最大的区域 $D$；**【隐藏条件】**：区域必为 $1-2x^2-y^2 \ge 0 \implies 2x^2+y^2 \le 1$（椭圆），利用椭圆换元 $x=\frac{r\cos\theta}{\sqrt{2}}, y=r\sin\theta$ 与雅可比 $J=\frac{r}{\sqrt{2}}$ 得最大值 $\frac{\sqrt{2}\pi}{4}$。
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第372页 [基础习题精练 14.12]）
> > **题目**：(1) 设积分区域 $D$ 能使二重积分 $\iint_D (1-2x^2-y^2) \, d\sigma$ 的值达到最大，求出该积分区域 $D$；(2) 求出其最大值。

## 💡 维度二：核心秒杀技巧与极速换元

## ⚠️ 维度三：隐蔽死穴与防坑指南

> [!warning] 🚨 二重和式极限误按一元定积分拆分
> 求 $\lim_{n \to \infty} \sum_{i=1}^n \sum_{j=1}^n \frac{n}{(n+i)(n^2+j^2)}$ 时，切勿将 $i$ 和 $j$ 的二重和式硬当成一元积分相加，必须将其整体识别为 $[0,1]\times[0,1]$ 上的二重积分！
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第371页 [基础习题精练 14.1 陷阱]）
> > **题目**：$\lim_{n \to \infty} \sum_{i=1}^n \sum_{j=1}^n \frac{n}{(n+i)(n^2+j^2)} = (\quad)$

> [!warning] 🚨 圆心不在原点的极坐标积分限 $r$ 与 $\theta$ 范围写错
> 圆 $x^2+y^2 \le 2y$（即 $x^2+(y-1)^2 \le 1$）切于原点，转极坐标时 $r \le 2\sin\theta$，因全在 $x$ 轴上方，$\theta$ 范围为 $[0,\pi]$，绝不能误写成 $[-\frac{\pi}{2}, \frac{\pi}{2}]$ 或 $[0, 2\pi]$！
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第371页 [基础习题精练 14.2 易错点]）
> > **题目**：设函数 $f(t)$ 连续，区域 $D = \{(x,y) \mid x^2+y^2 \le 2y\}$，则 $\iint_D f(xy) \, dxdy = (\quad)$

> [!warning] 🚨 二重变限积分未交换次序直接求导死穴
> 对 $F(t) = \int_0^t dy \int_y^t f(x) \, dx$ 求导时，内层限含 $t$，外层限也含 $t$，直接用莱布尼茨公式极易漏项！必须先画图交换积分次序化为一元变限积分 $\int_0^t x f(x) \, dx$ 再求导。
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第372页 [基础习题精练 14.6 易错点]）
> > **题目**：设 $f(x)$ 为连续函数，$F(t) = \int_0^t dy \int_y^t f(x) \, dx$，求 $F'(t)$。

> [!warning] 🚨 二重积分奇偶性归零误用前提失误
> 只有当区域 $D$ 关于 $y$ 轴对称且被积函数关于 $x$ 是奇函数时，积分才归零；若区域仅关于原点对称，奇函数积分不一定归零，必须严格校验区域对称轴！
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第372页 [基础习题精练 14.7 易错点]）
> > **题目**：设区域 $D$ 是由曲线 $y = \sin x$ 与直线 $x = \pm \frac{\pi}{2}, y = 1$ 围成的平面区域，求 $\iint_D (xy^5 - 1) \, d\sigma$。

> [!warning] 🚨 椭圆换元漏乘雅可比行列式 $J$
> 用 $x = \frac{r\cos\theta}{\sqrt{2}}, y = r\sin\theta$ 换元时，面积元素 $d\sigma = \frac{r}{\sqrt{2}} \, dr \, d\theta$，绝不能漏掉缩放因子 $\frac{1}{\sqrt{2}}$！
> 
> > [!example]- 📖 溯源例题（张宇《基础30讲》第14讲第372页 [基础习题精练 14.12 易错点]）
> > **题目**：(1) 设积分区域 $D$ 能使二重积分 $\iint_D (1-2x^2-y^2) \, d\sigma$ 的值达到最大，求出该积分区域 $D$；(2) 求出其最大值。
